## 개념

**음운의 변동**이란 한 음운이 일정한 음성 환경에서 다른 음운으로 바뀌어 발음되는 현상이다. 두 형태소가 만나는 **경계**에서 주로 일어나며, 발음을 더 쉽게 하려는 경제성에서 비롯된다.

예) `/값 + 만/ → [감만]`
1. 겹받침 'ㄳ'이 음절 끝에서 [ㅂ]으로 줄고(**자음군 단순화**),
2. 그 [ㅂ]이 뒤의 비음 'ㅁ' 앞에서 [ㅁ]으로 바뀐다(**비음화**).
→ 한 단어에 **두 변동이 잇따라** 일어나기도 한다. 수능에서는 "어떤 변동이 몇 번, 어떤 순서로 일어났는가"를 자주 묻는다.

> 지금 우리가 발음할 때 일어나는 현상(공시적)이 음운 **변동**, 시간이 흐르며 말소리가 바뀐 것(통시적)이 음운 **변화**다. 둘을 구별한다.

## 변동을 보는 두 기준

| 기준 | 갈래 |
|------|------|
| **결과**(겉으로 나타난 모습) | 교체 · 탈락 · 첨가 · 축약 |
| **원인·동기** | 동화 · 이화 |

- **교체**: 한 음운이 다른 음운으로 **바뀜**(수 변화 없음) / **탈락**: 있던 음운이 **없어짐** / **첨가**: 없던 음운이 **생김** / **축약**: 두 음운이 **하나로** 합쳐짐
- **동화**: 한 소리가 이웃 소리의 조음 위치·방법을 **닮아 가는** 것(비음화·유음화·구개음화) / **이화**: 반대로 달라지는 것

아래는 학교 문법의 분류대로 **결과** 기준으로 정리한다. (괄호 안은 변동의 성격)

## 1. 교체

음절 끝이나 자음이 이어질 때 한 음운이 다른 음운으로 바뀐다.

**① 음절의 끝소리 규칙** — 음절 끝에서 자음은 'ㄱ ㄴ ㄷ ㄹ ㅁ ㅂ ㅇ' 7개 중 하나로만 발음된다. 이 7개에 없는 받침은 대표음으로 바뀐다.
- 예) 옷[옫], 낮[낟], 꽃[꼳], 부엌[부억], 솥[솓], 앞[압]
- 단, 뒤에 모음으로 시작하는 형식형태소(조사·어미)가 오면 **연음**되어 끝소리 규칙이 적용되지 않는다. (옷이[오시], 꽃을[꼬츨])

**② 비음화**(동화) — 받침 'ㄱ, ㄷ, ㅂ'이 비음 'ㄴ, ㅁ' 앞에서 같은 위치의 비음 'ㅇ, ㄴ, ㅁ'으로 바뀐다.
- 예) 국물[궁물], 닫는[단는], 밥물[밤물], 먹는[멍는], 앞날[암날]
- 'ㄹ'의 비음화: 'ㅁ, ㅇ' 뒤의 'ㄹ'이 [ㄴ]으로. (담력[담녁], 종로[종노], 대통령[대ː통녕])

**③ 유음화**(동화) — 'ㄴ'이 'ㄹ'의 앞이나 뒤에서 유음 [ㄹ]로 바뀐다.
- 예) 신라[실라], 칼날[칼랄], 권력[궐력], 난로[날로]
- 주의: 'ㄴㄹ'이라도 유음화하지 않고 **비음화**하는 한자어가 있다. (의견란[의ː견난], 생산량[생산냥], 입원료[이붠뇨]) — 한 글자가 독립된 단어처럼 쓰이는 경우.

**④ 구개음화**(동화) — 받침 'ㄷ, ㅌ'이 모음 'ㅣ'(또는 반모음 ㅣ)로 시작하는 형식형태소를 만나 [ㅈ, ㅊ]으로 바뀐다.
- 예) 굳이[구지], 같이[가치], 해돋이[해도지], 붙이다[부치다], 닫히다[다치다]
- 조건이 중요: **형태소 경계**에서, 뒤가 **조사·접사**인 'ㅣ'일 때만. 한 형태소 안('잔디·느티나무')에서는 일어나지 않는다.

**⑤ 된소리되기(경음화)** — 예사소리가 된소리로 바뀐다.
- 받침 'ㄱ,ㄷ,ㅂ' 뒤: 국밥[국빱], 닫고[닫꼬], 옷고름[옫꼬름]
- 용언 어간 받침 'ㄴ,ㅁ' 뒤: 신고[신ː꼬], 감다[감ː따]
- 관형사형 '-(으)ㄹ' 뒤: 할 것을[할꺼슬]
- 한자어 'ㄹ' 받침 뒤 'ㄷ,ㅅ,ㅈ': 갈등[갈뜽], 발전[발쩐]

## 2. 탈락

이웃한 두 음운 중 하나가 사라진다.

**① 자음군 단순화** — 음절 끝 겹받침 중 하나가 탈락한다.
- 앞 자음이 남음: 넋[넉], 앉다[안따], 외곬[외골], 값[갑]
- 뒤 자음이 남음: 닭[닥], 삶[삼ː], 읊다[읍따]
- 주의: '밟-'은 [밥], '넓죽하다'는 [넙쭈카다]처럼 예외가 있어 자주 출제된다.

**② 'ㅎ' 탈락** — 'ㅎ(ㄶ, ㅀ)' 받침이 모음으로 시작하는 어미·접사 앞에서 탈락한다.
- 예) 좋은[조은], 낳아[나아], 많아[마ː나], 싫어도[시러도]

**③ 'ㅡ' 탈락** — 용언 어간 끝 'ㅡ'가 모음 어미 앞에서 탈락한다.
- 예) 쓰- + -어 → 써, 담그- + -아 → 담가, 치르- + -었다 → 치렀다

**④ 'ㄹ' 탈락** — 'ㄹ'이 'ㄴ, ㅂ, ㅅ, 오, ㄹ' 등 특정 환경에서 탈락한다.
- 용언 활용: 울- + -는 → 우는, 살- + -ㅂ니다 → 삽니다
- 합성·파생: 딸 + 님 → 따님, 솔 + 나무 → 소나무, 바늘 + 질 → 바느질

## 3. 첨가

없던 음운이 새로 생긴다.

**① 'ㄴ' 첨가** — 합성어·파생어에서 **앞말이 자음으로 끝나고** 뒷말이 'ㅣ, 야, 여, 요, 유'로 시작할 때 'ㄴ'이 덧난다.
- 예) 솜이불[솜ː니불], 색연필[생년필], 한여름[한녀름], 막일[망닐], 한국요리[한국뇨리]
- 'ㄴ' 첨가 후 다시 비음화·유음화가 이어지기도 한다. (예: 색연필 → ㄴ첨가 → 비음화 [생년필])

**② 사잇소리 현상** — 합성어에서 ㉠ 뒷말 첫소리가 된소리가 되거나, ㉡ 'ㄴ(ㄴㄴ)' 소리가 덧난다.
- 된소리: 밤길[밤낄], 등불[등뿔], 길가[길까]
- 'ㄴ' 덧남: 콧날[콘날], 잇몸[인몸], 나뭇잎[나문닙]
- 앞말이 모음으로 끝나고 고유어가 섞이면 **사이시옷**으로 표기한다(나무+가지→나뭇가지). 다만 사잇소리는 규칙성이 약해 예외가 많다(고래기름·기와집 등은 안 남).

## 4. 축약

두 음운이 하나로 합쳐져 음운 수가 줄어든다.

**① 거센소리되기(자음 축약)** — 'ㅎ'이 'ㄱ, ㄷ, ㅂ, ㅈ'과 만나 거센소리 'ㅋ, ㅌ, ㅍ, ㅊ'으로 합쳐진다.
- 예) 좋고[조코], 놓다[노타], 잡히다[자피다], 맏형[마텽], 꽂히다[꼬치다]
- 'ㅎ'이 앞에 오든 뒤에 오든 일어난다. (낳지[나치], 국화[구콰])

**② 모음 축약** — 두 모음이 한 음절(이중모음 등)로 줄어든다.
- 예) 보- + -아 → 봐, 두- + -었다 → 뒀다, 가지- + -어 → 가져, 되- + -어 → 돼
