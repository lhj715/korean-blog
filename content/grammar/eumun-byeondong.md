## 개념

**음운의 변동**이란 한 음운이 일정한 음성 환경에서 다른 음운으로 바뀌어 발음되는 현상이다. 발음을 더 쉽고 자연스럽게 하려는 데서 일어나며, 주로 **형태소와 형태소가 결합하는 경계**에서 나타난다.

예) /값 + 만/ → [감만] : '값'의 겹받침이 [갑]으로 줄고(자음군 단순화), 다시 'ㅂ'이 'ㅁ' 앞에서 [ㅁ]으로 바뀐다(비음화).

> 시간의 흐름에 따른 말소리의 바뀜(음운 **변화**, 통시적)과 구별해, 현재 공시적으로 일어나는 현상을 음운 **변동**이라 한다.

## 변동을 보는 두 기준

음운 변동은 두 가지 기준으로 나눌 수 있다.

| 기준 | 갈래 |
|------|------|
| **결과**(겉으로 나타난 양상) | 교체 · 탈락 · 첨가 · 축약 |
| **동기**(왜 바뀌나) | 동화 · 이화 |

- **교체**: 한 음운이 다른 음운으로 바뀜 / **탈락**: 있던 음운이 없어짐 / **첨가**: 없던 음운이 생김 / **축약**: 두 음운이 하나로 합쳐짐
- **동화**: 한 소리가 이웃 소리의 조음 위치·방법을 닮아 가는 것 (비음화·유음화·구개음화) / **이화**: 반대로 달라지는 것

→ 아래는 학교 문법의 분류대로 **결과** 기준(교체·탈락·첨가·축약)으로 정리한다.

## 1. 교체

한 음운이 다른 음운으로 바뀐다. (대부분 동화에 속한다)

- **음절의 끝소리 규칙** — 받침은 'ㄱ ㄴ ㄷ ㄹ ㅁ ㅂ ㅇ' 7개로만 발음된다.
  예) 옷[옫], 부엌[부억], 낮[낟], 꽃[꼳]
- **비음화**(동화) — 받침 'ㄱ, ㄷ, ㅂ'이 비음 'ㄴ, ㅁ' 앞에서 'ㅇ, ㄴ, ㅁ'으로.
  예) 국물[궁물], 닫는[단는], 밥물[밤물]
- **유음화**(동화) — 'ㄴ'이 'ㄹ'의 앞이나 뒤에서 'ㄹ'로.
  예) 신라[실라], 칼날[칼랄], 권력[궐력]
- **구개음화**(동화) — 받침 'ㄷ, ㅌ'이 모음 'ㅣ'(반모음 ㅣ)를 만나 'ㅈ, ㅊ'으로.
  예) 굳이[구지], 같이[가치], 해돋이[해도지]
- **된소리되기(경음화)** — 예사소리가 된소리로.
  예) 국밥[국빱], 신고[신ː꼬], 갈등[갈뜽]

## 2. 탈락

두 음운 중 하나가 사라진다.

- **자음군 단순화** — 겹받침 중 하나가 탈락. 예) 값[갑], 닭[닥], 넋[넉], 앉다[안따]
- **'ㅎ' 탈락** — 'ㅎ' 받침이 모음 앞에서 탈락. 예) 좋은[조은], 낳아[나아], 많아[마ː나]
- **'ㅡ' 탈락** — 어간 끝 'ㅡ'가 모음 어미 앞에서 탈락. 예) 쓰- + -어 → 써, 담그- + -아 → 담가
- **'ㄹ' 탈락** — 'ㄹ'이 특정 환경에서 탈락. 예) 울- + -는 → 우는, 딸 + 님 → 따님, 솔 + 나무 → 소나무

## 3. 첨가

없던 음운이 새로 생긴다.

- **'ㄴ' 첨가** — 합성어·파생어에서 앞말이 받침으로 끝나고 뒷말이 'ㅣ, 야, 여, 요, 유'로 시작하면 'ㄴ'이 덧난다.
  예) 솜이불[솜ː니불], 색연필[생년필], 한여름[한녀름]
- **사잇소리 현상** — 합성어에서 뒷말 첫소리가 된소리가 되거나 'ㄴ' 소리가 덧난다.
  예) 밤길[밤낄], 촛불[초뿔], 콧날[콘날], 나뭇잎[나문닙]

## 4. 축약

두 음운이 하나로 합쳐진다.

- **거센소리되기(자음 축약)** — 'ㅎ'이 'ㄱ, ㄷ, ㅂ, ㅈ'과 만나 'ㅋ, ㅌ, ㅍ, ㅊ'으로.
  예) 좋고[조코], 놓다[노타], 잡히다[자피다], 맏형[마텽]
- **모음 축약** — 두 모음이 한 음절로. 예) 보- + -아 → 봐, 두- + -었다 → 뒀다, 가지- + -어 → 가져
