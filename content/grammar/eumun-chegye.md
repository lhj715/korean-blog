## 음운이란

**음운**은 말의 뜻을 구별해 주는 소리의 가장 작은 단위다.
'물'과 '불'의 뜻이 갈리는 것은 첫소리 'ㅁ'과 'ㅂ'이 다르기 때문인데, 이렇게 뜻을 가르는 'ㅁ', 'ㅂ' 하나하나가 음운이다.

음운은 두 갈래로 나뉜다.

| 구분 | 내용 |
|------|------|
| 분절 음운 | 자음과 모음. 소리마디를 나눌 수 있다. |
| 비분절 음운(운소) | 소리의 길이·높낮이 등. 자음·모음에 얹혀 뜻을 구별한다. |

## 음운과 음성 — 변이음

말소리는 두 차원에 존재한다. **음성**은 실제로 발음되는 물리적 소리이고, **음운**은 그 말을 쓰는 사람이 머릿속에서 하나로 인식하는 소리다.

예를 들어 '바보[pabo]'에서 첫 'ㅂ'은 무성음 [p], 둘째 'ㅂ'은 유성음 [b]로 **물리적으로 다르게** 소리 난다. 하지만 우리는 둘을 같은 'ㅂ'으로 느낀다. 이처럼 한 음운이 환경에 따라 다르게 실현된 소리들을 **변이음**이라 하고, 서로 겹치지 않는 자리에 나타나는 이 관계를 **상보적 분포**라 한다.

> 영어는 [p]·[b]가 뜻을 가른다(peach/beach). 우리말은 'ㅁ/ㅂ'이 뜻을 가른다(물/불). 이렇게 한 소리만 달라 뜻이 갈리는 단어 짝을 **최소 대립쌍**이라 하며, 이것으로 그 언어의 음운을 가려낸다.

## 자음 체계 (19개)

자음은 공기가 발음 기관의 방해를 받고 나는 소리다. **조음 위치**(어디서 나는가)와 **조음 방법**(어떻게 나는가)으로 분류한다.

| 조음 방법 \ 위치 | 입술소리 | 잇몸소리 | 센입천장소리 | 여린입천장소리 | 목청소리 |
|---|---|---|---|---|---|
| 파열음 (예사/된/거센) | ㅂ ㅃ ㅍ | ㄷ ㄸ ㅌ | | ㄱ ㄲ ㅋ | |
| 파찰음 (예사/된/거센) | | | ㅈ ㅉ ㅊ | | |
| 마찰음 (예사/된) | | ㅅ ㅆ | | | ㅎ |
| 비음 | ㅁ | ㄴ | | ㅇ | |
| 유음 | | ㄹ | | | |

- **파열음·파찰음·마찰음**은 안울림소리, **비음·유음**은 울림소리다. (모음은 모두 울림소리)
- 예사소리(ㄱ) → 된소리(ㄲ) → 거센소리(ㅋ)로 갈수록 더 세고 거칠게 발음된다.

## 모음 체계 (21개)

모음은 공기가 방해 없이 나는 소리다. 발음 도중 입 모양이 변하지 않으면 **단모음**, 변하면 **이중모음**이다.

### 단모음 (10개)

혀의 앞뒤(전설·후설), 혀의 높낮이(고·중·저), 입술 모양(평순·원순)으로 나눈다.

| | 전설 모음 | | 후설 모음 | |
|---|---|---|---|---|
| | 평순 | 원순 | 평순 | 원순 |
| 고모음 | ㅣ | ㅟ | ㅡ | ㅜ |
| 중모음 | ㅔ | ㅚ | ㅓ | ㅗ |
| 저모음 | ㅐ | | ㅏ | |

> 'ㅟ, ㅚ'는 단모음이 원칙이나, 이중모음으로 발음함도 허용된다(표준 발음법 제4항). 실제로 많은 세대가 이중모음으로 발음한다.

### 이중모음 (11개)

**반모음**(ㅑ·ㅘ의 첫 부분처럼 짧게 미끄러지는 소리)과 단모음이 결합한 소리다.

- 반모음 'ㅣ(j)'계: ㅑ ㅒ ㅕ ㅖ ㅛ ㅠ
- 반모음 'ㅗ/ㅜ(w)'계: ㅘ ㅙ ㅝ ㅞ
- 하향 이중모음: ㅢ

## 운소 — 소리의 길이

자음·모음 외에 **소리의 길이**도 뜻을 구별한다(비분절 음운). 같은 글자라도 길게/짧게 내느냐로 의미가 갈린다.

- 눈[눈ː] 雪(내리는 눈) — 길게 / 눈[눈] 眼(신체) — 짧게
- 말[말ː] 言(언어) — 길게 / 말[말] 馬(동물) — 짧게
