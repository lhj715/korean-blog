## 음운이란

**음운**은 말의 뜻을 구별해 주는 소리의 가장 작은 단위다. '물'과 '불'의 뜻이 갈리는 것은 첫소리 'ㅁ'·'ㅂ'이 다르기 때문인데, 이렇게 뜻을 가르는 'ㅁ', 'ㅂ' 하나하나가 음운이다.

음운은 두 갈래다.

| 구분 | 내용 | 예 |
|------|------|----|
| 분절 음운 | 자음·모음. 소리마디로 나뉜다 | ㄱ, ㅏ |
| 비분절 음운(운소) | 소리의 길이·높낮이. 자음·모음에 얹혀 뜻을 구별 | 눈[눈ː]/눈[눈] |

## 음운과 음성 — 변이음

말소리는 두 차원에 있다. **음성**은 실제로 발음되는 물리적 소리이고, **음운**은 그 말을 쓰는 사람이 머릿속에서 하나로 인식하는 소리다.

- '바보[pabo]'에서 첫 'ㅂ'은 무성음 [p], 둘째 'ㅂ'은 유성음 [b]로 **물리적으로 다르게** 난다. 하지만 우리는 둘을 같은 'ㅂ'으로 느낀다.
- 이렇게 한 음운이 환경에 따라 다르게 실현된 소리들을 **변이음**, 서로 겹치지 않는 자리에 나타나는 이 관계를 **상보적 분포**라 한다.

> **최소 대립쌍** — 같은 자리의 한 소리만 달라 뜻이 갈리는 단어 짝(물/불, 발/팔/빨). 이것으로 그 언어의 음운을 가려낸다. 영어는 [p]/[b]가 음운이지만(pin/bin), 우리말에선 한 음운('ㅂ')의 변이음일 뿐이다.

## 소리가 나는 과정

말소리는 세 단계로 만들어진다.
1. **발동** — 허파에서 공기를 내보낸다.
2. **발성** — 목청(성대)을 지나며 떨면 **유성음(울림소리)**, 안 떨면 **무성음(안울림소리)**. 모음과 'ㄴ, ㅁ, ㅇ, ㄹ'은 울림소리다.
3. **조음** — 입안의 여러 기관(혀·입천장·입술)이 공깃길을 좁히거나 막아 구체적 소리값을 만든다.

공깃길이 **막히거나 좁아져** 방해를 받으면 **자음**, 방해 없이 나면 **모음**이다.

## 자음 체계 (19개)

자음은 **조음 위치**(어디서)와 **조음 방법**(어떻게)으로 나뉜다.

| 조음 방법 \ 위치 | 입술소리(양순) | 잇몸소리(치조) | 센입천장(경구개) | 여린입천장(연구개) | 목청(후음) |
|---|---|---|---|---|---|
| 파열음 (예사/된/거센) | ㅂ ㅃ ㅍ | ㄷ ㄸ ㅌ | | ㄱ ㄲ ㅋ | |
| 파찰음 (예사/된/거센) | | | ㅈ ㅉ ㅊ | | |
| 마찰음 (예사/된) | | ㅅ ㅆ | | | ㅎ |
| 비음 | ㅁ | ㄴ | | ㅇ | |
| 유음 | | ㄹ | | | |

- **조음 방법**: 파열음(공기를 막았다 터뜨림) · 파찰음(막았다가 좁혀 마찰) · 마찰음(좁은 틈으로 마찰) · 비음(코로) · 유음(혀 옆/굴림).
- **소리의 세기**: 예사소리(ㄱ) → 된소리(ㄲ) → 거센소리(ㅋ)로 갈수록 세진다. 이 **삼중 대립**이 국어 자음의 특징이다.
- 파열·파찰·마찰음은 안울림소리, 비음·유음은 울림소리.

## 모음 체계 (21개)

모음은 발음 도중 입 모양이 **변하지 않으면 단모음**, **변하면 이중모음**이다.

### 단모음 (10개)
혀의 **앞뒤**(전설·후설), 혀의 **높낮이**(고·중·저), **입술 모양**(평순·원순) 세 기준으로 나뉜다.

| | 전설 평순 | 전설 원순 | 후설 평순 | 후설 원순 |
|---|---|---|---|---|
| 고모음 | ㅣ | ㅟ | ㅡ | ㅜ |
| 중모음 | ㅔ | ㅚ | ㅓ | ㅗ |
| 저모음 | ㅐ | | ㅏ | |

> 'ㅟ, ㅚ'는 단모음이 원칙이나 이중모음 발음도 허용된다(표준 발음법 제4항). 실제로 많은 세대가 이중모음으로 내며, 'ㅔ/ㅐ'의 구별도 점차 사라지는 추세다.

### 이중모음 (11개)
**반모음**(ㅣ나 ㅗ/ㅜ를 아주 짧게 내며 미끄러지는 소리)과 단모음이 결합한 소리다.
- 'ㅣ(j)'계: ㅑ ㅒ ㅕ ㅖ ㅛ ㅠ
- 'ㅗ/ㅜ(w)'계: ㅘ ㅙ ㅝ ㅞ
- 하향 이중모음: ㅢ (단모음 뒤에 반모음)

## 운소 — 소리의 길이

자음·모음 외에 **소리의 길이**도 뜻을 구별한다(비분절 음운). 긴소리는 원칙적으로 **첫음절에서만** 인정된다.

- 눈[눈ː] 雪(내리는 눈) / 눈[눈] 眼(신체) · 말[말ː] 言 / 말[말] 馬 · 밤[밤ː] 栗(먹는 밤) / 밤[밤] 夜
- 둘째 음절 이하에선 짧아진다. (눈[눈ː] → 첫눈[천눈], 함박눈[함방눈])
