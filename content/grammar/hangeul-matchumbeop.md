## 총칙 — 세 가지 원칙

> **제1항** 한글 맞춤법은 표준어를 **소리대로 적되, 어법에 맞도록** 함을 원칙으로 한다.
> **제2항** 문장의 각 단어는 **띄어 씀**을 원칙으로 한다.
> **제3항** **외래어**는 '외래어 표기법'에 따라 적는다.

제1항의 두 축은 서로를 보완한다.

- **소리대로** — 발음 그대로 적는다. (구름, 나무, 하늘)
- **어법에 맞도록** — 뜻을 가진 부분(형태소)의 본모양을 밝혀 적는다.

→ '꽃'에 조사를 붙이면 발음은 [꼬치]·[꼬츨]·[꼳또]로 달라지지만, 표기는 **'꽃이·꽃을·꽃도'**로 형태를 고정한다. 그래야 뜻을 한눈에 알아본다. 소리대로만 적으면 '꼬치·꼬츨·꼳또'가 되어 같은 단어인 줄 모른다.

## 소리에 관한 것

- **된소리** — 한 단어 안 뚜렷한 까닭 없이 나는 된소리는 된소리로 적는다. (소쩍새, 어깨, 오빠, 가끔) 단, 'ㄱ·ㅂ' 받침 뒤의 된소리는 적지 않는다. (국수[국쑤], 갑자기)
- **'ㄷ' 소리 받침** — 'ㄷ'으로 소리 나도 'ㄷ'으로 적을 까닭이 없으면 **'ㅅ'**으로 적는다. (덧저고리, 핫옷, 무릇, 사뭇)
- **두음 법칙**
  - 한자어 첫머리의 '녀·뇨·뉴·니'는 '여·요·유·이'로 적는다. (女子→여자, 年歲→연세)
  - 한자어 첫머리의 '랴·려·례·료·류·리'는 '야·여·예·요·유·이'로, '라·래·로·뢰·루·르'는 '나·내·노·뇌·누·느'로 적는다. (良心→양심, 老人→노인)
  - 단어 첫머리가 아니면 본음대로. (改良→개량, 會社→회사)

## 형태에 관한 것

- **체언과 조사**는 구별하여 적는다. (떡이, 떡을, 떡에 — '떡'을 고정)
- **어간과 어미**도 구별하여 적는다. (먹다, 먹고, 먹어 — '먹-' 고정)
- **'-이'와 '-히'** — 부사를 만들 때, 분명히 '이'로 나면 '이', '히'로 나면 '히'로 적는다. (깨끗이·가만히, 솔직히)
- **접미사가 붙어 된 말** — 어간의 본뜻이 유지되면 원형을 밝혀 적는다. (길이, 믿음 / 본뜻에서 멀어지면 소리대로: 너비, 마중)

## 띄어쓰기

| 규정 | 내용 | 예 |
|------|------|----|
| 조사 | 앞말에 **붙여** 쓴다 | 꽃이, 학교에서**처럼**, 너**조차** |
| 의존 명사 | **띄어** 쓴다 | 아는 **것**, 먹을 **만큼**, 떠난 **지** 오래 |
| 단위 명사 | 띄어 쓴다 (순서·숫자 뒤는 붙임 허용) | 한 **개** / 2시 30분 |
| 수 | 만(萬) 단위로 띄어 쓴다 | 십이억 삼천사백오십육만 |
| 보조 용언 | 띄어 씀이 원칙, 붙임도 허용 | 꺼져 **간다** / 꺼져간다 |

> '지'·'데'·'만큼' 등은 의존 명사일 때 띄고, 어미일 때 붙인다. (간 **지** 오래 / 작은**지** 모른다)

## 사이시옷 (제30항)

합성어에서 사잇소리가 날 때 받친다. **세 조건**을 모두 따진다.

1. 합성어이고, **앞말이 모음으로 끝날 것** (촛불 ○ / '위층'은 'ㅊ' 거센소리라 사이시옷 안 씀)
2. 앞말·뒷말 중 하나 이상이 **고유어**일 것
3. 사잇소리(된소리화·'ㄴ' 덧남)가 실제로 날 것

- 뒷말 첫소리가 된소리로: 나무+가지 → **나뭇가지**[나무까지]
- 'ㄴ' 소리 덧남: 코+날 → **콧날**[콘날], 나무+잎 → **나뭇잎**[나문닙]
- **한자어 + 한자어**는 원칙적으로 안 씀. 예외 6개만: 곳간(庫間)·셋방(貰房)·숫자(數字)·찻간(車間)·툇간(退間)·횟수(回數)

## 자주 틀리는 맞춤법

| 틀림 | 맞음 | 비고 |
|------|------|------|
| 돼요/되요 | **돼요** / 안 **되**다 | '되어'로 풀리면 '돼' |
| 일찌기 | **일찍이** | |
| 며칠 / 몇일 | **며칠** | '몇 일'로 적지 않음 |
| 왠지 / 웬지 | **왠지** (왜인지) / **웬**일 | |
| 금새 | **금세** | '금시에'의 준말 |
| 어떻해 | **어떡해** / 어떻게 | |

> 표기가 맞는지·표준어인지는 [표준국어대사전](https://stdict.korean.go.kr/)에서 바로 확인할 수 있다.
