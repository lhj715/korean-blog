## 품사란

**품사**는 단어를 공통된 성질에 따라 묶은 갈래다. 세 가지 기준을 쓴다.

- **기능** — 문장에서 하는 역할 (가장 중심 기준): 체언·용언·수식언·관계언·독립언
- **형태** — 모양이 변하는가: 불변어 / 가변어
- **의미** — 어떤 뜻을 나타내는가: 명사·동사 등 9품사

국어의 단어는 **5언 9품사**로 정리된다.

## 5언 9품사

| 갈래(기능) | 품사 | 정의 | 예 |
|---|---|---|---|
| 체언 | 명사 | 사물·사람의 이름 | 하늘, 안창호 |
| | 대명사 | 이름을 대신 가리킴 | 나, 이것, 저기 |
| | 수사 | 수량·차례 | 하나, 첫째 |
| 용언 | 동사 | 동작·작용 | 살다, 먹다 |
| | 형용사 | 상태·성질 | 아름답다, 푸르다 |
| 수식언 | 관형사 | 체언을 꾸밈 | 새, 모든, 이 |
| | 부사 | 주로 용언을 꾸밈 | 잘, 매우 |
| 관계언 | 조사 | 체언 뒤에서 문법 관계 표시 | 이/가, 을/를 |
| 독립언 | 감탄사 | 감정·부름·대답 | 아, 어머나 |

## 하위 갈래

- **명사** — 보통명사/고유명사, 자립명사/**의존명사**(것·수·바: '먹을 **것**')
- **대명사** — 인칭(나·너·그) / 지시(이것·여기). 미지칭·부정칭·재귀칭(자기)
- **수사** — 양수사(하나·둘) / 서수사(첫째·둘째)
- **동사·형용사** — 동사는 현재형 '-ㄴ/는다'와 명령·청유가 되지만(먹는다/먹어라), 형용사는 안 된다(*예쁜다/*예뻐라).
- **관형사** — 성상(새·헌) / 지시(이·그·저) / 수(한·두·모든)
- **부사** — 성분 부사(성상·지시·부정: 매우·이리·안) / 문장 부사(양태·접속: 과연·그러나)
- **조사**
  - 격조사: 주격(이/가), 목적격(을/를), 보격(이/가), 관형격(의), 부사격(에/에서/로), 호격(아/야), 서술격(이다)
  - 접속조사: 와/과, 하고
  - 보조사: 은/는, 도, 만, 까지 — 특별한 뜻을 더함
- **감탄사** — 감정(아!) / 의지(자, 가자) / 입버릇(뭐, 음)

## 형태로 본 가변어 / 불변어

- **가변어** — 모양이 변하는 단어. **용언(동사·형용사)**과 **서술격 조사 '이다'**가 활용한다.
  예) 먹다 → 먹고, 먹으니, 먹어서 (어간 '먹-' + 어미 변화)
- **불변어** — 나머지(체언·수식언·독립언, 격조사 등).

> 같은 글자도 쓰임으로 품사가 갈린다. "**이** 사람"(관형사) / "철수가"의 '가'(조사) / "키가 **크다**"(형용사) vs "키가 **큰다**"(동사). 헷갈리면 [표준국어대사전](https://stdict.korean.go.kr/)에서 품사를 확인한다.
