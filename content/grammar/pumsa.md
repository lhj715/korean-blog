## 품사란

**품사**는 단어를 공통된 성질에 따라 묶은 갈래다. 세 가지 기준으로 나눈다.

- **형태** — 모양이 변하는가 (불변어 / 가변어)
- **기능** — 문장에서 하는 역할 (체언·용언·수식언·관계언·독립언)
- **의미** — 어떤 뜻을 나타내는가 (명사·동사 등 9품사)

국어의 단어는 **5언 9품사**로 정리된다.

## 5언 9품사

| 갈래(기능) | 품사 | 정의 | 예 |
|---|---|---|---|
| 체언 | 명사 | 사물·사람의 이름 | 하늘, 나무, 안창호 |
| | 대명사 | 이름을 대신 가리킴 | 나, 너, 이것, 저기 |
| | 수사 | 수량·차례 | 하나, 둘, 첫째 |
| 용언 | 동사 | 동작·작용 | 살다, 오다, 먹다 |
| | 형용사 | 상태·성질 | 아름답다, 푸르다 |
| 수식언 | 관형사 | 체언을 꾸밈 | 새, 모든, 이, 헌 |
| | 부사 | 주로 용언을 꾸밈 | 잘, 매우, 빨리 |
| 관계언 | 조사 | 체언 뒤에서 문법 관계 표시 | 이/가, 을/를, 의 |
| 독립언 | 감탄사 | 감정·부름·대답 | 아, 어머나, 예 |

## 형태로 본 가변어 / 불변어

- **가변어** — 모양이 변하는 단어. **용언(동사·형용사)**과 **서술격 조사 '이다'**가 활용한다.
  예) 먹다 → 먹고, 먹으니, 먹어서 (어간 '먹-' + 어미 변화)
- **불변어** — 모양이 변하지 않는 나머지. 체언·수식언·독립언과 격조사 등.

## 헷갈리는 품사 — 형태가 같아도 쓰임이 다르면 다른 품사

같은 글자라도 문장에서의 기능으로 품사가 갈린다.

- **이**: "**이** 사람" → 관형사 / "철수**가**처럼 쓰인 '이'(이/가)" → 조사 / "이를 어찌할꼬"의 '이' → 대명사
- **크다**: "키가 **크다**"(상태) → 형용사 / "키가 **큰다**"(자라다, 동작) → 동사

> 품사가 헷갈리는 단어는 [표준국어대사전](https://stdict.korean.go.kr/)에서 품사 표기를 확인할 수 있다.
