## 1. 종결 표현

문장을 끝맺는 방식으로, 말하는 이의 태도를 나타낸다.

| 종류 | 뜻 | 예 |
|------|------|----|
| 평서문 | 단순 진술 | 간다. |
| 의문문 | 물음 | 가니? |
| 명령문 | 행동 요구(동사만, 과거 ✕) | 가라. |
| 청유문 | 함께 하기 요청(동사만) | 가자. |
| 감탄문 | 느낌 표현 | 가는구나! |

> 의문문은 다시 **설명 의문문**(물음말 있음: 언제 가니?), **판정 의문문**(예/아니요: 지금 가니?), **수사 의문문**(대답 불요, 서술·명령 효과)으로 나뉜다.

## 2. 높임 표현

대상을 높이거나 낮추는 **문법적** 체계. (어휘만으로 높이는 다른 언어와 달리 국어는 문법 범주로 발달했다) 누구를 높이느냐로 셋이다.

### 상대 높임 — 듣는 이를 높임 (종결 어미)
| 격식체 | 비격식체 |
|--------|----------|
| 하십시오체 (-습니다) | 해요체 (-아요) |
| 하오체 (-오) | 해체/반말 (-아) |
| 하게체 (-네) | |
| 해라체 (-다) | |

### 주체 높임 — 주어를 높임
- 선어말어미 **'-(으)시-'**, 조사 **'께서'**, 특수 어휘(계시다·주무시다·잡수시다)
  예) 아버지**께서** 신문을 보**신**다.
- **간접 높임** — 주어와 관련된 대상(말씀·손가락 등)을 높일 땐 특수 어휘 대신 '-시-'를 쓴다. (말씀이 **있으시겠습니다** / *계시겠습니다)

### 객체 높임 — 목적어·부사어의 대상을 높임
- 특수 어휘 **모시다·드리다·뵙다·여쭙다**, 조사 **'께'**
  예) 나는 부모님을 **모시고**, 선생님**께** 선물을 **드렸다**.

## 3. 시간 표현 (시제)

**발화시**(말하는 때)와 **사건시**(일이 일어난 때)의 앞뒤로 나눈다.

| 시제 | 표지 | 예 |
|------|------|----|
| 과거 | -았/었-, 회상 -더-, 관형사형 -(으)ㄴ/-던 | 먹**었**다 / 가**더**라 |
| 현재 | -ㄴ/는-, 관형사형 -는 | 먹**는**다 |
| 미래 | -겠-, -(으)ㄹ | 먹**겠**다 |

> 진행·완료를 나타내는 **동작상**도 있다. 먹**고 있**다(진행) / 먹**어 버렸**다(완료).

## 4. 피동·사동 표현

- **피동** — 주어가 남의 행동을 **당함**.
  - 파생적 피동: 접미사 -이/히/리/기- (잡**히**다) / 통사적 피동: '-아/어지다', '-게 되다'
- **사동** — 주어가 남에게 동작을 **시킴**.
  - 파생적 사동: 접미사 -이/히/리/기/우/구/추- (입**히**다) / 통사적 사동: '-게 하다'
  > 파생적 사동은 직접·간접 두 의미가, 통사적 사동('-게 하다')은 주로 간접 의미가 된다.

## 5. 부정 표현

- **'안' 부정** — 단순·의지 부정. (안 먹는다 / 먹지 않는다)
- **'못' 부정** — 능력 부족·외부 원인. (못 먹는다 / 먹지 못한다)
- 부사로 짧게 쓰면 **짧은 부정**, '-지 않다/못하다'로 길게 쓰면 **긴 부정**.
