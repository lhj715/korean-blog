## 1. 종결 표현

문장을 끝맺는 방식으로 화자의 태도를 나타낸다.

| 종류 | 뜻 | 예 |
|------|------|----|
| 평서문 | 단순 진술 | 간다. |
| 의문문 | 물음 | 가니? |
| 명령문 | 행동 요구(동사만, 과거 ✕) | 가라. |
| 청유문 | 함께 하기 요청(동사만) | 가자. |
| 감탄문 | 느낌 표현 | 가는구나! |

> **의문문의 갈래**: 설명 의문문(물음말 있음 — "언제 가니?"), 판정 의문문(예/아니요 — "지금 가니?"), 수사 의문문(대답 불요, 서술·명령 효과 — "누가 모르겠니?"). 명령·청유는 **동사**에만 쓰이고 **과거 시제와 안 어울린다**.

## 2. 높임 표현

대상을 높이거나 낮추는 **문법적** 체계. (어휘로만 높이는 다른 언어와 달리 국어는 문법 범주로 발달) 누구를 높이느냐로 셋이다.

### 상대 높임 — 듣는 이를 높임 (종결 어미)
| 격식체 | 비격식체 |
|--------|----------|
| 하십시오체 (가십니다) | 해요체 (가요) |
| 하오체 (가오) | 해체/반말 (가) |
| 하게체 (가네) | |
| 해라체 (간다) | |

### 주체 높임 — 문장의 주어를 높임
- 선어말어미 **'-(으)시-'**, 조사 **'께서'**, 특수 어휘(계시다·주무시다·잡수시다·돌아가시다)
- 예) 아버지**께서** 신문을 보**신**다.
- **간접 높임**: 높일 대상의 신체·소유물·말 등을 높일 땐 특수어휘 대신 '-시-'를 쓴다. (할머니께서 귀가 **밝으시다** / 말씀이 **있으시겠습니다**(○) / *계시겠습니다(✕))

### 객체 높임 — 목적어·부사어의 대상을 높임
- 특수 어휘 **모시다·드리다·뵙다·여쭙다**, 조사 **'께'**
- 예) 나는 부모님을 **모시고**, 선생님**께** 선물을 **드렸다**.

## 3. 시간 표현 (시제)

**발화시**(말하는 때)와 **사건시**(일이 일어난 때)의 앞뒤로 나눈다.

| 시제 | 표지 | 예 |
|------|------|----|
| 과거 | -았/었-, 회상 -더-, 관형사형 -(으)ㄴ/-던 | 먹**었**다 / 가**더**라 / 먹**은** 밥 |
| 현재 | -ㄴ/는-, 관형사형 -는 | 먹**는**다 / 먹**는** 밥 |
| 미래 | -겠-, -(으)ㄹ | 먹**겠**다 / 먹**을** 밥 |

> '-겠-'은 미래 외에 **추측·의지·가능**도 나타낸다(내일은 춥겠다/내가 하겠다/나도 들겠다). **동작상**: 진행(먹**고 있**다)·완료(먹**어 버렸**다).

## 4. 피동 · 사동 표현

- **피동** — 주어가 남의 행동을 **당함**.
  - 파생적: 접미사 '-이/히/리/기-' (잡**히**다, 열**리**다) / 통사적: '-아/어지다', '-게 되다' (이루**어지**다)
  - 주의: **이중 피동**은 잘못된 표현. (잊혀지다 → 잊히다, 쓰여지다 → 쓰이다)
- **사동** — 주어가 남에게 동작을 **시킴**.
  - 파생적: 접미사 '-이/히/리/기/우/구/추-' (입**히**다, 깨**우**다) / 통사적: '-게 하다'
  - **의미차**: 파생적 사동은 직접·간접 두 뜻(엄마가 아이에게 옷을 입혔다=직접/시킴), 통사적 사동('입게 하다')은 주로 **간접**(시키기만).

## 5. 부정 표현

- **'안' 부정** — 단순 부정·의지 부정. (안 먹는다 / 먹지 않는다)
- **'못' 부정** — 능력 부족·외부 원인. (못 먹는다 / 먹지 못한다)
- 부사로 짧게 = **짧은 부정**('안/못'+용언), '-지 않다/못하다' = **긴 부정**.
- **중의성**: "학생이 다 안 왔다"는 '전부 안 옴/일부만 옴' 두 해석이 가능하다.

## 시험 포인트

- 한 문장에서 **주체·객체·상대 높임이 동시에** 실현된 양상 분석(어머니께서 할머니께 책을 드리셨습니다).
- 간접 높임의 잘못된 사용("주문하신 커피 나오셨습니다" = 사물 높임 오류).
- 이중 피동·잘못된 사동 가려내기, 부정문의 중의성.
