# 독립 검토 21~25번 (1차)

방법: 쪽 그림(8·9쪽)과 해설지(2~3쪽)로 먼저 풀고 세트와 대조.

## 직접 푼 결과
정답 21=①, 22=②, 23=①, 24=④, 25=②. 세트 answer 와 같음. 각 선지 판정도 해설지와 일치(해설지에 없는 선지 없음).

## 확인한 것
- 프로그램 검사(`세트_검사.py`) 합격.
- 굵은 글씨: `get_texttrace` type=1 겹침(Haansoft Batang) 글자를 줄별로 뽑아 세트 bold 와 대조.
  - (가): 넉넉지 않 / 서러운 줄 모 / 새 술 / 미끼 없는 낚싯대 / 어조(魚鳥) / 휘파람 / 달(1번뿐) / 흰 눈 / 정사 / 돌보시는: 일치.
  - (나): 죄명 / 극중일월(棘中日月) / 자식 / 은덕 / 두루미 / 헛소리 / 조개 등 / 바다 / 세상의 넓은 곳: 일치.
  - (다): 첫 문단의 «개해» 줄에서 «개»(첫째, «개는 해를 보면»)와 «해»(첫째)만 굵고, 다음 줄은 «해를 보고 짖는»(«개» 안 굵음), «하늘»(첫째 «하늘만»)이 굵음: nth 없는 첫째 출현과 일치. «악을 항상 행하는 »+«것»까지 굵음(type=1 줄 «것구름»에서 «것» 확인): 세트와 일치. «구름» 단독, «신하가 크게 걱정하는», «악이 일상적이지 않게», «군왕이 한번 마음을 바꾸고 옮기», «올바름을 보고 짖는 개들의 소리», «이 세상»: 일치. 빠진 굵은 글씨·넘치는 굵은 글씨 없음. 선지·발문·<보기>에는 굵은 글씨 없음(그림 확인).
- 문단 경계: (다) 세 문단 모두 들여쓰기 시작(평소에 / 촉나라의 기후가 / 오호라), 사이에 (중략). 일치.
- 밑줄: PDF 선 그리기 목록에서 발문 «않은»(22·24·25) 3곳뿐, 세트의 stem_underlines 와 같음. 지문 밑줄 없음.
- [A]~[E]: 왼쪽 괄호 선 y좌표로 줄 수 확인(A 2줄, B 3줄, C 4줄, D 4줄, E 2줄). ranges 의 text 와 일치.
- <제N수> 줄·각주·출처 note 순서: 그림과 같음.
- 이유 문장: em dash 없음, «해설지는» 메타 문구 없음, 지문·해설지 밖 내용 없음.

## 고치면 좋은 것
- 21③ 근거(산새 노래하며 지저귀고): «음성상징어 없음» 판단이라 결정 문장이 없는 선지다. 지금 근거는 «산새 지저귀고» 장면이 음성상징어가 아님을 보이는 용도로 적절하다. 그대로 두어도 된다.
- 21④ 근거는 21① 의 (가) 근거(산수의 즐거움을 나밖에 뉘 아는가)를 재사용하나, 이유 문장이 «설의이지 묻고 답이 아님»으로 그 문장의 쓰임을 설명하므로 허용 범위다.
- 23⑤ 이유의 «(나)의 바다는 유배지의 좁은 처지와 관련된 소재»는 약간 해석이 들어갔다. 인용한 «섬은 조개 등만 하고 바다는 일배수 같아»(좁음 강조)와는 어긋나지 않는다. 원하면 «좁은 공간을 나타내는 소재»로 줄이면 더 안전하다.
