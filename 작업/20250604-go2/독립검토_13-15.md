# 독립 검토 (1차): 세트_13-15.json (2025-06 고2 13~15번, 문법)

검토 방법: 쪽 그림(문제 5·6쪽)과 해설지로 먼저 풀고, 세트 파일과 대조. PDF 텍스트층(`get_texttrace`, `get_drawings`)으로 굵은 글씨·밑줄 선을 직접 쟀다. 프로그램 검사(`세트_검사.py`)는 합격.

## 스스로 푼 답
- 13번 ③ (㉢ '누며' = 현대어 '누우며', 높임 특수 어휘 아님). 14번 ① ('언니가 만든' 과거 + '은사이신' 서술격 조사 현재). 15번 ② ('주고'·'갔다' 모두 본용언이라 띄어 써야 하므로 '적절함'이 틀림).
- 정답표(③·①·②)와 해설지, 세트 파일의 answer 모두 일치. 발문이 «적절하지 않은 것»(13·15)이라 정답 선지 판정이 부정(부적절)인 것도 맞다. 14번은 «적절한 것» 이라 정답이 적절.
- 선지별 판정 15개(13번 5, 14번 5, 15번 5) 모두 내 판단과 같다. 해설지 인용 15개는 그 문항 해설에 글자 그대로 있다.

## 직접 잰 것
- 굵은 글씨(type 0+1 겹침, 같은 쪽 보통 글자는 type=0 전용 확인):
  - 13번 «[현대어 풀이]»: '['·']' 는 type=1, '현대어'·'풀이' 는 0+1 → 괄호 포함 굵음. 세트 `bold: ["[현대어 풀이]"]` 일치. 같은 쪽에 13번 안의 다른 굵은 글씨 없음.
  - 14번: 6쪽에서 14번 구역(y 171~520)에 type=1 글자 없음 → 굵은 글씨 없음, 일치.
  - 15번: «학생» + «:»(type 1, 129,588), «선생님» + «:»(1, 140,623) → 이름과 콜론 모두 굵음, «[학습 과제]» 괄호 포함 굵음(117~168,754). 세트 `bold: ["학생:"]`, `["선생님:"]`, `["[학습 과제]"]` 일치. 표 머리 «과제»(122,880)는 type=0 이라 굵지 않음, 세트도 굵게 안 함.
- 밑줄 선(PDF 가로선) 대 세트:
  - 13번 ㉠ 615~688(出家(출가)ᄒᆞ샤), ㉡ 648~669(쑤믈), ㉢ 498~529(누볏며), ㉣ 460~481(드를), ㉤ 674~716(니ᄅᆞ쇼셔). 낱말 위치(`get_text('words')`)와 맞고, 세트의 ㉠~㉤ 범위와 같다. 오려 낸 그림 `그림_13-15_13_보기본문.png` 에도 다섯 밑줄과 ㉠~㉤ 기호가 모두 보인다.
  - 15번 ㉠ 227~284(읽어 주었다), ㉡ 258~300(주고갔다), ㉢ 228~300(덤벼들어보아라), ㉣ 166~238(읽어도보았으나), ㉤ 289~351(올 듯도 하다). 쪽 그림에서 마침표는 밑줄 밖이다 → 세트가 마침표를 뺀 것이 맞다. 13·15번 발문 «않은» 밑줄도 쪽 그림에서 확인되고 세트에 `stem_underlines: ["않은"]` 있음.

## 반드시 고칠 것
1. **13번 출처 줄(`n1`)이 화면에서 «- -월인석보-(1449) -» 로 깨진다.** 원본은 «-『월인석보』(1449)-» (쪽 그림 확인). 데이터 text 는 `- 월인석보(1449) -` 로 『』 자리에 PUA(U+F000)가 들어 있고, `도구/기출_렌더.py` 48행이 U+F000 을 «PUA 하이픈» 으로 보고 «-» 로 바꾸기 때문이다(미리보기 HTML 직접 확인: `<p class='xm-note xm-right'>- -월인석보-(1449) -</p>`). 독자에게 보이는 글자 오류이므로 게시 전에 고쳐야 한다. 방법은 작업자가 도구 한계로 보고하고 주 세션이 처리(예: 이 항목만 『 』 를 보이게 하는 처리 또는 note 를 그림으로 대체). 같은 U+F000 이 다른 게시 회차의 『』·「」 자리에도 있는지 주 세션이 한 번 훑어볼 것.
