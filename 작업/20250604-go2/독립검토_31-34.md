## 확인한 것 (이상 없음)
- 문단 경계: 12쪽에서 따옴표 줄마다 줄머리가 들여쓰기(x≈175, 연속 줄은 x≈162)로 시작해 새 문단이 맞다. «하산 아저씨는 한숨을 내쉬었다.»도 새 문단. «그의 가슴팍은 단단하지 않았다.»는 들여쓰기가 없어 p23의 이어진 줄이 맞다. 11쪽의 p2~p4, p6~p9 문단 시작도 쪽 그림과 같다.
- p9 → p10 쪽 경계 `cont:true`: 11쪽 마지막 줄 «…문을 열지 못하고»에서 12쪽 «오래도록…»으로 이어지는 한 문단이므로 맞다.
- [A] range: 쪽 그림의 꺾쇠가 «내 지도에서 한국인은…» 첫 줄부터 «…타고 돌아다녔다.» 끝줄까지, 즉 p8 하나만 감싼다. `ranges` 와 일치.
- boxed «완성된 지도»: 11쪽 p9 첫 줄의 «완성된 지도»에만 네모 테두리가 있고, 12쪽 p10의 «완성된 지도를 놓고»에는 없다(데이터도 p9에만 달려 있음). 33번 발문의 «완성된 지도»도 네모 → `stem_boxed` 맞다.
- 굵은 글씨(`get_texttrace` type 0+1 겹침, 글꼴 Haansoft Batang/Dotum, 쪽 그림 확대):
  - 11쪽 type=1 구간: «[앞부분의 줄거리]», «두려워하는», «자신들/과 /다르다», «선택», «얼굴»(p7 첫 번째 «얼굴은»의 얼굴), «전형적인 한국인의 얼굴». `bold` 목록과 정확히 같고, 두 번째 «얼굴»은 «전형적인 한국인의 얼굴» 안에 포함돼 nth 문제 없음.
  - 12쪽 type=1 구간: «넓은 가슴팍에 품»(뒤의 «았다» 보통), «더 많은 이야기»(뒤 «를» 보통), «기다렸다»(마침표 «.» 는 type 0 전용, 보통), «역사가 날염된 흉터»(마침표 보통). 데이터와 일치. p24의 «역사가 날염*된»은 type 0 만이라 보통이 맞다.
  - 발문 «않은» 밑줄: 32번·34번 쪽 그림에 밑줄이 있고 `stem_underlines:["않은"]` 로 등록돼 있다. 31·33번 발문에는 밑줄 없음(맞다).
- 각주 note 3개, 출처 줄, <보 기> 상자(34번, 한 문단), 각주 별표 위치(어섯눈·금식 기간·날염)는 쪽 그림과 같다.

## 반드시 고칠 것
1. 34번 ⑤ (basis 자체): 이유의 결론 «이들이 상처를 입고 살아온 사회적 약자임»을 받치는 근거가 빠져 있다. 인용된 p24(«네 흉터는 그냥 흉터가 아니란다», «내 몸의 모든 흉터들 역시 내 개인사가 날염된 것들이지»)는 흉터가 삶의 기록이라는 말일 뿐, «사회적 약자»·«차별받음»은 보이지 않는다. 결정적인 문장은 p1(줄거리 «차별받으며 살아 온 고아인 나»)과 p2(«자신들과 다르다는 사실 하나뿐») 쪽에 있다. `evidence` 에 p1 의 해당 문장(예: «차별받으며 살아 온 고아인 나는 얼굴을 스크랩하는 취미가 있다»)을 추가하고, 이유도 그 근거에서 «차별받아 온 인물들»로 이어지게 고칠 것. (p24 를 2개 인용하는 것보다 p1 인용이 결정적이다.)
