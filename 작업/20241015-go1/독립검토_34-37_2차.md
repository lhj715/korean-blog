## 반드시 고칠 것 1: p8 굵은 글씨 분리 — 반영됨
- 세트: `bold: ["모두 살생한다는 점", "똑같"]` 두 항목.
- PDF `get_texttrace`(12쪽): «모두 살생한다는 점» type 0+1 겹침(x 465~559), 사이의 «은 »(x 558~572)는 type 0 만, «똑같» type 0+1(x 574~595). 
- 500dpi 확대 그림(`_임시\z2_p8.png`): «점» 굵음, «은» 얇음, «똑같» 굵음, «습니» 얇음. 세트의 분리와 정확히 일치한다. 같은 낱말 반복이 없어 nth 불필요.
