# 독립검토 38~41번 (2024-10 고1, 2차)

검토 방법: 1차 «반드시 고칠 것» 3건이 세트 파일에 어떻게 반영됐는지 원문(문제 PDF 텍스트·쪽 그림 확인은 1차 결과 유지)과 해설지로 직접 판단했다. 세트 전체를 다시 훑어 다른 부분이 바뀌지 않았는지 보았다. `도구\세트_검사.py` 는 합격(해설지에 없는 선지 8개 안내, 1차와 같은 수).

## 1차 반드시 고칠 것 반영 확인
1. **40번 ⑤ (반영됨, 타당).** 근거가 p8 «그 다음날은 수유리 쪽으로 … 어디서고 구십만원짜리 독채 전세는 구경도 못 하고» 로 늘었고 p7 «나는 다시 버스를 타고 이 아름다운 신흥 주택가에 앙심을 품고 떠났다.» 가 추가됐다. 이유(사흘 동안 다녀도 독채 전세는 구경도 못 했고, 복덕방 영감의 말 때문이 아니다)가 인용 안에서 받쳐진다. 1차가 권한 «불과했다» 까지는 아니지만 이유가 쓰는 «구경도 못 하고» 가 인용에 들어 있어 충분하다. 지문에 영감이 «구십만원이면 전세방을 구할 수 있다» 고 말하는 대목이 없다는 점도 원문(p9 «반응은 괜찮았다. 사뭇 굽실대기까지 했다.»)으로 다시 확인했다.
2. **40번 ③ (반영됨, 타당).** p1 «작은 것 한 장도 못 되는 돈 갖고 이 바닥에서 독채 전세를 얻겠다고?» 가 p2 앞에 추가돼 이유(구십만원이 작은 것 한 장도 안 된다며 웃는다)와 맞는다. 순서도 p1, p2 로 지문 순서다.
3. **38번 ① (반영됨, 타당).** 근거가 p7 «나는 그들에게 완전히 잊혀졌다.»(1인칭 서술)와 «나는 다시 버스를 타고 … 앙심을 품고 떠났다.» 로 바뀌었다. 이유(1인칭 시선, 여러 인물의 내적 독백 없음)를 받친다. 인용은 p7 문단 안에 글자 그대로 있다.

## 다른 부분 변경 여부
- 정답: 38 ④, 39 ②, 40 ②, 41 ⑤ 그대로이고 정답표·해설지와 일치. 선지별 판정·basis(자체 8개, 해설지 12개)도 1차와 같다.
- 굵은 글씨(12곳 + 40번 «선생님:»), ㉠~㉤ 밑줄, 39·41번 발문 «않은» 밑줄, 문단 구분(p1~p31)은 1차에서 확인한 상태 그대로이며 검사기(B1·B3·C3 포함)가 합격한다.
- 해설지 인용(39번 5개, 40번 ②, 41번 5개)은 변경 없고 해당 문항 해설에 글자 그대로 있다. 이유에 em dash 와 «해설지는…» 문구 없음.
