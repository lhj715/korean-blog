방법: 8~9쪽 그림과 해설지 2~3쪽을 먼저 보고 풀이(22⑤, 23⑤, 24①, 25④)한 뒤 세트 파일 전체를 대조했다. 프로그램 검사 «합격». 미리보기 HTML(`_임시\미리_22-25.html`) 생성 확인.

## 1차 지적 반영 확인
1. 25④ 이유 «2의 4제곱, 곧 16배»로 고침. 2^4=16, 사실 맞음. 원본 8쪽 3문단 «2⁴배» 와 일치. `explanation_quote` 는 해설지 글자(«24배») 그대로 유지돼 E3 통과.
2. 25④ 근거에 결정 문장(p3 끝 «전체 계산량은 24배가 된다»)과 표의 A·B 10km, C·D 20km/8km 행 추가됨.
3. 3문단 p3 `"sup":["2|4"]`: 미리보기 HTML 에서 «…전체 계산량은 2</span><span class="xm-sup …">4</span>배가 된다» 로 «4» 만 위첨자 span 으로 그려지고, CSS `.xm-sup{vertical-align:super;font-size:.75em}` 가 있다. 원본 쪽 그림의 2⁴ 모양과 같다. 근거 꼬리표가 붙은 위첨자도 정상(span 에 xm-ev 클래스 동반). 브라우저 창으로는 열지 못했으나(파일 접근 거부) HTML·CSS 로 확인.
4. 25② 근거에 «수평 방향의 공간분해능10km10km», «…20km8km» 추가됨. 이유(B 10÷2=5초 > 8초라 재설정, D 8÷2=4초 ≥ 3초라 유지)와 연결되고 해설지와 같다.
