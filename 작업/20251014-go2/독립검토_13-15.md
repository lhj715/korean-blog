# 독립 검토 13~15번 (1차)

스스로 푼 결과(쪽 그림 5·6쪽, 해설지): 13번 ②(읽히기는 피동사), 14번 ①(많은의 ㅎ은 모음 어미 앞에서 탈락), 15번 ③(잇ᄂᆞ뇨 / 그러터녀 / 求ᄒᆞᄂᆞᆫ다). 세트 파일의 정답·선지별 판정 15개 모두 일치. 프로그램 검사: 합격.

## 확인한 것
- 13번 `table_border`: 표 칸 선(x 441.6~756.3, 폭 315pt 가로선, 표 전체 테두리)이지 선지 글에 그어진 밑줄이 아님. 쪽 그림 확대로도 ③⑤ 문장에 밑줄 없음. 건너뛴 것이 맞다.
- 13번 stem 은 비지 않음(`<학습 활동>을 수행한 결과로 …`). 상자 라벨 «학습 활동»과 안내문·주머니 그림·표 머리 구성이 원본과 같다.
- 굵은 글씨(get_texttrace type 0+1 겹침 + 1200dpi 아닌 300dpi 확대로 직접 확인): 14번 «선생님:»(콜론까지), 15번 «선생님:»·«학생:»(콜론까지)·«[학습 활동]» 모두 굵음. 같은 쪽 보통 글자(type 0 전용)와 비교해도 굵다. 데이터와 일치.
- 15번 옛한글: 예문 2·3줄 display_image 는 원본(㉡·㉢ 밑줄·기호 포함)과 같고, 선지 PUA 그림 a=ᄂᆞ, b=ᄒᆞ, c=ᄂᆞᆫ 이 선지 1~5의 위치(잇ᄂᆞ, 求ᄒᆞᄂᆞ, 求ᄒᆞᄂᆞᆫ)에 맞게 배치됨. 예문 1 빈칸 ㉠ 은 원본 밑줄 위 기호와 같다.
- 해설지에 없는 선지: 없음(15개 모두 해설지 문장이 있고 `explanation_quote` 가 그 문항 해설에 글자 그대로 있음).
- 이유 문장에 «해설지는…» 메타 문구·em dash 없음. 지문(보기·그림) 밖 내용은 해설지가 말한 문법 설명 수준이다.

## 반드시 고칠 것
없음.

## 고치면 좋은 것
1. 15번 stem `<보기>의 ㉠~ ㉢에` 에 `~` 뒤 공백이 있다. 원본 그림은 «㉠~㉢» 로 붙어 있다(PDF 텍스트층에는 공백이 있어 검사기는 무시). 화면 충실도상 `㉠~㉢` 이 낫다.
2. 14번 ① 근거 인용(교체·탈락·축약 문장)은 결정 문장이 아니다. <보기>에 «모음 앞 탈락»을 말한 곳이 없으므로 이 선지는 사실상 해설지 판단에 기댄다. 인용을 그대로 두어도 판정은 맞으나, 필요하면 `basis` 를 유지한 채 이유 문장 설명을 보강하는 정도면 충분하다.
3. 15번 선지 그림 c(ᄂᆞᆫ) 오른쪽 끝에 다음 글자 획 조각이 살짝 보인다. 우측 경계를 0.5pt 줄이면 깔끔하다.
