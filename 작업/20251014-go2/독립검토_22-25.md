# 독립 검토 1차: 세트_22-25.json (22~25번, 2025-10 고2)

검토 방법: 문제 8~9쪽을 그림(130dpi)으로 렌더해 스스로 풀고(22⑤, 23⑤, 24①, 25④), 해설지 2쪽의 22~25번 해설과 대조한 뒤 세트 파일을 열었다. 프로그램 검사(`세트_검사.py`)는 «합격». 정답(5, 5, 1, 4)·선지별 판정 20개 모두 내 풀이와 해설지에 일치한다. 해설지 없는 선지는 없다(20개 모두 해설지에 문장이 있고 `basis:"해설지"`, 사실 맞음).

## 확인한 것(문제 없음)
- 지문 6문단 경계: 쪽 그림의 들여쓰기 첫 줄과 일치(대기는 / 모의 영역은 / 공간분해능과 / 모의 영역의 대기를 / 상단 경계에서는 / 측면 경계에). 5문단은 왼쪽 단 끝에서 오른쪽 단으로 이어지는 한 문단으로 맞다.
- 굵은 글씨: 8·9쪽 `get_texttrace` type=1 은 안내문(`[22~25]`, `[26~30]`)·문항 번호·`[갑 연구소]`/`[을 연구소]`(표 그림 안)뿐이다. 지문·발문·선지·<보기> 본문에는 굵은 글씨가 없다. 세트에 `bold` 없음이 맞다.
- 네모 글자: 4문단 «경계 조건», 24번 발문 «경계 조건» 둘 다 쪽 그림에 네모가 있고 세트에 `boxed`(p4), `stem_boxed`(24번)로 반영돼 있다.
- 밑줄: 22·23·25번 발문 «않은» 밑줄(`stem_underlines`) 맞다. 24번 발문은 «않은» 없이 «가장 적절한 것» 이라 밑줄 없음이 맞다. 지문·선지에 다른 밑줄 없음.
- 그림 글자 대조: 23번 메모 그림(`그림_22-25_23_메모.png`)은 «수치예보는? / 대기 상태를 모의하고 기상 현상을 예측하는 일이다. / ㉠ 빈칸 / * ‘모의한다’는 것의 의미는? ㉡ / 수치예보 모델의 준비 과정은? / 모의 영역 설정(㉢) → 격자 단위로 세분화(㉣) → 조건 설정(㉤)» 로 pdf_text·alt 와 글자 단위로 일치, 상자 잘림 없음. 25번 표 그림은 갑 연구소(A·B)·을 연구소(C·D) 두 표의 숫자 16개(10km/10km, 80/50km, 80/100층, 8/8초, 20/8km, 80/40km, 40/80층, 8/3초) 모두 pdf_text·alt 와 일치.
- 선지 풀이 재계산: 25② B 10km÷2km/s=5초(<8초, 재설정), D 8÷2=4초(≥3초, 유지) 맞음. 25③ B 50km, D 40km 모두 80km 미만 → 감쇠층 맞음. 25⑤ 맞음.

## 반드시 고칠 것
1. **25번 ④ 이유의 «24배» (오해 소지).** 원본 3문단 끝과 해설지는 «전체 계산량은 2의 4제곱배(2⁴=16배)» 이다. 8쪽 쪽 그림과 텍스트층(위첨자 «4», 작은 글씨·위로 올라간 y)으로 확인했다. 현재 이유는 «전체 계산량은 24배가 된다», «현재의 24배가 된다» 로 읽혀 학생이 «스물네 배» 로 오해한다. 선지가 «4배» 라서 «24배(스물네 배)» 도 틀렸다는 점은 같지만 정답 근거로는 «16배» 여야 한다. 이유를 «2의 4제곱, 곧 16배» 꼴로 고친다(`explanation_quote` 는 해설지 텍스트층 글자 그대로 «24배» 를 유지해야 검사 통과).
2. **25번 ④ 근거 인용에 결정 문장이 없다.** 현재 근거는 «두 배로 높이면 ... 각각 두 배로 높인다»(p3 앞 문장)와 표의 C 수평 해상도뿐이다. 계산량 값을 말하는 문장 «그러면 3차원 공간의 세 축과 시간 차원에서 각각 계산량이 두 배로 증가하게 되어, 전체 계산량은 24배가 된다» (p3 끝)가 근거에 빠졌다. 이 문장을 `evidence` 에 추가한다. 표에서 A의 «수평 방향의 공간분해능10km10km» 도 함께 넣으면 «A와 같아지도록» 의 근거가 완성된다.

## 고치면 좋은 것
3. **3문단 본문 «24배» 표기(도구 한계).** 지문 본문도 위첨자 «4» 가 일반 글자로 붙어 «24배» 로 보인다. 현재 데이터 구조에 위첨자 필드가 없어 텍스트층 그대로 둔 판단은 B1 검사 규칙상 맞다. 다만 사이트 화면에서는 «24배» 로 보이므로 주 세션이 도구에 위첨자 지원(예: `"sup":["4"]` 로 «2⁴배» 표시)을 넣거나, 그 전까지 이 한계를 CLAUDE.md «알려진 화면 한계» 에 적어 두는 것을 권한다. 데이터 쪽 수정은 불필요.
4. **25번 ② 근거 보강.** 현재 근거는 시간분해능 행(8초8초 / 8초3초)뿐이다. 판정의 핵심인 «수평 방향의 공간분해능10km10km», «…20km8km»(B 10km, D 8km)를 표 인용으로 추가하면 이유(10km÷2=5초, 8km÷2=4초)와 근거가 연결된다.
5. 23번 ①~④ 의 근거 인용 중 그림 쪽 인용(«대기 상태를 모의하고…», «모의 영역 설정» 등)은 정답 판단의 본질이 아닌 위치 표시용이다. 문제는 아니고, 지문 인용이 결정 문장이라 통과 수준이다.
