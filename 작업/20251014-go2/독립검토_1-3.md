# 독립 검토 1차: 세트 1~3번 (2025-10 고2, 화법 발표)

방법: 세트 파일을 열기 전에 1쪽 그림으로 스스로 풀고, 그다음 해설지·세트 파일과 대조했다. 프로그램 검사 `세트_검사.py` 는 «합격» (해설지에 없는 선지 4개: 1번 ①②③⑤ 는 아래에서 직접 확인).

## 스스로 푼 결과
- 1번 ④ (3문단 «이게 어떻게 가능한 일일까요?» 뒤 스스로 답함). 정답표·세트와 일치.
- 2번 ④ (자료 3은 암컷이 수컷으로 변하며 큰 점이 생기는 변화일 뿐 몸 크기를 바꾼다는 말은 없음). 일치.
- 3번 ⑤ (의문을 제기한 사람은 학생 3뿐, 학생 1은 «더 찾아봐야겠어»). 일치.

## 확인한 것
- 지문 5문단: 쪽 그림의 들여쓰기(안녕하세요 / 첫 번째로 / 다음으로는 / 마지막으로 / 지금까지)와 p1~p5 경계 일치. 글자·띄어쓰기 일치.
- 밑줄 ㉠㉡㉢: PDF 선 좌표 (141.0~161.7 / 111.5~132.2 / 333.6~354.3, 각 20.7pt)가 «자료» 두 글자 폭과 같고 기호 ㉠㉡㉢ 는 선 밖. 세트의 `text:"자료"` 가 맞다.
- 발문 «않은» 밑줄: 2번 (509.9~530.7), 3번 (520.4~541.1) 선이 있고 두 글자 폭. 세트의 `stem_underlines` 맞다. 1번 발문과 선지에는 밑줄 선이 없고 세트도 없다.
- 3번 <보기> 굵은 글씨: `get_texttrace` 에서 «학생 », «1: »(콜론·공백 포함) 이 type 0+1 겹침. 1200dpi 잉크량으로 직접 쟀다. «학생» 두 글자는 굵은 것 약 14.8천, 같은 글자의 보통(3번 선지 ⑤의 «학생») 약 10.2천으로 +46%. 콜론 단독은 굵은 것 893, 3쪽의 보통 콜론 642~654로 +37%. 따라서 콜론까지 굵다. 세트의 `bold: ["학생 1:"]`, `"학생 2:"`, `"학생 3:"` 이 맞다. <보기> 안 다른 글자에 type 1 은 없다(쪽 전체 type 1 목록 대조).
- 2번 그림 `그림_1-3_2_자료.png`: 래스터 글자는 «내층», «배아», «[육아낭 내부 구조]» 세 가지뿐이고 `raster_text` 와 일치. `pdf_text` «[자료 1] [자료 2] [자료 3]» 일치. 대체 글(alt)도 그림과 맞다.
- 2번 ④⑤ 근거 문장 재사용: ④ 의 두 번째 근거와 ⑤ 의 근거가 같은 문장이다. ④ 는 «변화가 일어납니다. → 암컷이 수컷으로 변하고 큰 점이 생긴다» 는 내용만 있고 크기 변화는 없다는 판단이라 같은 문장을 쓰는 것이 자연스럽고 해설지 4번 설명도 이 문장을 근거로 삼는다. 결정 문장이므로 문제 없음.
- 1번 ①②③⑤ (basis:"자체") 엄격 확인:
  - ① 도입(p1)에 청중의 경험을 떠올리게 하는 말이 없다. 발표 전체에도 «여러분도 ~ 한 적 있죠» 류 말이 없음. 판정·이유 맞다.
  - ② 마지막 p5 는 «소개했는데요 … 마치겠습니다» 뿐이고 «이해되셨나요» 류 확인이 없다. 맞다.
  - ③ 전문가 평가를 인용하는 부분이 지문 어디에도 없다. 이유는 맞다. (아래 고치면 좋은 것)
  - ⑤ 첫 문단은 인사·화제 소개·주의 요청이며 소감을 말하지 않는다. 맞다.
- 이유 문장: 지문·해설지 밖 말 없음, «해설지는…» 메타 문구 없음, em dash 없음. 인용은 모두 해당 문단·<보기>에 글자 그대로 있고(검사기 E 통과) 판정 방향도 발문(않은)과 맞다.

## 고치면 좋은 것
- 1번 ③ 의 근거로 p4 «수컷은 무리에서 가장 크고, 몸에 큰 점을 가지고 있습니다.» 를 들었는데, 이 문장은 «전문가 평가 없음» 을 보이는 결정 문장이 아니라 발표자 자신의 설명 예시다. 이유 문장(발표자 자신의 말로 이루어짐)과는 맞으니 그대로 둬도 되고, 더 낫게 하려면 발표자가 자료를 설명하는 대표 문장(예: p2 «이것은 수컷 아귀입니다.»)으로 바꾸는 정도. 판정에는 영향 없음.
