# 독립 검토: 2026-03 고2 국어 1~3번 (화법, 의문문 발표)

검토 자료: 문제_1쪽.png(dpi 150, 3번 <보기> 대화 상자는 확대해 밑줄 확인), 해설_글자.txt 1~3번 해설, 정답 bundle(1=④, 2=④, 3=③), 세트_1-3.json.
절차: 쪽 그림과 해설지로 먼저 직접 푼 뒤(1절) 세트 JSON 을 열어 대조했다(2절).

## 1. 직접 푼 결과 (세트 JSON 열기 전)

### 1번 (가장 적절한 것, 정답 ④)
- ① 부적절. 청중이 무엇을 요청하는 장면이 없다. 청중 반응은 발표자 질문에 대한 반응뿐("(청중의 반응을 살핀 후) 대답 감사합니다.").
- ② 부적절. 시각 자료 언급 없음. 예문은 모두 말로 제시("예를 들어 “우리 언제 어디에서 만날까?”는 …").
- ③ 부적절. 시작은 "지난 수업 시간에 선생님께서 다음 발표 순서가 누구인지 물어보셨는데요." 로 화제를 끌어낼 뿐 소감 없음.
- ④ 적절(정답). 2문단 "여러분, 판정 의문문의 개념이 이해되었나요? (청중의 반응을 살핀 후)", 3문단 "어떤 대답을 요구할까요? (청중의 반응을 살핀 후)", 4문단 "성공적으로 이루어졌다고 말할 수 있을까요? (청중의 반응을 살핀 후)".
- ⑤ 부적절. 도입은 "오늘은 의문문에 대해 발표하겠습니다." 로 화제만 밝힘. 순서 안내 없음.

### 2번 (반영되지 않은 것, 정답 ④)
- ① 반영. 청중이 함께 겪은 지난 수업의 선생님 질문 → "이렇게 화자가 청자에게 질문하여 대답을 요구하는 문장을 의문문이라고 합니다."
- ② 반영. 2문단 판정 의문문(긍정·부정 대답 요구) "반면" 설명 의문문(구체적 설명 요구).
- ③ 반영. "네가 가게에 갈래?"(행동 요구), "나랑 같이 가게에 갈래?"(함께 할 것 요구).
- ④ 미반영(정답). 4문단은 "응, 시끄럽네." 하고 아무 행동도 하지 않는, 성공적이지 않은 상황 하나만 다룬다. 마지막 문장은 원활한 의사소통의 조건을 일반적으로 말할 뿐 '다양한 상황 분석'이 아니다.
- ⑤ 반영. "물 흐르듯이 원활한 의사소통이 가능할 것입니다."(직유).

### 3번 (적절하지 않은 것, 정답 ③)
- ① 적절. ⓐ는 잘되고 있는지 여부를 묻는 판정 의문문(2문단 판정 의문문 정의).
- ② 적절. ⓑ는 '왜'에 대한 정보를 요구하는 설명 의문문(2문단 설명 의문문 정의).
- ③ 부적절(정답). ⓒ "나랑 나갔다 올래?"는 함께 할 것을 요구하는 판정 의문문(3문단 "나랑 같이 가게에 갈래?"와 같은 유형). '설명 의문문'이 틀림.
- ④ 적절. 4문단 마지막 문장: 긍정 대답 + 요구한 행동 수행이어야 원활. ⓓ의 청자는 A.
- ⑤ 적절. 4문단 "응, 시끄럽네." 상황과 같은 구조. 긍정 대답만 하고 행동이 없으면 원활하지 않음.

## 3. 지문 충실도 (쪽 그림 대조)

- p1~p5: 문단 경계 5개, 글자 모두 그림과 일치. "(청중의 반응을 살핀 후)" 세 곳 위치 일치.
- 2번 계획 상자: [도입]·[전개]·[정리] 머리말, 항목 5개, 점선 뒤 ①~⑤ 번호가 상자 안에 있음. `choices_in_box: true` 와 각 항목 끝 번호 일치. 선지 글 = 상자 항목 글.
- 3번 <보기>: "선생님:" 설명, A·B 대화 8줄, "학생: [가]". 말한 이 이름 일치, 선생님·학생 굵은 글씨 일치.
- 밑줄(확대 확인): ⓐ "중간고사 준비는 잘되고 있니?", ⓑ "근데 왜 계속 동아리 회의 자료만 보고 있어?", ⓒ "바람도 쐴 겸 잠깐 나랑 나갔다 올래?", ⓓ "마침 열두 시니 같이 급식 먹을까?" 는 물음표까지 밑줄. ⓔ 는 "오늘 급식 식단표 좀 보여 줄 수 있어" 까지이고 물음표 앞에서 끝남. 데이터와 모두 일치.
- 띄어쓰기: "못했거든", "잘되고" 그림과 일치.

## 최종 판정: **통과**

### 반드시 고칠 것
- 없음. 판정·정답·근거 인용 모두 원본·해설지와 맞고, 결론을 바꾸는 이유 오류는 없다.

### 고치면 좋은 것
1. 3-③ 이유의 "청자 혼자 할 행동을 요구한다고 한 것" → 선지에 '혼자'라는 말은 없다. 선지 글자("그 행동을 할 것을 요구하는")에 맞춰 "'함께'가 빠졌다" 식으로 고치기.
2. 3-①·3-② 이유의 "…대답을 했으므로 판정 의문문이다", "…설명으로 답했으므로 설명 의문문이다" → 의문문 종류는 질문이 요구하는 대답으로 정해진다. 대답은 보조 근거로 낮추기.
3. 1-⑤ 이유의 '의문문에 대해 발표하겠다' → 원문은 "발표하겠습니다". 따옴표 안은 원문 그대로.
4. 2-④ 이유에 4문단 마지막 문장은 조건을 말할 뿐 성공 상황을 여럿 분석한 것이 아니라는 점을 한 마디 덧붙이기.
