# 독립 검토 3차: 2026-03 고2 1~3번 (3번 <보기> 모양 확인)

검토 범위: 3번 <보기>에 오늘 추가된 안쪽 상자(`"inbox": "대화"`)와 빈칸(`"blank": "[가]"`)이 원본과 같은지, 굵은 글씨가 '선생님'·'학생'뿐인지, 판단·근거가 바뀌지 않았는지.
(기존 `독립검토_1-3.md`, `독립검토_1-3_2차.md` 가 있어 이 파일을 3차로 둔다.)

## 확인 방법

- 원본 PDF 1쪽 오른쪽 <보기> 구역을 200dpi·500dpi 로 렌더해 눈으로 확인.
- `page.get_text("dict")` 로 줄 위치, `get_texttrace()` 로 획 처리 글자 확인.
- 미리보기(`미리보기_1-3.html`) 다시 만들어 HTML 확인, `assets/css/exam.css` 의 `.xm-inbox`·`.xm-blank` 확인.
- `git diff` 로 세트 JSON 변경 확인.

## 결과

1. 안쪽 상자: 원본에는 <보기> 안에 모니터 모양 테두리(두꺼운 회색 틀, 아래 가운데 작은 동그라미)가 있고, 그 안에 A·B 대화 8줄(A: ⓐ중간고사 … ~ B: 응, 그럼. 요즘 학생회에서 …)만 들어 있다. '선생님:' 두 줄은 틀 위, '학생: [가]' 는 틀 아래로 밖에 있다. 세트는 t1~t8 에만 `inbox` 가 붙어 있고 t0(선생님)·t9(학생)에는 없다. 일치.
   - 미리보기 HTML 도 `<div class='xm-inbox'>` 안에 q3-t1~t8 만 들어 있다.
   - 화면 테두리는 1px 얇은 선(`.xm-inbox`)이라 원본의 두꺼운 모니터 틀·동그라미까지 재현하지는 않는다. "대화가 안쪽 틀 안에 있다"는 구조는 전달되므로 문제로 보지 않는다.
2. 굵은 글씨: 그림에서 굵은 것은 '선생님'(콜론 앞)과 '학생'(콜론 앞)뿐이고, A·B 는 본문과 같은 보통 굵기다(500dpi 확대 확인). 세트도 t0·t9 에만 `bold` 가 있고 A·B 줄에는 없다. 일치.
   - 참고: texttrace 로는 A·B 에도 획 처리(type 1, 검은색, 선 굵기 1.84)가 잡히지만 그림에서는 굵지 않다. 그림을 기준으로 판정했다.
3. 빈칸: 원본 마지막 줄은 '학생:' 뒤에 상자 오른쪽 끝 가까이까지 긴 밑줄이 있고 그 가운데에 '[가]' 가 놓여 있다(텍스트층에도 '[가]' 앞뒤로 긴 공백). 세트는 t9 에 `"blank": "[가]"`, 미리보기는 `<span class='xm-blank'>[가]</span>`(최소 너비 60%, 아래 선, 가운데 정렬). 일치.
4. 판단·근거: `git diff` 결과 `세트_1-3.json` 의 변경은 3번 <보기> t1~t8 의 `"inbox"` 추가와 t9 의 `"blank"` 추가뿐이다. 본문 글자·밑줄(ⓐ~ⓔ)·`questions`·`judgments`·`evidence` 는 바뀌지 않았다. `세트_1-3_만들기.py` 변경도 이 두 가지 등록뿐이다. `도구/세트_검사.py` 재실행: 합격.

최종 판정: 통과
이유: 안쪽 틀 안에 든 줄(A·B 대화 8줄), 굵은 글씨('선생님'·'학생'만, A·B 는 보통), '[가]' 가 긴 빈칸 밑줄 위에 있는 것 모두 원본 쪽 그림과 맞는다. 판단·근거는 바뀌지 않았고 프로그램 검사도 합격이다. 화면 틀이 원본의 두꺼운 모니터 모양보다 단순한 것은 구조 전달에 지장이 없어 수정 사항으로 두지 않는다.
