# 독립 검토 (1차): 세트_4-7.json (2025-09 고2, 4~7번, 화법과 작문)

검토 방법: 쪽 그림(문제 2·3쪽)과 해설지로 먼저 풀고(4=②, 5=④, 6=④, 7=⑤ 일치, 선지별 판단도 해설지·원문과 일치), 세트 파일과 대조. 문제 PDF 의 `get_texttrace`(type 0+1 겹침)와 600dpi 확대로 굵은 글씨를 직접 쟀고, PDF 그린 선(`get_drawings`)으로 밑줄·묶음 괄호를 확인했다. `세트_검사.py` 는 합격이다.

## 확인한 것 (이상 없음)

- 정답·판정 방향: 4=② 적절, 5=④(발문 «않은», 정답 판정 부적절), 7=⑤(발문 «않은», 정답 판정 부적절). 6=④. 모든 선지 판정이 해설지·원문과 맞다.
- 문단 경계: (가) 표제·전문·본문, 둘째 문단 «또한 참가자들은»(들여쓰기), 셋째 문단 «‘초록누리’ 동아리 회장인»(들여쓰기)이 쪽 그림과 일치. 대화는 «학생 N» 마다 한 항목.
- [A] = p13·p14(학생3 «맞아…» ~ 학생2 «…있겠다.»), [B] = p21·p22(학생2 «그런데…» ~ 학생3 «…있을 것 같아.»). 그림 속 괄호 선(y 602.9~653.2, y 172.4~222.6)과 일치.
- 밑줄 ㉠~㉤: PDF 선 범위와 일치. ㉣ 은 ㉣ 기호부터 «아쉬워.» 까지 이어진 한 선(109.4~286.5 → 87.4~156.9)이고 «○○» 도 선 안에 들어 있다. 데이터의 «○○생태원 외부에서…» 가 맞다. 발문 «않은» 밑줄(5번, 7번)만 있고 4번·6번 발문·선지에는 밑줄이 없다.
- 굵은 글씨(콜론 이외): «[표제] …방문해»(가운데 맞춤 포함), «[전문]», «[본문]», 모든 «학생 N» 의 «학생»+숫자, «학생 2, 3» 이 type 0+1 겹침으로 확인되고 데이터와 같다. «(가)»·«(나)» 소제목도 굵지만 label 형식을 화면(CSS)이 굵게 그리므로 데이터에 따로 적을 필요 없다. 선지·발문·7번 상자에는 굵은 글씨가 없다.
- 6번 `table_border`: 6번 선지에는 실제 밑줄이 없다(쪽 그림, 선 목록으로 확인). `table_border` 를 빼면 검사기가 C9 오탐 4건을 내므로 이 표시는 필요하다(검사기 한계이지 세트 오류가 아님).
- 7번 상자: 라벨 없는 상자, ◦·→ 항목, 점선 뒤 ㉮~㉲ 가 PDF 와 같다. 선지 ①~⑤ 가 ㉮~㉲.
- em dash 없음, «해설지는…» 메타 문구 없음, 이유가 지문·해설지 밖으로 나간 곳 없음.
- 해설지 없는 선지 4번 ①③④⑤: 판단·이유 모두 맞다. 근거 문장이 이유를 직접 받치는 정도는 약한 편이나(없음을 보이는 선지라 어쩔 수 없다) 틀리지 않았다. 6번 ①②③⑤: 판단·이유는 맞다(아래 근거 문제만 있음).

## 반드시 고칠 것

1. **굵은 콜론 위치가 뒤바뀜 (p23 ↔ p26).** 문제 2쪽 오른쪽 단에서 굵은 콜론(type 0+1, 글꼴 Haansoft Dotum, 600dpi 확대로도 굵음)은 p19(y121 «학생 3:»), p26(y316 «학생 1: 그러네.»)에 있고, p23(y230 «학생 1: 고마워.»)의 콜론은 보통 굵기(type 0 만, Haansoft Batang)다. 세트는 p23 `"bold": ["학생 1:"]`, p26 `"bold": ["학생 1"]` 로 거꾸로 적었다. 고치기: p23 = `["학생 1"]`, p26 = `["학생 1:"]`. (p13, p15, p19 의 콜론 굵음은 맞다.)
2. **6번 ② 근거가 결정 문장이 아님.** 이유는 «학생2는 자료를 더 요청하지 않고 동의한다» 인데 근거는 학생3의 제안(p13 «체험 활동 장소를 추가해야 하지 않을까?»)뿐이다. 학생2 의 발화(p14 «좋은 생각이야. ○○늪 습지도 언급해 주면 … 정확하게 전달할 수 있겠다.»)를 근거로 넣거나 바꿔야 한다.
3. **6번 ③ 근거 인용이 잘림.** p22 quote «맞아. 그렇게 수정하면» 은 문장의 앞토막이다. 결정 문장 전체(«맞아. 그렇게 수정하면 관심이 있는 학생들이 더 많이 참여할 수 있을 것 같아.»)로 늘린다.
4. **6번 ⑤ 근거가 이유와 어긋남.** 이유는 «[A]의 학생3 … 질문 형태로 제안한다» 인데 근거 p13 quote 는 질문이 아닌 앞 문장(«전문만 보면 … 전달될 수 있을 것 같아.»)이다. 질문 문장 «체험 활동 장소를 추가해야 하지 않을까?» 를 근거로 쓰거나 둘 다 넣는다(앞 문장만 단독으로 두면 오히려 정확성을 따지는 말처럼 읽힌다).
