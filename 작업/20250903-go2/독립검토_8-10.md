## 3. 대조 결과

### 지문·화면 충실도 (통과)

- 문단 경계: 쪽 PDF 줄 시작 x 좌표(들여쓰기)로 확인. 작문 상황 1개, 초고 5개 문단이 데이터와 같다. ㄴ 신문 기사 1문단, ㄷ 인터뷰 1문단도 같다.
- 밑줄: PDF 선은 8번 발문 «않은», 9번 발문 «않은» 두 곳뿐이고 `stem_underlines` 와 같다. 10번 발문과 선지에는 밑줄이 없다(데이터도 없음). 
- 굵은 글씨(직접 잼):
  - `[작문 상황]`, `[초고]`: type 0+1, 선 굵기 1.36. 굵은 글씨가 맞다.
  - 네모 안 `[A]` (작업자가 자신 없던 곳): 같은 쪽 글꼴(Haansoft Batang)·같은 크기의 보통 `[A]`(이 쪽 왼쪽 단, type=0 전용)와 비교하면 type 0+1 겹침(선 굵기 1.36)이고 1200dpi 잉크량 5162 대 3746 으로 약 38% 많다. **굵은 글씨가 맞다.** 데이터의 `bold:["[A]"]` 는 옳다.
  - `선생님`: type 0+1. 콜론(:)과 뒤 글은 type 0 전용(보통). 데이터가 `"선생님"` 만 굵게 둔 것이 맞다.
  - `ㄱ. 통계 자료`, `ㄴ. 신문 기사`, `ㄷ. ◇◇구민 인터뷰`: 마침표·공백까지 모두 type 0+1. 데이터와 같다.
  - `< 보 기 >` 머리말은 type 0 전용이라 보통 글씨다. 데이터도 굵게 두지 않았다. 지문·발문·선지 본문에 type 1 인 글자는 위 목록 밖에 없다(문항 번호·쪽 번호는 세트 밖).
- 9번 래스터 통계 그림 `raster_text` (작업자가 자신 없던 곳): 그림(`그림_8-10_9_통계자료.png`)과 글자 대조 결과 전부 일치한다. 2020 211건 · 2021 243건 · 2022 262건 · 2023 298건, 연도 축, 유형 31·28·23·11·7%(합 100), «(2020~2023 누적 건수 기준)», 제목 «ㄱ-1.·ㄱ-2.» 까지 맞다. `alt` 도 그림과 맞다. PDF 텍스트층에는 이 그림 글자가 없으므로(이미지 1장) `pdf_text:""` 처리가 옳다.
- 지문 전체를 감싼 네모 상자와 [A] 칸의 폭은 알려진 화면 한계이다.

## 4. 반드시 고칠 것

1. **10번 ② 선지 띄어쓰기**: 데이터 `choices[1]` 이 `"…점검하고 관리한다면,◇◇구 구민들은…"` 로 쉼표 뒤 공백이 없다. 쪽 그림에서 이 쉼표는 줄 끝이고, 같은 문항 ①·③·④ 는 `다면, ◇◇구` 처럼 쉼표 뒤에 띄어 쓴다. 텍스트층에 줄 끝 공백이 없어 생긴 오류로, 검사기가 공백을 무시해 못 잡았다. `관리한다면, ◇◇구` 로 고쳐야 한다. 해설지 인용(판정 ②의 `explanation_quote`)에는 «관리한다면’은» 으로 이 문장이 따로 나오므로 영향 없음.
