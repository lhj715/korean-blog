# 독립 검토 27~30번 (2025-09 고2, 오정희 「겨울 뜸부기」) 1차

검토 방식: 세트 파일을 보기 전에 쪽 그림(9·10·11쪽)과 해설지 3쪽으로 먼저 풀었고, 그다음 `세트_27-30.json` 과 대조했다.
프로그램 검사(`도구\세트_검사.py`): 합격. 해설지에 없는 선지 9개(27②③④⑤, 28⑤, 29①②④⑤)만 아래에서 엄격히 봄.

## 1. 스스로 푼 결과

정답 27번 ①, 28번 ②, 29번 ③, 30번 ⑤. 정답표·세트 파일과 모두 같다. 선지별 판단도 세트 파일과 모두 같다.

## 2. 직접 확인한 것

- 굵은 글씨 11곳: `get_texttrace` 에서 type 0 글자 위에 type 1 이 같은 자리로 겹쳐 있는 구간(font Haansoft Batang)을 모두 뽑았다. 지문에서 굵은 구간은 정확히 11개이고 세트 파일의 `bold` 와 글자 범위가 일치한다(과거 운이 없어 / 학급에서 중간 정도의 성적 / 일류 학교들 / 큰 배의 선장이 되어 먼 바다로 나가겠다는 / 약학 대학쯤 들어 / 안정된 생활을 할 수 있 / 인생이 다만 그런 것뿐이라면 허전하고 쓸쓸해서 / 우리네 사는 삶과는 좀 다른 / 입만 가지고 하는 장사는 사기밖에 없다 / 오징어잡이 배를 타고 있다는 엽서 / 왕창 망해 버렸다는 호기와 허언으로). 닫는 따옴표·마침표·조사는 굵지 않음.
  600dpi 잉크량: 굵은 한글 118자를 같은 글자의 보통 글씨(type 0 전용, type 1 겹침 제외)와 비교하니 최소 1.36배, 중앙값 1.48배로 전부 확실히 굵다. 보통 글씨 쪽에는 type 1 겹침이 한 글자도 섞이지 않았다. 빠진 굵은 글씨 없음(문항·선지·<보기> 안에는 굵은 글씨 없음, 10쪽 문항 번호와 11쪽 안내문은 형식 요소).
- 문단 경계: 줄 첫머리 들여쓰기 글자(앞 공백)로 확인. p1~p8, p10~p19, p20~p31 모두 새 문단 시작과 세트 파일의 항목 경계가 일치한다. p19 는 9쪽 끝에서 10쪽 첫 줄로 이어지는 한 문단(「살아갈 방책을 세우도록 해라…」)이고 한 항목으로 맞게 합쳐졌다. 대화문 둘째 줄 이하 안쪽 들여쓰기(318.7)는 줄바꿈일 뿐 문단이 아니다.
- 밑줄: PDF 선 그림의 끝 x 좌표를 글자 상자와 대조했다.
  ㉠ 선 끝 355.4, 마침표 353.3~355.5 → 마침표 포함. 세트 파일도 포함. 맞음.
  ㉡ 선 끝 386.0, '다' 끝 386.3, 마침표 시작 386.0 → 마침표 제외. 세트 파일도 제외. 맞음.
  ㉢ 선 끝 414.1, 마침표 412.1~414.3 → 포함. 세트 파일도 포함. 맞음(두 문장에 걸친 선, 중간 공백 빈틈은 띄어쓰기).
  ㉣ 선 끝 249.7, 마침표 시작 249.7 → 제외. 맞음.
  ㉤ 선 끝 220.0, 마침표 시작 220.0 → 제외. 맞음.
  시작 위치(㉠ 「그렇다고」, ㉡ 「어머니의」, ㉢ 「꼭」, ㉣ 「오빠는」, ㉤ 「지금보다는」)도 맞다.
  발문 「않은」 밑줄: 27·28·30번 모두 PDF 선이 있고 `stem_underlines` 에 있다. 29번 발문에는 선이 없고 파일에도 없다. 선지 속 밑줄 없음.
- 네모: 지문 「금반지」(p20)와 29번 발문 「금반지」 모두 PDF 에서 네모 테두리, 파일도 `boxed`·`stem_boxed` 로 맞음.
- 특수문자: 28번 선지의 `~`(ASCII)·`～`(전각)가 PDF 와 같은 문자. `(중략)` 항목, 작품 출처 줄 「- 오정희, ｢겨울 뜸부기｣-」 맞음. 지문 글자·선지·<보기> 글자는 검사기 B1·B3 통과.
- 이유 문장: em dash 없음, 「해설지는…」 메타 문구 없음, 지문 밖 지식 없음.

## 3. 해설지 없는 선지(basis:자체) 엄격 검토

- 27② 판정 맞음. 인용 p4 는 결정 문장(저울추로 신체검사 통과). 이유 맞음.
- 27③ 판정 맞음(정답이 ①이므로 적절). 이유는 맞지만 인용이 p5 한 문장뿐이다. 선지의 「원하는 대학만을 고집」 부분을 받치는 문장은 p3 「어머니는 2차 대학의 비교적 약한 과를 택해 응시하기를 종용했으나 오빠는 막무가내로 3수에 들어갔다」인데 이유에서 말로만 쓰고 근거로 달지 않았다.
- 27④ 판정·인용 맞음(p22 울고 있었다 + p23 마지막).
- 27⑤ 판정 맞음. 인용 「이번에 다시 실패하면」은 결정 문장이다. 다만 이유가 「계획서를 보이며」라고 썼는데 이 말은 계획서를 펴 보이기 직전의 대사(p11→p12 순서)다. 선지가 「보여 주기 이전」을 묻는 만큼 표현을 맞추는 편이 안전하다.
- 28⑤ 판정 맞음. 인용 한 문장이 선지의 나열·비교를 모두 담는다. 이유도 지문 범위 안.
- 29① 판정 맞음. 이유 맞음. 다만 인용이 p5(어머니가 오빠를 탓함)뿐이라 「금반지는 심리적 보상이 아니다」를 직접 받치지 못한다. p19 「나는 이제 아무 힘이 없다」를 추가하면 정답 근거와 맞물린다.
- 29② 판정 맞음. 인용 p21 은 결정 문장.
- 29④ 판정 맞음. 인용 p22(울고 있었다)는 「현실에 만족」을 부정하는 간접 근거라 약하다. 이후 오빠가 울릉도에서 오징어잡이를 하고 「호기와 허언」으로 나타나리라는 서술(p24, p31)이 더 직접적이다.
- 29⑤ 판정 맞음. 이유의 「가족의 안정적인 삶을 지키려는 것이 아니다」를 받치는 인용이 없다(p11 은 한밑천 요청일 뿐). 오빠가 안정된 삶에 뜻이 없다는 p7 「인생이 다만 그런 것뿐이라면 허전하고 쓸쓸해서」나 p14~p15 의 자기 사업 서술이 근거로 낫다.
