- 굵은 글씨 (`get_texttrace` type 0+1 겹침 + 쪽 그림):
  - (가) 대화 «학생 1:» 등 22개 전부 «학생»·숫자·쌍점(`:`)까지 type 0+1(Haansoft Batang)로 굵음. «학생 2, 3:» 도 «2, »·«3»·«:» 모두 굵음 → 세트의 bold 22항목과 일치. 지문 본문(type 0 전용 글자)과 비교해 구분됨.
  - 소제목 (가)·(나): 둘 다 type 0+1 로 굵음. 세트는 label 항목으로 두었고 화면 CSS(`.xm-label` font-weight 700)가 굵게 그리므로 문제없음. 별도 bold 지정 불필요.
  - 본문(나) 5개 문단과 그 밖의 지문·선지에는 type=1 글자 없음(세트에 bold 없음 = 맞음).
