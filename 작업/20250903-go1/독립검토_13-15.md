# 독립 검토 13~15번 (2025-09 고1, 세트_13-15.json, 1차)

검토 방법: 세트 파일을 열기 전에 쪽 그림(5쪽·6쪽)과 해설지 13~15번으로 먼저 풀었다. 그다음 세트 파일과 대조했고 `세트_검사.py` 를 돌렸다.

## 스스로 푼 결과
- 13번: 정답 ④. 읽다의 현재 관형사형은 «-는» 이므로 «읽은»(과거)은 현재 시제 문장에 맞지 않는다.
- 14번: 정답 ④. «선생님께»의 «께»는 객체 높임이고 주체(동생) 높임 표현이 없어 ㉯가 아니라 ㉮.
- 15번: 정답 ③. «보믜»의 끝 조사는 관형격이 아니라 부사격 조사.
- 세트의 answer(4, 4, 3)와 일치하고 정답표 bundle 과도 일치한다(검사기 D 통과).

## 작업자가 자신 없다고 한 곳
1. 14번 순서도에서 ①②④가 같은 근거 인용: 문제없음. ①·②·④는 모두 순서도의 첫 판단 칸(«문장에서 주체를 높이는 표현이 쓰이고 있는가?»)에서 «아니요»로 빠지는 이유라서 결정 문장이 실제로 같은 칸이다. ③은 둘째 칸의 «특수 어휘»로, ⑤는 두 칸 모두로 서로 다르게 잡았다. 다만 ④·⑤ 인용에 텍스트층 조각 «㉰㉮» 가 붙는데 그림 속 글자 그대로라 검사상 문제는 없다(고치면 좋은 것 1).
2. 13번 선지 표 머리 «시제/문장» 밑줄: PDF 선과 쪽 그림에서 두 낱말 모두 밑줄이다(`mark:""`). 굵은 글씨 아님(type 0 전용). 맞다.
3. 15번 출전 줄 U+F000 과 그림 조각: 쪽 그림(300dpi)과 `예문1~3.png` 를 대조했다. 세 그림 모두 «∘ 예문 / [풀이] / –『출전』» 세 줄이 온전하고 굵은 부분(부톄 안ᄌᆞ시니, 보믜, 뛰노니, 뫼헤)도 그림에 살아 있다. 선지 속 옛한글 그림 4개(ᄌᆞ, ᄆᆡ, ᄋᆡ, ᄠᅱ)는 원본 선지 ②③④의 글자와 일치하고 alt 도 맞다. 데이터 글자의 PUA 는 display_image 가 있는 항목과 choice_images 대상에만 있다.
4. 굵은 글씨: `get_texttrace` 로 쟀다.
   - 13번 «[자료]»: type 0+1 겹침, 대괄호까지 굵음. 세트의 `bold:["[자료]"]` 맞음.
   - 14번 «[탐구 과정]»: type 0+1 겹침, 대괄호까지 굵음. 맞음.
   - 13번 표 머리·행 머리(품사, 시제, 동사, 형용사, 과거, 현재, 미래)는 굵지만 그림에 들어 있다.
   - 선지 13~15번 전부와 «시제 문장» 머리, 발문, 문단 본문은 type 0 전용이라 굵지 않음(15번 쪽의 type=1 «(나)»는 옆 열 지문이라 이 세트와 무관).
