## 2. 확인한 항목 (작업자가 자신 없다고 한 곳 포함)

- **「학생 N:」 굵은 글씨(콜론까지)**: 맞다. 18개 모두 PDF 텍스트층에서 Haansoft Dotum 7.5pt 의 type 0+1 겹침이고 stroke 선 너비가 같다(1.36). 이 쪽에는 type=0 전용 Dotum 이 없어서 같은 PDF 의 다른 쪽(6·11·12·13쪽)의 type=0 전용 Dotum 과 1200dpi 잉크량(글자 크기 보정)을 직접 비교했다. 콜론 «:» 0.97 대 1.42(+46%), «는» 7.71 대 11.14, «을» 11.55 대 16.85, «의» 10.01 대 13.30, «이» 9.26 대 12.10. 모두 굵다. 숫자 «1» 은 type 0 전용 비교 대상이 없지만 같은 줄·같은 stroke(0+1)라 같이 굵은 것이 맞다. 세트의 `bold: ["학생 N:"]` 는 콜론까지 포함이라 맞다.
- **(가)(나) 소제목 굵기**: 굵은 글씨가 맞다. Haansoft Batang 7.5pt 의 type 0+1 이고, 같은 쪽 보통 Batang(type=0 전용) «가» 와 잉크량이 6.77 대 9.34(+38%)다. 8배 확대 그림에서도 («우리가» 의 «가» 보다) 획이 굵다. 작업자가 «쪽 그림에선 굵게 안 보인다» 고 했으나 텍스트층과 잉크량 둘 다 굵음을 가리키므로 세트의 `bold: ["(가)"]`, `["(나)"]` 가 맞다.
- **다른 곳에 굵은 글씨가 빠졌는지**: 14쪽에서 type 0+1 인 글자는 안내문(발문 줄, 도구가 따로 그림), (가)·(나), 「학생 N:」, [A]·[B], 문항 번호뿐이다. (나) 본문·선지·발문에 type 1 없음. 42번 상자의 【선생님의 조언】【마지막 문단】 도 type 1 없음(굵지 않음)이라 세트가 굵게 표시하지 않은 것이 맞다.
- **㉠㉡ 밑줄 / ㉢~㉤ 밑줄**: PDF 선과 직접 대조했다. ㉠ 선 끝 x=403.1, 뒤의 «.» 는 403.2부터 → 마침표 앞에서 끝남. ㉡ 선 끝 524.8, «.» 525.0 → 마침표 앞에서 끝남. ㉢ «…됩니/다.» 선이 둘째 줄 325.9 까지 «다.» 포함, ㉣ «…있습니다.» 포함, ㉤ «…수치입니다.» 선 끝 527.1 마침표 포함. 세트의 `underlines` 글자와 일치한다. 발문 «않은» 밑줄: 38번(14쪽)·40번·41번(15쪽) 모두 PDF 선이 있고 세트에 `stem_underlines` 가 있다. 39·42번 발문에는 선이 없고 세트에도 없다.
- **[A]=p3~p5, [B]=p14~p16**: 쪽 그림의 [A] 괄호는 «학생 2: 지난번에…» 부터 «학생 2: 기억난다…» 까지(p3~p5), [B] 괄호는 «학생 3: 그리고 예산을…» 부터 «학생 3: 나도 그렇게 생각해…» 까지(p14~p16). 맞다.
