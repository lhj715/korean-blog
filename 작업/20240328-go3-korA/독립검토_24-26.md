## 작업자가 자신 없다고 한 곳
- **굵은 글씨, 마침표 비굵음: 맞다.** 텍스트층에서 «간다.»가 아니라 «올라간다» «깨운다» «환해진다» 의 글자만 type 0+1 이고, 바로 뒤 마침표(y831 근처 «. », y864 «. », y931 «.»)는 type 0 만이다. «좋다», «린다», «아»(태양아의 아), «이»(것이) 등도 type 0 이라 굵지 않다. 세트의 bold 목록과 PDF 의 type=1 구간이 (가) 11곳, (나) 9곳 모두 일치한다(없는 것도, 넘치는 것도 없음). 쪽 그림에서도 같다. 비교 기준 보통 글자는 type 0 전용이다.
  - 같은 글자가 둘 이상 나와 nth 가 필요한 곳 없음(땅·하늘·밤·기다·아침·태양 각 1회).
- **(가) 산문시 문단 경계: 맞다.** 줄 시작 x 좌표로 확인. «태양아»(x108), «다만…»(108), «태양아»(108), «너는…»(108), «태양보다도…»(108) 가 들여쓴 줄이고 이어지는 줄은 x98. 세트의 g1~g5 분할(태양아 / 본문 / 태양아 / 본문 / 마지막 연)과 같다. (나)의 앞 산문(h1, 108 시작 후 98)과 행 구분 시(h2) 경계도 맞다.
- 밑줄: ㉠(두루미/의 목통, 줄 걸침)·㉡·㉢·㉣·㉤ 범위가 PDF 선(C3 합격)과 쪽 그림에서 일치. 25번·26번 발문 «않은» 밑줄 등록됨(쪽 그림에서 둘 다 밑줄 확인). 24번 발문에는 밑줄 없음(그림도 없음).
