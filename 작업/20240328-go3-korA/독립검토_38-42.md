## 굵은 글씨 직접 측정 (`get_texttrace`, 14쪽, 글꼴 Haansoft Batang 전용 확인)
- «학생», 숫자(1·2·3)는 type 0+1 겹침(굵음), 콜론 «:» 은 type 0 전용(보통). 데이터의 `bold: ["학생 1"]` 등과 일치(숫자 포함, 콜론 제외). 비교 기준 콜론이 type=0 전용임을 확인했다.
- «학생 2, 3» 은 «학생», «2, », «3» 이 모두 0+1(굵음), 콜론 0 전용. 데이터와 일치(쉼표·숫자 포함).
- (가)(왼쪽 단 y216), (나)(오른쪽 단 y360) 소제목: 괄호·글자 모두 0+1. 데이터의 bold 와 일치.
- 선지·발문·<보기>·(나) 본문에는 type=1 이 없다(데이터에 bold 없음, 맞음). `[A]`·`[B]` 표시는 type 1 이지만 구간 표시(ranges)로 처리되어 본문 항목이 아니므로 문제 없음. 문제 번호 «38.»~«42.» 의 굵은 처리는 화면이 따로 그린다.
