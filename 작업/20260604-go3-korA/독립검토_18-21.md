# 독립 검토 18~21번 (1차)

대상: 세트_18-21.json. 원본: 문제 6쪽 오른쪽 단, 7쪽 / 해설 11~14쪽.

## 확인한 것
- 스스로 푼 답: 18 ①, 19 ②, 20 ①, 21 ③. 세트 파일, 정답표와 일치. 선지별 판정 20개 모두 맞음. 해설지에 없는 선지 없음.
- 세트_검사.py: 합격.
- 문단 경계(줄 시작 x 좌표): p1~p23 모두 맞음.
- 밑줄(PDF 선 좌표): ⓐ, ⓑ, ㉠(«아니가?»까지), ㉡, ㉢, ㉣, ㉤, ㉤ 다음 문단의 기호 없는 밑줄(mark ""), 18·21번 발문 «않은» 모두 맞음.
- 굵은 글씨: 이 PDF 는 전부 type 0, 글꼴로 갈림. [A] 안 견명조 10곳(«안 돼!» 부터 «궁둥이를 탁 치»까지)은 등록과 일치하고 같은 낱말이 앞에 따로 나오지 않아 nth 문제 없음. 빠진 곳은 아래 1-2.
- [A] 범위 p8~p11: 쪽 그림의 괄호와 일치.
- 21③ «보여주어»는 텍스트층에서 줄 끝 공백이 없어 현재 표기 유지 가능.

## 반드시 고칠 것

1. 21번 <보기> (문제 7쪽 오른쪽): `bogi.paras[0]` 이 `>이 작품에는 ...` 로 시작한다. «<보 기>» 의 닫는 꺾쇠가 본문에 섞였다(만들기.py 59행 부근 `st[k+len("보 기"):]`). 화면에 «>이 작품에는»으로 보인다. `>` 를 지운다.
2. p4 중략 안내 (문제 6쪽 오른쪽, y=523.9): «[중략 부분의 줄거리]» 는 신명-태고딕(뒤 본문은 신명-중고딕)이고 쪽 그림에서도 굵다. `"bold": ["[중략 부분의 줄거리]"]` 를 단다(이미 게시한 회차들도 같은 방식).
3. 19⑤ 근거: 인용 «그러나 그들을 나룻배에 태우지 않을 수 없었다.» 는 지난봄이 아니라 함박눈이 마을을 덮은 겨울 그날의 일이다. 이유 «지난봄에 삼바우는 두 사람을 나룻배에 태워 ...» 의 근거로 붙이면 학생이 시점을 거꾸로 읽는다. 근거를 시점이 갈리는 문장으로 바꾼다. 예: «ⓐ지난봄의 일이 생각났던 것이다.» 와, 강 길을 끊는 것이 지금의 삼바우임을 보이는 p14/p15 쪽 문장(19③·④ 인용과 되도록 겹치지 않게). 이유도 «강 길을 끊은 것은 지난봄이 아니라 나중에 삼바우가 한 행동이고, 적대적 인물이 끊은 것이 아니다» 방향으로 해설(해설 13쪽 19번 ⑤)에 맞춰 고친다.
4. 19② (정답) 근거: ⓐ와 겨울을 비교하는 선지인데 인용 두 개 어디에도 ⓐ가 없다. «하루는 또 ... 섰다» 를 지난봄과 잇는 «ⓐ지난봄의 일이 생각났던 것이다.» 를 근거에 넣는다.
5. 19① 근거: «삼바우는 가슴이 덜컥 내려앉았다.» 에서 끊겨 ⓐ와의 연결 문장이 빠졌다. «삼바우는 가슴이 덜컥 내려앉았다. ⓐ지난봄의 일이 생각났던 것이다.» 로 늘린다.
6. 19④ 이유: «위기를 푸는 것도 외부인이 아니라 마을 쪽 사람의 노력이다» 는 위기가 풀린 것처럼 읽힌다. 해설(13쪽)은 «위기를 해결하려는 내부인의 노력»이다. «위기를 풀려고 나선 것도 ...» 로 고친다.

## 고치면 좋은 것
- 18④ 근거: 인용이 «... 어디냐고 하면서» 에서 끊긴다. 선지의 «찾아다녔다» 에 해당하는 «... 눈에 묻힌 골무샅*을 돌아다녔다.» 까지 늘린다.
- p24 작품 출처: `｣-` 로 붙어 있어 화면 도구의 오른쪽 맞춤 조건(`- ... -`, 끝 하이픈 앞 공백)에 걸리지 않는다. 쪽 그림처럼 `- 하근찬, ｢나룻배 이야기｣ -` 로 띄우면 오른쪽에 붙는다(검사는 공백 무시).
- 20③ 이유: 지문 순서는 «풀려 나간다» 다음에 «하는 수 없다는 생각이 들자» 이다. 해설의 설명을 따르되 «체념하는 마음이 몸에 드러난 것» 처럼 쓰면 지문 순서와 부딪히지 않는다.
