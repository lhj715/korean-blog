# 독립 검토 37~39번 (세트_37-39.json, 2025-07 고3 언어와 매체, 1차)

## 스스로 푼 결과 (세트 파일을 열기 전)
- 37번: 음절 유형이 바뀐 말은 물놀이(연음), 아랫입술(ㄴ첨가), 육각형(거센소리되기)이고 닭고기는 안 바뀐다. 음운 변동에 의한 것은 아랫입술과 육각형이다. 정답 ① (해설지·정답표와 같음).
- 38번: 오르내리다는 어간+어간이라 비통사적 합성어(㉡)다. ③이 부적절. 정답 ③.
- 39번: 지븨는 집+의(부사격). 관형격이라는 ③이 부적절. 정답 ③.

## 대조 결과
- 지문 글자·선지: 프로그램 검사 합격(`세트_검사.py`). 쪽 그림(13·14쪽)과 직접 대조해도 37·38·39번 발문, 상자, 선지가 같다.
- 정답·판정: 37 ①, 38 ③, 39 ③ 모두 해설지·정답표와 일치. 부정 발문(38·39 «않은»)의 정답 선지 판정이 부적절이다. 선지 15개 모두 해설지 5쪽에 있어 `basis:"해설지"` 가 맞고 `explanation_quote` 도 그 문항 해설에서 온다.
- 밑줄: 37번 선지 머리 ㉠·㉡(PDF 선 776~792, 980~997 px)이 있고, 38번 ㉠·㉡·발문 «않은», 39번 ㉠~㉤·발문 «않은» 이 PDF 선과 맞는다. 39번 ㉡·㉤ 밑줄은 옛한글 PUA 글자까지 포함해 등록돼 있고, ㉤ 선(194~257)이 «첫소리+ᄅᆞᆯ» 끝까지 간다.
- 굵은 글씨 (`get_texttrace` type 0+1 겹침, 글꼴 Haansoft Dotum, 쪽 그림 확대):
  - 37번 첫 «선생님» 은 이름만 type 1, 콜론은 type 0 전용(보통). 작업자의 설명이 맞다. 그 줄은 display_image 이고 그림에서도 이름만 굵고 콜론은 보통이다.
  - 나머지 «학생:»·«선생님:» 4줄은 이름과 콜론 모두 type 0+1(굵음). 데이터의 bold 가 `"학생:"`·`"선생님:"` 로 콜론까지 포함해 맞다.
  - 이 영역(37번 상자)에서 type 1 인 다른 글자는 없다. 38·39번 본문에서는 쪽 번호 «39.» 외에 굵은 글자가 없다.
- 작업자가 자신 없던 곳:
  - 37번 안쪽 단어 상자(inbox+center): 원본의 2줄×2열 상자를 가운데 맞춘 두 줄로 근사했다. 단어 4개와 순서가 같고 학습에 지장이 없다. 허용.
  - 37번 ㉡ 에서 물놀이를 빼는 근거: 발문 안내 «연음이나 음운 변동이 일어나면서…» 가 연음과 음운 변동을 나눠 말하고, 해설지가 물놀이를 «연음이 일어나» 로만 설명한다. 이유 문장은 이 둘에서 나가지 않는다. 적절.
  - 37번 첫 말 네모 숫자 display_image: 그림(603 폭)에 ①~④ 네모 숫자, 굵은 이름·보통 콜론, 줄 바꿈이 원본과 같다. 대체 텍스트도 PDF 글자와 같다.
  - 39번 display_image 3장(자료 줄)과 선지 ②⑤ 그림(ᄋᆞᆯ·ᄅᆞᆯ, PUA U+EE8C·U+E470): 원본 글자와 같고 밑줄도 그대로 담겼다. `choice_images.text` 가 PUA 한 글자로 들어 있다(규칙대로).
- 이유 문장: «해설지는…» 같은 메타 문구와 em dash 없음. 지문·해설지 밖 내용은 «부텨»(체언 기본형)·«ㅅ» 정도로 해설지 괄호 풀이 그대로다.
