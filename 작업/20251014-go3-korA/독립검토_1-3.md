## 직접 잰 것

- 문단 경계: 왼쪽 단 줄 시작 x 가 107.8(들여쓰기)인 곳이 «인지 심리학», «독자는 글을 읽을 때», «독자는 응집성 기준과», «독자 주도적 독서에서» 4곳뿐이다. p1~p4 와 같다. 쪽 경계에서 끊긴 문단 없음.
- ㉠ 밑줄: 선 두 줄(y=672.3 x 269.2~402.0 / y=689.0 x 97.7~178.2). 둘째 줄 선 끝 178.2 는 «사용한다» 의 «다» 끝이고 «사용한다.» 단어 끝(181.3)보다 짧다. 마침표는 밑줄 밖이므로 세트의 `"응집성을 높이기 위한 독서 전략을 사용한다"`(마침표 없음)가 맞다. 쪽 그림 확대도 같다.
- 굵은 글씨: 이 세트 범위(지문·발문·선지·그림)에 `get_texttrace` type=1(굵은)인 글자 없음. type=1 은 머리글(시험 이름·«제1교시»·«[1~3] 다음 글을…»·문항 번호 «1.» «2.» «3.»)뿐이다. 세트의 `bold` 필드 없음이 맞다. (안내문 «[1 ~ 3]» 은 guide 이고 굵은 글씨는 화면 도구가 처리하는 영역으로 보이며 세트 데이터 문제는 아님.)
- 발문 밑줄: 1번 «않는»(y≈949.7), 2번 «않은»(y=248.2 x 658~679), 3번 «않은»(y≈915.4) 모두 PDF 선 있음, 세트 `stem_underlines` 와 일치.
- 2번 기록 상자 그림: `그림_위치_1-3.json` 의 rect [444,259,745,584] 로 자른 200dpi 그림(837x904, dpi 기록 199.99). 쪽 그림 대조 결과 ⓐ~ⓔ 밑줄 범위가 원본과 같다(ⓐ «달리기 부상의 원인에 대한 / 궁금증이 … 시작했다.», ⓑ «관절과 근육이 … 나갔다.», ⓒ «달리기 자세를 … 읽었다.», ⓓ «달리기와 심폐 … 있었다.», ⓔ «달리기가 뇌 기능을 … 읽었다.»). 선 끝이 마침표 앞에서 끝나는 것도 원본과 같다. 테두리 선이 조각에 걸리지 않았다. `pdf_text` 는 PDF 텍스트층과 글자가 같다(그림 속 『 』 는 텍스트층에 없어서 pdf_text 에도 없음, 검사기 통과).
- 근거 인용: 모든 quote 가 지문 문단·그림 글에 그대로 있고(검사기 통과), 해설지 인용도 그 문항 해설에 있다.

## 작업자가 자신 없다고 한 곳

1. ㉠ 밑줄 마침표 처리: 위에서 쟀듯 마침표 제외가 맞다. 문제 없음.
2. 2번 ⑤ basis «해설지» 와 ⓓ 판단: basis/explanation_quote 는 적절하다. 해설지는 ⑤ 의 오류를 «ⓑ 에서 어려움을 이유로 기준을 낮췄다» 로 설명하고(해설 103~105줄), 세트의 explanation_quote 가 그 문장이다. 다만 아래 «반드시 고칠 것» 1번의 이유 문장 문제가 있다.
3. 2번 그림 속 밑줄·글자: 위에서 대조했고 일치한다.

## 반드시 고칠 것

1. **2번 ⑤ reason 의 논리 오류.** 현재 문장: «ⓑ에서 학생은 내용이 어렵다는 이유로 응집성 기준을 응집성보다 낮추었다. 그러나 ⓓ는 이미 알고 있는 내용이라 응집성이 응집성 기준보다 높아 의식적인 노력 없이 읽은 경우이므로, 기준을 낮추었다고 볼 수 없다.»
   - 지문 3문단은 «응집성이 응집성 기준보다 높을 때» 와 «응집성 기준을 응집성보다 낮추게 된다» 를 같은 상태(기준 < 응집성)로 다룬다. 그런데 이유는 ⓓ 가 «응집성 > 기준» 이라고 하면서 «기준을 낮추었다고 볼 수 없다» 고 해서 앞뒤가 맞지 않고, 해설지에도 없는 주장이다(해설지는 ⓓ 가 기준을 낮추지 않았다고 말하지 않는다).
   - 해설지가 가리키는 결정적 이유는 선지가 «ⓑ와 ⓓ 둘 다 이미 알고 있는 내용이라는 이유» 라고 했는데 ⓑ 는 «지나치게 자세히 설명되어 어렵다» 는 이유로 기준을 낮춘 것이라는 점이다. 이유를 그 점 중심으로 다시 쓴다(예: «ⓓ 는 이미 알고 있는 내용이라 쉽게 읽었지만, ⓑ 는 내용이 지나치게 자세해 어려워서 기준을 낮춘 것이지 이미 알고 있어서가 아니다»).
   - evidence 의 p3 «응집성이 응집성 기준보다 높을 때 …» 문장은 ⓓ 이해용으로는 쓸 수 있으나 위 결정 이유와 짝이 되도록 이유 문장과 같이 손본다(ⓑ 의 이유가 «어려움» 임을 보이는 그림 인용 «ⓑ관절과 근육이 … 훑어 나갔다.» 는 이미 있음).

## 고치면 좋은 것

- 2번 ① 의 지문 근거가 p3 «독서 목적에 따라 높은 응집성 기준을 설정하고…» 인데, «독서 목적이 기준 조정 요인» 을 직접 말하는 p2 문장(«독자는 독서 목적, 독서 동기, …»)이 더 결정적이다. 필수는 아님.
- 2번 ③ 과 ② 가 같은 p2 문장을 근거로 재사용한다. 해설지도 요인 목록으로 설명하므로 허용 범위이나, 가능하면 «글에 대한 관심»·«내용의 중요도 평정» 을 각각 이유에 짚어 주면 좋다(이미 이유에서 짚고 있음).
