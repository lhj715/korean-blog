# 독립 검토 1차: 세트_35-37 (2025-10 고3 화법과 작문, 35~37번)

방법: 쪽 그림(13쪽)과 해설지로 먼저 풀고(35 ④, 36 ④, 37 ⑤) 세트 파일과 대조. 검사기(`세트_검사.py`)는 합격.
굵은 글씨·밑줄·문단 경계는 `get_texttrace`·좌표로 직접 확인(`_임시\검토_35-37.py`, `검토2_35-37.py`).

## 확인된 것 (이상 없음)
- 정답 3개(35 ④, 36 ④, 37 ⑤) 모두 정답표·해설지와 일치. 선지별 판정 방향도 발문("않은")과 맞다. 36·37 정답 선지는 부정 판정.
- 문단 경계: 5문단, 시작어(안녕하세요? / ([자료 1]을 / ([자료 2]를 / 판본체와 / 한글 서예의)가 쪽 그림의 들여쓰기 줄과 같다. 이 세트에는 `ranges`([A][B])가 없고 지문에도 없다.
- 굵은 글씨: <보기>의 «학생»과 숫자(1·2·3)는 type 0+1 겹침(굵음), 콜론(x 495~498)은 type 0 전용이라 보통. 비교 기준 «보통 글자»(보기 본문 «궁서체는» 등)도 type 0 전용. 세트의 `bold: ["학생1"]` 등은 맞고 콜론은 넣지 않아 맞다. 지문(발표문)에는 굵은 글씨 없음.
- 밑줄: 36번·37번 발문 «않은» 만 밑줄(PDF 선·쪽 그림 일치), 세트에 `stem_underlines` 있음. 지문·선지 밑줄 없음. 35번은 없음.
- 36번 그림: 위치(13쪽 오른쪽 상단 상자)와 `pdf_text`(`[자료 1] [자료 2] [자료 3]`)가 맞고, alt 설명은 그림 내용(자료 1 두 열의 아래아 원 표시, 자료 2 점선·마름모·삼각형, 자료 3 장봉·노봉 그림)과 어긋나지 않는다. 그림 속 옛한글(훈민정음·석보상절 글자)은 현대 한글 «슬릅사솜 / 바혀내는» 꼴로 읽혀 alt가 이를 구체적으로 적지 않았을 뿐 틀린 말은 없다.
- 36번 ② explanation_quote(«해례본에서는 하나의 점이던 아래아가»)는 해설지 36번 ② 풀이에 줄바꿈(아래/아가)만 끼고 그대로 있다. 해설지 문항도 맞다.
- 해설지 없는 선지 35 ②·⑤ (basis 자체): 판정(부적절)은 맞다. ⑤는 이유·근거 모두 타당(마무리 문단에 이해도 확인 말이 없음, 중간의 질문은 ④ 근거).

## 반드시 고칠 것
1. **겹낫표 『 』 누락 (지문 p2).** 쪽 그림에 『훈민정음』 해례본, 『석보상절』이 겹낫표로 찍혀 있고, PDF 텍스트층에는 U+F000(폭 있는 PUA 글자, x 135·188·307·360·238·291)으로 들어 있다. 세트 p2 본문은 낫표 없이 «훈민정음 해례본», «석보상절» 4곳이다. 같은 시험 다른 세트(1-3, 23-26 등)와 14-17(2026-03)은 『』를 글에 그대로 두었고, 검사기는 `『』` 를 같게 보므로 통과만 했을 뿐 화면 충실도 오류다. p2 의 «훈민정음 해례본의 일부», «훈민정음 해례본은», «석보상절의 일부», «석보상절에 쓰인» 을 각각 『훈민정음』 해례본…, 『석보상절』… 으로 고친다(발표문 p2 의 4곳: 해례본 2, 석보상절 2). evidence quote(p2 인용)에는 낫표가 든 문장이 없어 영향 없음.

## 고치면 좋은 것
1. 35 ② reason: «발표 순서를 알려 주는 말은 1문단의 대표적인 서체를 살펴보겠다는 말뿐이다.» 는 «살펴보겠다»가 순서 안내인 것처럼 읽힌다. 실제로는 순서를 안내하는 말이 없다는 점이 요지이므로 «자료를 제시하는 동작은 있으나 발표의 순서를 안내하는 말은 없다. 1문단의 «대표적인 서체들을 살펴보려고 합니다»는 다룰 대상을 밝힐 뿐 순서를 알리지 않는다.» 정도로 바꾸면 정확하다(근거 인용 2개는 그대로 둘 수 있다).
2. 37번 <보기> 본문이 «학생1 :» 로 붙어 있으나 쪽 그림은 «학생 1 :»(학생과 숫자 사이 간격, 선지는 «학생 1»)이다. 공백은 검사기가 무시하므로 통과하지만, 화면 일치를 위해 «학생 1 :» 로 쓰고 bold 를 «학생 1» 에 맞추는 것이 좋다(굵은 범위는 학생+숫자 그대로).
3. 36번 ② reason «자료 1의 두 글자를 견주어»: 그림에는 두 글자가 아니라 두 열(해례본·석보상절)이 있으므로 «자료 1의 두 부분을 견주어» 가 더 정확하다.
