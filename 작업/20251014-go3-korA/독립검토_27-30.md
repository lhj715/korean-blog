## 작업자가 자신 없다고 한 곳
1. 지문 굵은 글씨 16곳(실제 등록 17개 조각): 텍스트층에서 type=1(굵음) 이고 Haansoft Batang 글꼴인 조각이 9쪽·10쪽에서 정확히 다음과 같고, 쪽 그림에서도 굵게 보임. 등록된 목록과 하나도 빠짐·넘침 없이 일치.
   가을 / 북풍이 높이 부(`니` 는 보통) / 긴 하늘, 넓은 들(쉼표 포함, 등록 조각 «긴 하늘, 넓은 들» 로 덮임) / 저녁 눈 / 성 밖의 초목 / 매화 / 솔 / 소와 양 / 석문봉 / 석양 / 기러기 가는 듯 돌아오 / 회안봉 / 행인 / 저녁 빛 / 까마귀 / 푸른 산.
   지문의 다른 곳(㉠~㉤ 밑줄 줄, 각주, 출처 줄)에는 type=1 이 없음. 비교한 «보통 글자»는 같은 쪽 type=0 의 Haansoft Batang 임을 확인.
2. nth(몇 번째): 굵은 낱말들이 지문에서 처음 나오는 자리와 PDF 굵은 자리가 같음(예: 솔은 «서 있는 솔», «늙은 솔» 은 보통; 석양은 «석문봉에 석양이», 회안봉은 본문 «회안봉*이», 저녁 빛·저녁 눈은 각각 한 번뿐). nth 지정 필요 없음. 네모 친 «달빛» 도 쪽 그림에서 첫 등장 «기대어서 [달빛]을 기다리니» 한 곳뿐이라 nth 필요 없음. 발문 30번 네모(달빛)도 일치.
3. ㉡ 밑줄 마침표: PDF 선이 x 108~271, 마지막 글자 «가»(261~272) 에서 끝나고 마침표(272~275)는 선 밖. 세트의 ㉡ 범위(마침표 없음)가 맞음. 반대로 ㉢(선 끝 291~294 안에 마침표), ㉣, ㉤ 은 마침표를 포함하고 PDF 선도 마침표까지 닿음. 맞음.
4. 가사 빈 줄(쪽 경계) 제거: 9쪽 마지막 «본래 지닌 절개가 날이 춥다 변할쏘냐.» 와 10쪽 첫 줄 «앞산의 짙은 안개…» 사이는 연 구분이 아니라 쪽 경계일 뿐이고, 작품 전체가 연 구분 없이 이어져 있음. 빈 줄 없이 이은 것이 맞음.
