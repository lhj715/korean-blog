# 독립 검토 (2차): 세트_40-43.json (2024-07 고3 언어와 매체 40~43번)

방법: 앞 검토 결론에 기대지 않고 쪽 그림(문제 14쪽 오른쪽·15쪽 왼쪽·오른쪽)과 해설지(40~43번)로 다시 풀었다. 정답 40②·41⑤·42②·43①은 정답표·세트와 같다. 그다음 세트 파일과 대조했다. `세트_검사.py` 는 합격(해설지에 없는 선지 3개 안내: 41①·41④·42③).

## 1차에서 지적한 두 건 재확인

1. 43번 ①②의 하이픈: 세트 선지는 「종결 어미 ‘-습니까’」「연결 어미 ‘-면’」(U+002D 하이픈 있음)이고, 원본 텍스트층은 ‘습니까’·‘면’(PUA U+F000 두 곳뿐), 쪽 그림에서도 짧은 가로선이 보인다. `meta.textlayer_subs {"-":""}` 로 검사기가 같게 보고 합격한다. 화면과 원본이 같다. 고쳐졌다.
2. 41번 ④ 근거: `evidence` 에 «방송 후에 관련 기사를 찾아보니…» 와 결정 문장 «이런 시기에 오늘 방송은 정말 의미 있고 적절한 주제를 다루었다고 생각해요.» 가 모두 있다. 이유와 일치. 고쳐졌다.

## 확인한 것(문제 없음)

- 지문 글자·문단: (가) 진행자·전문가 줄마다 새 문단(17개), (나) 한 문단. 쪽 그림과 같다.
- 굵은 글씨: «진행자»·«전문가»·콜론은 Haansoft Dotum 텍스트층에서 type 0+1 겹침이고 쪽 그림에서도 굵다. 세트 `bold` 가 모든 대화 문단과 맞다. «(가)» 소제목은 세트에 굵게 있다(쪽 그림에서 (가)·(나) 모양이 본문 보통 글자보다 굵음, (나) 메모 상자 안은 보통). 댓글 창 이름(미소·샛별·낮달)의 굵은 글씨는 그림 안에 있어 alt 에 기록돼 있다.
- 밑줄: ⓐ~ⓔ 는 쪽 그림의 밑줄 범위와 같다(ⓑ 는 «…이어지는 방식입니다» 까지, ⓒ 는 마침표 포함, ⓔ 는 «말씀하신 대로…있어요.»). ㉠·㉡ 은 «슬라이드» 낱말만. 발문 «않은» 은 40·42·43번에 있고 41번 발문에는 없어 세트와 같다.
- 그림: 댓글 창·슬라이드 그림이 원본과 같고 pdf_text·alt 가 그림과 맞다(막대 값, 장점 다섯 개, 세 앱).
- 정답 방향: «않은» 40·42·43번은 정답 선지가 «부적절», 41번은 정답이 «적절». 맞다. 해설 인용이 해당 문항 해설에 글자 그대로 있고 이유에 메타 문구·em dash 없음.
- 선지별 판정(스스로 푼 결과와 일치):
  - 40: ②가 부적절(앞부분 요약 없음). 나머지는 해설지 ①③④⑤ 와 같고 인용이 각 선지의 결정 문장.
  - 41: ⑤만 적절(기사 탐색 활동으로 시의성 판단). ②③은 해설지, 나머지는 자체 판단이며 아래.
  - 42: ②가 부적절(장점만 나열, 비교 없음). ①④⑤ 는 해설지 근거, ③은 자체.
  - 43: ①이 부적절(ⓐ 는 누리 소통망 기부를 먼저 설명해 달라는 요청). ②~⑤ 해설지 근거와 일치.
- 해설지에 없는 선지(자체) 엄격 확인:
  - 41①: 미소는 학생인 처지에서 도움이 되는 정보라고 했을 뿐 전문성·정확성은 언급하지 않았다. 부적절 맞음.
  - 41④: 낮달은 다루지 않은 내용을 지적하지 않았고 방송이 의미 있고 적절하다고 했다. 부적절 맞음.
  - 42③: 슬라이드의 «푸른별지킴이»는 전문가가 말한 앱(가치걷자, 비영리 단체 앱)에 없는 또 다른 예시다. 적절 맞음. 근거 인용의 «필요 한»은 그림 줄바꿈이 낳은 띄어쓰기로 텍스트층 공백 무시 검사에는 영향 없고 내용 오류 아님.
