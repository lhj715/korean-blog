# 독립 검토 (1차): 세트_40-43.json (2024-07 고3 언어와 매체 40~43번)

방법: 쪽 그림(문제 14쪽 오른쪽, 15쪽 왼쪽·오른쪽)과 해설지(5쪽)를 보고 먼저 풀었다. 정답 40②·41⑤·42②·43①은 정답표·세트와 같다. 그다음 세트 파일과 대조했다. `세트_검사.py` 는 합격(해설지에 없는 선지 3개: 41①·41④·42③ 안내).

## 확인한 것(문제 없음)

- 지문 글자·문단 경계: (가) 대화 17개 문단은 모두 «진행자:»·«전문가:» 로 시작하는 줄에서만 새 문단. (나) 메모는 한 문단. 일치.
- 굵은 글씨: PDF 텍스트층에서 «진행자»·«전문가»·콜론 모두 Dotum type 0+1 겹침(진행자 9곳, 전문가 8곳, 콜론 포함). 1200dpi 잉크량도 보통 글자의 3배 안팎. 세트의 `bold: ["진행자:"]`·`["전문가:"]` 가 17개 문단 모두와 맞다. «(가)»·«(나)» 소제목은 type 1 만 있는 Batang 글자인데, 같은 크기의 보통 «(가)»(40번 발문, type 0 전용)보다 잉크량이 1.3~1.4배(5159·4865 대 3623)여서 굵은 글씨가 맞다. (나) 메모 상자(HancomGothic, type 0 전용)에는 굵은 글씨 없음, 세트도 없음. 발문 «[3점]» 은 보통 굵기로 세트와 같다.
- 밑줄(PDF 선 좌표와 글자 좌표 대조): ⓐ 「누리 소통망을…있습니까?」, ⓑ 「특정 행위를…방식입니다」(선이 513.7 에서 끝나고 마침표는 513.8~516.1 이라 마침표는 밑줄 밖: 세트 맞음), ⓒ 「많은 유명인이…달성했죠.」(마침표 포함), ⓓ 「그렇다면…방식입니까?」, ⓔ 「말씀하신 대로…있어요.」, ㉠·㉡ 은 «슬라이드» 낱말만, 발문 «않은» 은 40·42·43번 모두 선이 있고 세트에 있음. 41번 발문에는 선이 없고 세트에도 없음.
- 댓글 창·슬라이드 그림: 잘라 낸 그림 2개가 원본과 같고, `pdf_text`·`alt` 가 그림과 맞다(댓글 세 개 글자, 슬라이드 막대 값 약 32/15·22/6·21/36, 장점 다섯 개, 푸른별지킴이 등 세 앱). 막대그래프 축·범례 글자는 alt 에만 있고 근거 인용은 «기부 방식의 변화» 만이라 검사 방식과 충돌 없음.
- 정답·판정 방향: 발문 «않은» 40·42·43번은 정답 선지가 «부적절», 41번은 정답이 «적절». 맞다. 해설 인용은 해당 문항 해설에 글자 그대로 있고 이유에 «해설지는…» 메타 문구·em dash 없음.
- 43① 판정: 선지는 «무엇을 먼저 설명해야 하는지를 묻고 있다», 해설지는 «누리 소통망을 통한 기부부터 설명해 줄 것을 물음의 방식을 통해 요청하고 있다». ⓐ 가 이미 «누리 소통망을 통한 기부» 를 정해 놓았으므로 선지가 틀리고 정답(부적절)이 맞다. 이유도 해설지와 같은 말이다.
- 해설지의 U+F000: 해설 PDF 에서 U+F000 은 «‘-습니까’»·«‘-면’» 의 하이픈 자리다. 세트의 43번 해설 인용(①②④⑤)은 이 글자가 든 부분을 인용하지 않아 문제 없고, 이유의 «ⓑ의 '-면'» 은 하이픈이 살아 있다. 해설지 처리 자체는 맞다.
- 자체 판단(basis:"자체") 3개:
  - 41①: 미소는 «학생이어서 …부담스러웠는데 저와 같은 사람들에게 도움이 되는 정보» 라고 자기 처지를 말했을 뿐 전문성·정확성은 말하지 않았다. 판정(부적절)·이유 맞음.
  - 41④: 낮달은 «의미 있고 적절한 주제를 다루었다» 고 했으므로 «타당하지 않다고 판단» 은 틀림. 판정·이유 맞음(근거 인용 문제는 아래 반드시 고칠 것 2).
  - 42③: 전문가가 소개한 앱은 가치걷자와 비영리 단체 앱뿐이고 «푸른별지킴이» 는 언급이 없다. 슬라이드에 있으므로 적절. 판정·이유 맞음.

## 반드시 고칠 것

1. **43번 ①·② 선지 글자에서 하이픈 누락.** 원본(쪽 그림 500dpi 확인, 텍스트층 U+F000)은 ①「종결 어미 ‘-습니까’를 사용하여」, ②「연결 어미 ‘-면’을 사용하여」인데, 세트는 ①「‘습니까’」, ②「‘면’」으로 하이픈(–)이 빠졌다. 검사기가 PUA 글자를 무시해 합격했지만 화면에 나가는 선지가 원본과 다르다. 선지 글자를 원본대로 «‘-습니까’»·«‘-면’» 으로 고친다(원본 모양은 짧은 가로선이며 이유의 «'-면'» 표기와 맞춘다). 그 뒤 검사기를 다시 돌려 합격을 확인한다.
2. **41번 ④ 근거 인용이 결정 문장이 아님.** 이유는 낮달이 «오늘 방송이 의미 있고 적절한 주제를 다루었다고 평가했으므로 타당하지 않다고 판단한 것이 아니다» 라고 하는데, `evidence` 에는 첫 문장(기사를 찾아봄)만 있다. 판단을 결정하는 두 번째 문장 「이런 시기에 오늘 방송은 정말 의미 있고 적절한 주제를 다루었다고 생각해요.」를 근거에 추가한다(첫 문장은 유지).

## 고치면 좋은 것

1. 42번 ③ 근거 인용 «[푸른별지킴이] 쓰지 않는 물건을 필요 한 곳에 기부하는 앱» 의 «필요 한» 은 그림 줄바꿈 때문에 생긴 띄어쓰기다. 텍스트층 글자는 «필요한 곳» 이므로 «필요한 곳에» 로 쓰면 화면 인용이 자연스럽다(공백은 검사가 무시하므로 합격에는 영향 없음).
2. 41번 ① 근거에 «정보 전달자의 전문성은 언급하지 않았다» 를 뒷받침할 다른 인용은 필요 없지만, 이유 둘째 문장(정확하다고 판단하지도 않았다)이 있으므로 이유를 «도움이 되는 정보이군요» 쪽으로 한 문장 줄여도 된다(선택).
