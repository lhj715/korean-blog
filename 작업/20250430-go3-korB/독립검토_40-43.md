# 독립 검토 (1차): 세트_40-43.json (2025-04 고3 언어와 매체 40~43번, 뉴스 + 학생 메모)

검토 방법: 세트 파일을 열기 전에 쪽 그림(문제 14·15쪽)과 해설지(해설_글자.txt 1062~1113줄)로 먼저 풀었다.
내가 푼 정답은 40번 ④, 41번 ③, 42번 ④, 43번 ⑤ 이고, 세트 파일의 정답·bundle 정답과 같다.
`세트_검사.py` 는 합격(프로그램 검사 전 항목 통과). 해설지에 없는 선지 8개(41 ①②④⑤, 42 ①②③⑤)는 아래에서 엄격히 봤다.

## 직접 확인한 것

- 지문 글자·문단 경계: 진행자·기자·농민·연구원 발화 단위로 문단이 나뉘고, (나)는 한 문단이다. 쪽 그림과 일치.
- 밑줄: PDF 선 좌표로 ㉠(끝 x=526.0, «다» 끝 526.9), ㉡, ㉢, ㉣(끝 x=384.4 = «고» 끝, 쉼표 제외), ㉤(쉼표·마침표 제외), ⓐ, ⓑ, 발문 «않은»(40번·43번) 확인. 41·42번 발문에는 밑줄이 없고 세트에도 없다.
- 굵은 글씨: `get_texttrace` type 0+1 겹침으로 진행자·기자·농민·연구원 이름과 쌍점(진행자:, 기자:, 농민:, 연구원: 모두 콜론까지 굵음)을 확인했다. 비교 기준인 같은 줄 본문 글자는 type=0 전용이다. 세트의 `bold` 목록(이름+쌍점)이 맞다. (가)·(나) 라벨도 굵은 글씨(type 0+1)이고 label 항목이라 화면이 굵게 그린다. 게시판 그림의 «시청자 N:» 는 type 0+1 이고 알트에 «굵은 글씨» 로 적혀 있어 맞다(그림 속 굵은 글씨는 알트에만 적는 방식이라 화면 데이터로는 문제 없음). 슬라이드 1의 «2.1℃» 는 쪽 그림 1500dpi 확대로 굵고 기울임임을 확인했다(알트와 일치).
- 방송 화면 3장과 [A][B][C] 를 한 그림으로 자르고 `ranges` 를 비운 방식: 자른 그림의 오른쪽에 «…… [A]» 등이 실제로 들어 있고(쪽 그림과 비교), 표시가 pdf_text 에 있어 검사기도 통과한다. 40번 발문의 «[A] ~ [C]» 를 독자가 그림에서 바로 찾을 수 있으므로 타당하다. 상자 테두리 선이 걸리지 않게 잘렸다.
- raster_text 대조(쪽 그림 500dpi 확대): A «기후 변화로 인한 농업의 변화», B «농업 연구소»·«김○○ 기자»·▶, C «박△△ / □□농업 연구소 연구원», 게시판 탭 «시청자 게시판», 슬라이드 2 «기후 변화에 대비하는 농업»·«*참고 자료», 슬라이드 1 제목·«우리나라 연평균 기온 변화»·«기온(℃)»·«●연평균 기온»·연도 축 1993/2003/2013/2023·«연도»·«재배 한계선 북상», 그래프 값 12.0/12.8/12.5/14.1 은 모두 일치. 아래 «반드시 고칠 것» 1건만 오류.
- 40~43번 각 발문, 선지 글자, 정답, 판정 말(40·43번 «적절하지 않은» → 정답 판정이 부적절)은 일치.

## 고치면 좋은 것

1. 42번 ③ 이유(basis 자체): «예전에는 사과 농사를 지을 수 있다고 생각하지 못했다는 뜻이다» 는 지문에 없는 의미를 보탠다. 지문은 «사과 농사는 생각도 못 했는데» 이므로 «생각조차 하지 못했다는 뜻이다. 의도해서 하지 않은 것이 아니다» 정도가 지문에 더 가깝다. 판정(부적절)은 맞다.
2. 42번 ⑤ 이유(basis 자체): 판정은 맞지만 «-겠-» 이 여기서 무엇을 나타내는지(필요하겠습니다 = 필요하다는 화자의 판단을 조심스럽게 말함) 한 마디가 있으면 선지의 «의지» 와 대비가 분명해진다. 지문 밖 설명이 아니라 문장 안 풀이 수준이면 충분하다. 필수는 아님.
3. 41번 ①·② 근거: 선지가 «기자 발화의 일부» 에 주목했다고 하므로 해당 기자 발화(p2 «주요 과수와 작물의 재배 지역이 달라지고 있습니다», «새로운 재배 방법을 모색하는 농가가 늘고 있습니다»)를 passage 근거로 하나씩 더 달면 선지 앞부분이 맞다는 것까지 보인다. 판정에는 영향 없음.
