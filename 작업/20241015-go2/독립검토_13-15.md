# 독립 검토 13~15번 (go2, 2024-10 고2 문법 단독 묶음)

검토 방법: 문제 PDF 5쪽(인덱스 4)을 쪽 그림과 get_texttrace 로 먼저 보고 13~15번을 스스로 풀었다(13번 ④, 14번 ①, 15번 ②, 해설지와 같음). 그다음 세트 파일과 대조했다. 프로그램 검사(`세트_검사.py`)는 합격.

## 확인한 것(문제 없음)
- 13~15번 정답(4·1·2)과 선지별 판정, 발문 방향(14·15번 «않은» 정답 선지가 부정/부적절) 모두 맞다. 13번 음운 변동 횟수(㉠ 2, ㉡ 2, ㉢ 1)와 이유는 해설지·원문 규칙과 일치.
- 굵은 글씨(get_texttrace type 0+1 겹침으로 직접 확인): 14번 «선생님»·«학생» 글자만 굵고 뒤의 «:» 는 type=0 전용(보통). 세트의 bold 목록과 같다.
  15번 탐구 자료는 «[탐구 자료]王薦(왕천)의 아비», «아ᄃᆞ리», «하ᄂᆞᇙ», «너를», «[현대어 풀이]» 가 굵고 病·神人·孝道·皇帝 등은 보통. 세트의 bold 목록과 같다. 쪽 그림 확대로도 일치.
- 밑줄: 14·15번 발문 «않은» 선 있음(stem_underlines 등록). 14번 선지 ①~⑤ 밑줄 낱말 10개 모두 쪽 그림에 있고 등록됨. 13번은 해당 없음.
- 옛한글 그림: 15번 <보기>·탐구 자료 display_image 는 쪽 그림과 같은 글자·굵기(탐구 자료 그림에서 굵은 부분 확인). 선지 ③ 그림(ᄃᆞ) 맞음.
- 14번 판정의 evidence 가 5개 모두 같은 보기 문장이라 변별력은 약하지만, 선지 자체가 근거 예문이라 허용 범위로 본다(고치면 좋은 것).

## 반드시 고칠 것
1. **15번 ③ 이유, ④ 이유에서 낱말이 화면에서 깨진다.** `reason` 이 «‘아리’는 자음으로 끝난 체언이므로…», «‘하’은 무정 체언이므로…» 로 옛한글 PUA 글자가 빠져 있다(PUA 가 없는 문자열이라 «아리», «하» 로만 보임: «하’은» 은 학생이 읽으면 오탈자). 선지 안은 choice_images 로 그림이 끼지만 `reason` 에는 그림 장치가 없다. 옛한글 낱말을 직접 쓰지 말고 «밑줄 친 체언은…», «탐구 자료의 해당 체언은…» 처럼 풀어 쓰거나 현대어로 바꿔 쓴다(예: ③ «이 체언은 자음 ‘ㄹ’로 끝나므로 주격 조사 ‘이’가 쓰였다», ④ «이 체언은 무정 체언이므로 관형격 조사 ‘ㅅ’이 쓰였다»).
2. **15번 선지 ④ choice_images 의 `alt` 가 틀렸다.** 현재 «ᄂᆞᆯ» 이지만 그림(PDF 글자 U+E28C, 쪽 그림 확대)과 해설지 흐름은 ‘하ᄂᆞᇙ’(ᄂᆞ+ᇙ, ㄹㅎ 받침)이다. alt 를 «ᄂᆞᇙ»(하늘의 옛 낱말) 로 고친다. (③ alt «ᄃᆞ» 는 맞음.)

- 15번 ⑤ evidence 의 «너를» 은 지문(탐구 자료) 속 낱말이므로 `source: bogi` 로 맞게 달려 있음(문제 없음, 참고).
