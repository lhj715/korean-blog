# 독립 검토 35~38번 (1차) — (가) 조성신 ｢개암정가｣ + (나) 김창협 ｢청청각기｣

검토 방법: 쪽 그림(12·13쪽 확대)과 해설지(5쪽)로 먼저 풀고(35 ②, 36 ⑤, 37 ④, 38 ④) 세트 파일과 대조. `세트_검사.py` 는 «합격» (해설지 없는 선지 35 ①③④⑤ 안내만 나옴).

## 확인한 것 (이상 없음)
- 정답 35=②, 36=⑤, 37=④, 38=④ 맞음. 36·37·38 «않은» 밑줄 PDF·쪽 그림 모두 있음. 점수 2·2·2·3(38 [3점]) 맞음.
- 문단 경계: (나) 4개 문단 시작 x 좌표가 들여쓰기(450, 13쪽 ㉣ 줄 104 vs 본문 94)로 일치. (가)는 연 구분 없음, (중략) 가운데 줄 맞음.
- 굵은 글씨(get_texttrace type 0+1 겹침 + 쪽 그림): 세트 파일의 (가) v1 7곳, v2 3곳, (나) p3 5곳, p4 5곳이 PDF 와 정확히 일치(조사 «은»·«의좋은» 제외, 낱말 쪼개짐 «샘|물에», «밝|은 본체», «이|누각에…» 포함). 빠지거나 더해진 곳 없음. «이군» 은 p3·p4 모두 첫 번째 등장만 굵음(맞음).
- 작업자 의문 1 «띄워 있다»·«벌려 있다» 끝 글자 '다': 굵지 않다. 해당 '다'는 별도 type 0 조각이고, 8배 렌더 잉크량이 같은 쪽의 보통 '다'와 같다(1033 대 1033, 굵은 '있'은 1744). 뺀 것이 맞다.
- 작업자 의문 2 (나) p3 «이군» 굵기: «이군» 만 type 1, «은» 은 아님. 맞다.
- 작업자 의문 3 37번 발문 «㉠~㉤»: 쪽 그림은 «㉠ ~ ㉤» 처럼 글자 사이가 벌어져 보이나 36번 «ⓐ ~ ⓔ» 와 같은 글자체 간격이다. 띄어쓰기는 검사기가 무시하고 영향 없다.
- 작업자 의문 4 36번 <보기> 표 그림: 쪽에서 잘라 낸 그림(ⓐ~ⓔ, 입몽·개암정 방문·경관 감상·개암정 모임·각몽)이 원본 표와 같고 테두리 선도 걸리지 않았다.
- 36·37·38 해설지 인용은 모두 해당 문항 해설과 글자 그대로 맞고 판정과 같은 말이다. 38 ④ 이유가 해설지의 판단(내면을 잊으면 안 됨)과 같다. 이유 문장에 em dash·«해설지는…» 메타 문구 없음.
- 35번 해설지 없는 선지(자체) 엄격 검토: 판정(①③④⑤ 부적절)은 모두 맞고, 이유의 사실 관계도 지문 안에서 맞다.
  - ① (가)에 «취병»(翠)·«백구»(白)가 있어도 색을 맞세우지 않음, (나)에도 없음 → 맞음.
  - ③ (가)는 «어디메뇨 … 여기로다» 의 자문자답이 있어도 (나)에 문답이 없음 → 공통점 아님, 맞음.
  - ④ (가)의 꿈은 가정 표현이 아니고 (나)의 «만일 … 할 수 있다면» 은 이를 수 있는 일을 가정함 → 맞음.
  - ⑤ (가) «백구에게 길을 물어» 만 있고 (나)는 자연물에 말을 건네지 않음 → 맞음.

## 반드시 고칠 것
1. **(가) 한자 오독 3곳이 화면에 그대로 나온다.** PDF 텍스트층 글자가 쪽 그림과 다르다(한글 글자로 잘못 매핑되어 PUA 도 아니라 `display_image` 규칙 밖).
   - v1 «청산벽계(복山碧溪)» → 그림은 «靑山碧溪» (복 = 靑)
   - v1 «수충대(드忠臺)» → 그림은 «輸忠臺» (드 = 輸)
   - v2 «소학사(蘇學士) 옛 풍류(빌流)를» → 그림은 «風流» (빌 = 風)
   근거: 12쪽 그림(왼쪽 위 `c_right1.png` 상당: 청산벽계·수충대 줄 / v2 «소학사» 줄). 학생이 틀린 한자를 본문으로 읽게 되므로 게시 전에 바로잡아야 한다. 작업자가 고칠 수 없는 한계(검사기 B1 이 텍스트층과 글자 일치를 요구)이므로 **주 세션이 도구에 «텍스트층 오독 교정표»(예: 항목별 `text_fix: {"복山":"靑山", …}` 을 검사기·화면이 알도록) 를 추가**하거나, 해당 항목에 한해 교정 방식을 정해 준 뒤 세트에 반영한다. 이 3곳 외에는 (가)·(나) 한자와 한글 모두 쪽 그림과 일치.
   → 도구가 정해지면 이 세트만 해당 부분을 바로잡고 검사기 재통과만 확인하면 된다(2차 검토는 이 부분 확인으로 충분).

## 고치면 좋은 것
1. 35번 ① 근거 2: 인용 «투명한 유리병이나 맑은 가을달과 같았던 연» 이 낱말 «연평» 한가운데서 끊긴다. 이유(색채 대비 없음)와도 직접 연결이 약하다. «그의 용모는 들판의 학과 같고 그의 기운은 깊은 숲 속의 난초와 같으니» 처럼 (나)의 비유 장면을 쓰거나, 최소한 «…맑은 가을달과 같았던» 까지로 끊는다.
2. 35번 ③ 근거 2: p3 «비록 그렇긴 하지만 환경은 외물이고 일은 거친 자취이다.» 는 이유(묻고 답하는 방식이 없다)와 연결되지 않는다. (나)가 문답이 아니라 서술·역접으로 전개됨을 보이는 문장으로 바꾸고 이유에 한마디 덧붙이면 좋다.
