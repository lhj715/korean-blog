# 2026-03 고3 국어(화법과 작문, korA) 38~42번 «학생 N» 굵기 재확인

검토 방법: 원본 PDF(`20260324-go3-problem-korA_mun_95U73553.pdf`)를 두 가지로 확인했다. 파일은 고치지 않았다.

1. PDF 글자 굵기 표시. `get_texttrace` 에서 같은 글자 상자에 type=1(테두리 겹쳐 찍기, 굵게 만드는 표시)이 있는지 본다.
2. 1200dpi 렌더에서 글자 하나하나의 가로 검은 픽셀 연속 길이 중앙값(획 두께)과 잉크 면적 비율을, 같은 쪽의 보통 글자와 나란히 비교한다.

## 1. 판정: 숫자 1·2·3 은 굵다, 콜론(:)은 보통이다

### PDF 글자 굵기 표시

| 위치 | «학생» | 숫자 | 콜론 |
|---|---|---|---|
| 14쪽 (나) 대화줄 16개 (p13~p28) | type=1 있음 | type=1 있음 | type=1 없음 |
| 15쪽 42번 상자 «학생 2:», «학생 3:» (b4, b5) | type=1 있음 | type=1 있음 | type=1 없음 |
| 13쪽 37번 <보기> «학생 1~3:» (참고) | type=1 있음 | type=1 있음 | type=1 없음 |
| 14쪽 (가) «진행자:», «담당자:» (참고) | 이름 type=1 있음 | 해당 없음 | type=1 없음 |

(나) 대화줄 16개와 42번 상자 2개 모두 «학생» 과 숫자는 같은 상자에 type=1 이 겹쳐 있고, 콜론은 어느 줄에도 없다.

### 1200dpi 획 두께 (같은 쪽 보통 글자와 비교)

| 글자 | 굵음 | 보통 |
|---|---|---|
| 숫자 1·2·3 (학생 N 줄) | 11.0px | 8.0px (14쪽 (가) 담당자 대사 속 «151»의 1·2) |
| 한글 «학생» | 10.5px | 8.0px (본문 한글 중앙값) |
| 콜론 | 12px (점 너비) | 12px (진행자·담당자 줄, 본문 콜론과 같음) |

- 잉크 면적 비율도 같은 결과다. 숫자 1 은 굵은 것 0.159 대 보통 0.106, 숫자 2 는 굵은 것 0.211 대 보통 0.138이다. «학생» 은 0.242 대 0.146 이다.
- 숫자는 «학생» 과 똑같이 굵은 쪽(11px 대 8px)이다. 3월 38~42번 2차 검토의 «숫자는 보통 굵기» 판정은 틀렸다.
- 콜론은 점이라 획 두께로 가르기 어렵지만, 굵은 줄의 콜론과 보통 줄의 콜론이 같은 값(12px, 잉크 0.06)이고 type=1 도 없다. 보통이다. 37번 <보기> 와 5월 시험 판정과 같은 결론이다.
- 42번 상자(15쪽)도 14쪽 (나)와 같은 값이다(숫자 11px, 한글 10.5px, 콜론 12px).
