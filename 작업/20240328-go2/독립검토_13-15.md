# 독립검토 1차: 세트_13-15.json (문법 단독 13~15번, guide 없음)

## 스스로 푼 결과 (세트 파일 열기 전)
- 13번: ① 일찍이(부사 어근 + -이 = 부사, 품사 불변). 14번: ④(ⓐ 조건이 아니다, ⓑ [ㄲ], ⓒ 있다). 15번: ③(ⓐ·ⓒ=㉠, ⓑ·ⓓ=㉡, ⓔ=㉢). bundle 정답·해설지(13·14·15번 해설)와 같음.

## 대조 결과
- 정답 3개, 선지별 판정 모두 맞음. 13번 «않은» 발문의 정답 ①이 부적절(부정)로 일치. 해설지 인용(explanation_quote)은 해당 문항 해설에 글자 그대로 있고 이유는 해설지·<보기> 안의 말만 씀. 메타 문구·em dash 없음.
- 근거 인용: 13번 ②~⑤는 <보기>에 선지 단어를 직접 가리키는 문장이 없어 ㉠ 정의와 '웃음' 예시 문장을 쓴 것이 불가피하다(해설지 판단 자체가 단어 분석). 14번 ①②④와 15번 ①⑤의 근거 겹침은 같은 빈칸·같은 분류 항목을 판단하는 선지라 정당하다. 모두 허용.
- 굵은 글씨(`get_texttrace`, 쪽 그림): 13번은 문항 번호 «13.» 외에 type 1 없음(굵은 글씨 없음 확인). 14번 type 0+1 겹침은 «학생»(x105~126), «선생님»(105~137), «[자료]», «[탐구 과정]», «[탐구 결과]» 이고, 콜론은 x129·x139 로 type 0 단독이라 보통. 15번은 «[현대어 풀이]» 만 type 0+1. 데이터와 일치. 15번 보기 2 본문·선지에 type 1 없음.
- 밑줄(PDF 선): 13번 ㉠ 정의구와 발문 «않은»(x652~673) 일치. 15번 ㉠(x489.7~641.3, 쉼표 x642 제외), ㉡(마침표 제외), ㉢(마침표 제외)이 데이터와 같고, ⓐ(547~580)·ⓑ(459~480)·ⓒ(612~644)·ⓓ(545~567)·ⓔ(두 줄)도 일치. 14번 발문에는 밑줄 없음. 14·15번 ⓐ~ⓒ 네모 3개(14번)는 PDF 사각형과 맞음.
- <보기 2> 옛한글 그림(`display_image`)은 쪽에서 오려 낸 본문 전체이며 밑줄·ⓐ~ⓔ 모양이 원본과 같음. 문단 경계(<보기 1> 한 문단, 14번 대화·탐구 과정 항목)도 쪽 그림과 일치.
- `세트_검사.py` 합격.

1. 선지 표 머리의 기호 밑줄 누락 (14번 ⓐ ⓑ ⓒ, 15번 ㉠ ㉡ ㉢). 원본 PDF 에서 이 기호 아래마다 가는 선이 있다.
   - 14번 머리: y712.6, x156.1~167.0(ⓐ), 238.1~249.1(ⓑ), 303.3~314.3(ⓒ). 쪽 그림 `문제_6쪽_왼쪽.png` 에서도 ⓐⓑⓒ 밑에 선이 보인다.
