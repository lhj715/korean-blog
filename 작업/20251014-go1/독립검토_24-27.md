## 확인한 것
- 프로그램 검사: 합격(전 항목 통과). 해설지 없는 선지 8개 표시는 아래에서 직접 봄.
- 문단 경계: (가) 4문단, (나) 4문단, (다) 4문단. 쪽 그림의 들여쓰기와 일치(「또한 돌봄 로봇은 편의성이」는 새 문단 아님). 해설지의 «(다)의 4문단» = p15 와 맞음.
- [A]: 8쪽 그림에서 대괄호가 «물론, 돌봄 로봇은 … 정서적 안정감을 높였다는 평가를 받았다» 만 감싼다. 이것이 p14 전체이므로 `ranges` 를 p14 로 둔 것이 맞다. 텍스트층에서 [A] 가 25번 ⑤ 뒤에 찍혀 있어도 데이터에서는 지문 쪽에 있어야 하므로 옮긴 판단은 옳다.
- 24번 수첩 상자(`choices_in_box`): «(가)와 관련하여,» «(나)와 관련하여,» 는 `get_texttrace` 에서 type 0+1 겹침(쉼표까지)이라 굵은 글씨가 맞다. label 항목은 CSS 가 이미 굵게 그리므로 `bold` 는 중복이지만 해가 없다. 소제목이 아닌 ◦ 항목(q1~q5)은 type 0 만이라 보통 글씨, 데이터와 일치. 선지 번호 ①~⑤ 가 점선 뒤에 붙은 상자 모양도 원본과 같다. 발문 밑줄 «없는» 도 그림과 일치.
- 26번 «선생님:» 은 «선생님» 0+1, «:» 1 이라 굵은 글씨, 그림 확대에서도 굵다. 발문 밑줄 «않은» 일치. 지문·<보기> 상자에 다른 굵은 글씨 없음(8·9쪽 전체에서 type 1 이 걸린 것은 머리 안내문·번호·라벨뿐이며 모두 도구가 알아서 굵게 그림).
- 27번 <보기> 상자: «< 보 기 >» 머리말, 본문, 오른쪽 출처 줄 모두 일치.
- 이유 문장: em dash 없음, «해설지는…» 메타 문구 없음, 문단 번호 표기((가) 1~4문단, (나) 1~4문단, (다) 1~4문단) 모두 맞음.
- 해설지 인용(`explanation_quote`)은 모두 그 문항 해설에 있고 해설지의 판단과 같은 말이다. 해설지가 25번에서 («(다)의 4문단 … (가)의 사회적 구성론을 반영») 덧붙인 부분을 세트가 쓰지 않은 것은 선지 판정에 지장 없음.

- 25① 적절. 결정적 문장은 p3 «사회나 문화적 요인에 구애받지 않고 독자적으로 발전하며». 선지는 «문화적 요인의 영향을 받아» 라 정반대. 이유·근거 일치.
