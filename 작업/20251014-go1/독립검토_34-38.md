검토 방법: 세트 파일을 열기 전에 쪽 그림(12·13쪽)과 해설지(4쪽)로 스스로 풀었다. 정답은 34②, 35③, 36③(ⓒ), 37②, 38⑤로 세트 파일·정답표와 같다. 프로그램 검사(`세트_검사.py`)는 합격(해설지에 없는 선지 8개 안내만 나옴).

## 확인한 것(문제 없음)

- 지문 글자: 문단 경계(들여쓰기)·대화 문단 구분 맞음. 쪽·단 경계 처리 맞음: «민멸|되어» 는 단 경계라 `cont:"join"`(공백 없이 이음), «태우게|되니» 는 쪽 경계에 띄어쓰기가 있어 `cont:true`.
- 『사기』: 텍스트층에서 U+F000(PUA)이라 `a1a` 를 `display_image` 로 처리한 것이 맞다. 그림(그림_34-38_a1a.png)이 『사기(史記)』와 ㉡｢백이전(伯夷傳)｣ 밑줄(괄호 포함, ㉡ 기호 제외)을 정확히 담았다.
- 밑줄: ㉠ «칠월시(七月詩)»(기호 제외) 맞음. 36번 감상문 ⓐ~ⓔ 는 쪽 그림 3.5배 확대에서 마침표 앞에서 끝나고 기호는 밑줄 밖임을 확인, JSON 과 일치. 발문 «않은» 밑줄 35·36·38번 맞음(34·37번은 밑줄 없음, 맞음).
- 굵은 글씨(직접 `get_texttrace` type=1 목록과 5배 확대 그림으로 확인): (가) 농사 / 인명(人命) / 하늘이 만 / 천민(天民)이 되어 나서 본업 / 처자식 / 배불리 먹 / 항산(恒産) / 선심(善心) / 밤이거든 글을 읽어 / 충효를 본을 삼, (나) 체를 만들어 파는 일 / 어버이 / 아이 / 추위와 배고픔 / 벼슬한 자들 / 스스로(2번째, 줄 y722) / 남을 잡스럽다고 / 체를 만드는 것과 글을 짓는 것 / 재료(2번째, «천한 재료», y809) / 소득 / 차이만 있(2번째, y843) / 무형(無形)의 형벌 / 벗어나 / 구애되는 바가 없게 되었. 세트 JSON 의 `bold` 와 빠짐·넘침 없이 일치. «하늘이 만» 뒤 «들었으니» 는 보통 글씨(확대 확인). nth 도 모두 맞다.
- 구간 [A]~[E] 줄 범위: 쪽 그림 괄호와 일치. 36번 상자(머리말 없음)·38번 <보기> 라벨 맞음.
- 판정(적절/부적절)·정답·해설지 인용(34②, 35전체, 36전체, 37②, 38전체): 해설지와 일치. 인용도 그 문항 해설에 글자 그대로 있다.

## 반드시 고칠 것

1. **37번 ⑤ 이유**: «㉠은 아이들에게 농사의 뜻을 일러 주는 글이고» 는 지문에 없는 단정이다. «어와 아이들아 자세히 들어보라» 는 ㉠(칠월시) 다음에 화자가 아이들에게 말을 거는 대목이지, ㉠이 아이들에게 가르치는 글이라는 근거가 아니다. 근거 인용(v2 «어와 아이들아…»)도 ㉠ 자체를 보여 주지 못한다. 고칠 방향: 인용을 «가색(稼穡)의 간난(艱難)*을 글마다 이르시니 / 주공의 ㉠칠월시…» 로 바꾸고 이유를 «㉠은 농사일의 힘듦을 이른 시로 화자가 감동할 만하다고 말하는 것일 뿐, 사회 전체가 함께 겪는 집단적 문제를 표현하는 것이 아니다» 꼴로. ㉡ 쪽(체 장수가 읽은 글)은 그대로 둬도 된다.
2. **34번 ③ 이유**: «(가)는 칠월시를 읊으라고 권하고» 는 사실과 다르다. 원문은 «읊으며 노래 불러 뉘 아니 감동하리» 로 권유가 아니라 감동하리라는 설의다. «(가)는 칠월시를 읊고 노래하면 누구나 감동한다고 말하고» 정도로 바로잡는다.
3. **37번 ③ 이유(㉡ 부분)**: «㉡도 … 낭독 소리의 격렬함을 보여 준다» 는 ㉡(백이전)이 아니라 읽는 소리에 대한 설명이다. ㉡은 체 장수가 낭독한 글이고 그 소리에 놀라 글쓴이가 찾아가게 된다는 쪽으로 쓴다(해설지가 ②에서 쓴 방향과 같다). 근거 인용(a1b «어조가 격렬하고 오열하여…»)은 두어도 되나 이유 문장과 짝이 맞게 고친다.

## 고치면 좋은 것

- 37번 ① 이유의 ㉡ 인용 a1a «깊어지자 … 알아듣지 못했다» 는 «상대의 처지를 짐작하게 하는 계기가 아님» 을 보이는 결정 문장이 아니다. «누가 읽었냐고 묻자, 방금 전에 ｢백이전｣을 읽은 사람이 말했다» 처럼 호기심으로 찾아간 대목으로 바꾸면 더 낫다(②와 같은 문장 재사용은 피한다).
- 34번 ⑤ 이유 «(가)는 봄 한 철이 나올 뿐» 은 (가)에 월삭·낙세·흉년 같은 말도 있어 약간 좁다. «계절이 돌아오는 순환을 말하지 않는다» 쪽이 안전하다.
- 34번 ④ 인용 v2 «대순은 성인으로 역산에 가 밭을 갈고» 는 «직유가 없음» 을 보이는 근거라기보다 예시다. 허용 범위지만 «대순은 성인으로 역산에 가 밭을 갈고 … 신야 이윤이와 남양 제갈량이» 처럼 사례를 곧바로 나열한다는 점을 이유에 분명히 쓰면 좋다.
