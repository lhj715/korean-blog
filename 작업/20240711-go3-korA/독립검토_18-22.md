# 독립검토 18~22번 (세트_18-22.json, 2024-07 고3 korA) 1차

검토 방법: 세트 파일을 열기 전에 6~7쪽 그림(문제_6쪽.png, 문제_7쪽.png)과 해설지(2쪽 하단 «18~22» 해설)로 문항을 직접 풀고, 그다음 세트 파일과 대조했다. 프로그램 검사(`도구\세트_검사.py`)는 «합격», 해설지에 없는 선지 2개(18번 ②, 18번 ④)만 별도 확인 대상으로 표시됐다.

## 1. 스스로 푼 결과와 세트의 일치

- 18번: ③ (과장된 표현, 해설지 18번 본문). ①⑤는 해설지에 있고 ②④는 없음. 세트 정답 3, 판정 일치.
- 19번: ② ([B] 제비 비비, 한숨). 해설지 19번과 일치. 세트 정답 2.
- 20번: 적절하지 않은 것 ④ (㉣은 절망적 상황의 운명에 대한 마음을 묻는 것). 해설지 20번과 일치. 세트 정답 4, 정답 선지 판정이 «부적절»로 발문 방향과 맞음.
- 21번: ① (근원에 대한 인식, 보이는 것에만 주목). 세트 정답 1.
- 22번: 적절하지 않은 것 ③ (달에 그리운 임을 빗댐, 시비 분별 안 됨 아님). 세트 정답 3, 판정 «부적절»로 맞음.
- 5문항 모두 선지 5개의 적절/부적절 판정이 내 풀이·해설지와 같다. 판정 오류 0건.

## 2. 해설지 없는 선지 (basis: "자체") 엄격 확인

- 18② (자체): (가)는 제1장 장부의 할 일(효제충신), 제2장 남산 솔(난 후), 제3장 제비, 제6장 매화로 장마다 소재가 달라 «유사한 시구의 점층적 나열»이 아니다. 사실에 맞고, 이유가 지문 안 내용(제1·제2장 구절)만 쓴다. 근거 인용 2개(`장부의 하올 사업 아는가 모르는가`, `남산에 많던 솔이 어디로 갔단 말고`)는 v1 안에 글자 그대로 있고 이유와 연결된다. 통과.
- 18④ (자체): (나)의 끝부분(`죽기도 운명이요 살기도 하늘이니`, `삼년 가뭄도 원통함에서 일어나도다`)이 운명론과 원통함이라는 서술은 지문에 맞는다. 판정(부적절)은 옳다. 다만 아래 «고치면 좋은 것» 1번 참고(㉣ 물음 활용).

## 3. 굵은 글씨 직접 측정 (get_texttrace, type 1 겹침 + 쪽 그림 확대)

비교 기준 «보통 글자»는 같은 줄의 type 0 전용 글자(예: `남산에`, `이 그다지도 날랠시고`, `지켰더니`)이고 글꼴은 전체가 Haansoft Batang 으로 같다. type 1 겹침 글자만 굵은 글씨로 읽었다.

- (가) 6쪽 왼쪽: 굵은 글씨 = 많던 솔 / 난(亂) 후 부근 / 우로(雨露) / 창밖 / 세우(細雨) / 뜰 가 / 적객 / 의 회포 / 제비 비비(飛飛) / 설월 / 매화 / 창(`창을 여니`) / 향기(`향기로다`) / 호접. 세트의 bold 목록과 14곳 모두 일치.
  - 각주 별표(`*`)는 위첨자로 따로 찍혀 있고 type 0 이라 보통 글씨다. 작업자가 «적객»과 «의 회포»로 나눈 것이 맞다(별표만 굵지 않음). 부근 뒤, 우로 뒤 별표도 보통.
  - `창` nth 2: v1 에서 `창`은 `창밖`(1번째), `창을 여니`(2번째) 두 번뿐이고 굵은 것은 `창밖`의 창과 `창을 여니`의 창이다. 맞다. `향기`는 2번 나오고(향기로다, 이 향기 알면) 굵은 것은 첫 번째(향기로다)뿐이라 nth 생략(기본 1번째)이 맞다.
  - [A][B][C] 표지(`[`, `A`, `]`)도 type 1 이지만 이것은 구간 표시이며 `ranges` 로 처리되므로 본문 굵기와 무관.
- (나) 6쪽 오른쪽: 백옥 같은 / 마음 / 무서리 섞어 치 / 뜻밖의 회오리바람 환해 / 억만 길 못에 빠 / 달 / 예전에 보던 낯빛. 세트와 일치. `마음`·`달`은 각 항목 안에서 한 번뿐이라 nth 불필요.
- (다) 6쪽 오른쪽·7쪽 왼쪽: 굵은 글씨 = 작은 샘 / 더럽게 여 / 사람(`아, 사람이`, d4 의 첫 번째) / 버림을 당하는 / 윗사람 / 마음의 곡직에는 근본하지 않. 세트와 일치. d4 에서 `사람`은 4번 나오지만 굵은 것은 첫 번째뿐이다(기본 1번째 맞음). 더럽게 여 뒤 `겨`, `근본하지 않` 뒤 `으니`는 보통.
- (다)·발문·선지·<보기>에 굵은 글씨는 이 밖에 없다. 문항 번호(`18.`)·(가)(나)(다) 소제목의 굵기는 번호/label 형식이다.
- 지시문에 적힌 «나»(v2 4번째)는 이 세트에는 없다(다른 세트 내용). 이 세트의 v2 굵은 목록은 위와 같고 모두 맞다.

## 4. 밑줄·네모·구간

- 지문 밑줄 ㉠~㉤은 쪽 그림과 PDF 선(C3)에서 모두 확인. ㉤ 밑줄은 `아는가.`의 마침표까지 포함하고(확대 그림), 세트의 `세상 사람들은 과연 물의 근원을 아는가.` 와 같다.
- 발문 밑줄 «않은»: 20번·22번에 있다(`stem_underlines`). 쪽 그림과 일치하고 18·19·21번 발문에는 밑줄이 없다(맞음). 선지 밑줄은 이 5문항에 없다.

## 6. 정답·판정·근거·이유 점검 요약

- 해설지 인용(`explanation_quote`)은 18~22번 해당 문항 해설에 글자 그대로 있고(검사기 E 항목 통과), 문항 간 혼입이 없다.
- 근거 인용은 지문·<보기>에 글자 그대로 있고, 선지마다 그 선지의 결정 문장을 가리킨다. 다른 선지 근거를 재사용한 곳은 없다.
- 이유 문장에 em dash, «해설지는…» 메타 문구는 없다.
- 글자: (다)의 `강· 회· 하· 한`, `반총· 동백· 곤륜· 민산`의 가운뎃점 뒤 공백은 PDF 텍스트층에 실제로 들어 있는 것이다. 검사기는 공백을 무시하고, 쪽 그림에서는 좁은 간격으로 보인다. 지적하지 않는다.

## 8. 고치면 좋은 것 (필수 아님)

1. 18④ (자체): 판정은 맞지만 이유의 힘이 약하다. 지문 v2b 에 `지하 북풍에 죽을 운명 벗기실까`(㉣)처럼 하늘이 운명을 벗겨 줄지 «묻는» 대목이 있어 «확신»이 아니라 불확실한 물음이라는 점이 더 직접적인 근거다. 이유에 한 문장 추가하고 이 구절을 근거 인용에 넣으면 좋다(지문 안 내용이라 규칙에 맞는다).
2. 18① 이유의 «봄비 속 제비», «눈 속 매화», 19③ 이유의 «눈 속에서도 향기를 풍기는 매화»: 지문에는 `세우(細雨)`, `설월`, `매화`만 있고 «봄»이나 «눈 속»이라는 말은 없다(설월 풀이를 지문 밖 지식으로 덧붙인 것). 해설지 문구 «추운 ‘설월’의 상황에도 향기를 풍기는 ‘매화’»나 «계절감이 드러나는 시어»에 맞춰 «가랑비», «설월» 같은 지문 속 낱말로 바꾸면 안전하다.
3. 21⑤ 근거 인용 2번째(`나는 또 말하기를`)는 이유(맹자 인용이 발생 원리를 이해하는 새 방법이 아님)와 직접 연결이 약한 조각이다. 이유에 맞게 `반드시 그 근원에 근본하라` 쪽 문장으로 바꾸거나 해당 인용을 빼는 편이 낫다(해설지 판단은 그대로 유지).
4. 22③ 근거 2번째(`매화나 보내고자 역로를 바라보니`)는 «그리운 임» 맥락 보조일 뿐 결정 문장이 아니다. 결정 문장 `처마 위에 뜬 달을 예전에 보던 낯빛인 듯`은 이미 첫 번째 인용이라 판정에는 지장이 없다.
