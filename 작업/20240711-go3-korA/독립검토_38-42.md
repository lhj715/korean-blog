   - PDF 선 그림: 15쪽에서 가로 밑줄은 y=375.1(40번 «않은»), y=624.6(41번 «않은»), 그리고 (43~45) 쪽 y=512·524·536 뿐이다. 41③ «필요성»(x 125.9~156.0, y 682~690) 아래에는 선이 없다.
   - 400dpi 로 확대한 쪽 그림에서도 41번은 발문 «않은» 만 밑줄이다(`_임시\z41.png`). 43번 (가) 의 «필요성» 밑줄(㉢)과 헷갈린 것으로 보인다.
   - 검사기는 «선지 밑줄 누락»(C9)만 보고 «없는 밑줄을 등록»한 것은 못 잡아 합격했다. 화면에 원본에 없는 밑줄이 그려진다.
   - 조치: 41번에서 `choice_underlines` 를 지운다.

## 직접 확인해서 맞은 것
- **굵은 글씨(get_texttrace type 0+1, 글꼴 Haansoft Dotum 7.5):** «학생 N:» 17곳(학생1·2·3, 숫자와 콜론까지 전부 type 0+1)이 모두 굵고 세트의 `bold` 와 일치한다. «(가)»·«(나)» 소제목(Batang 7.5)도 type 0+1 이라 굵고 등록돼 있다. 보통 기준 글자(Batang 7.7)는 type 0 전용임을 확인했다. (나) 본문, 발문·선지·<보기>(Batang 7.7)는 전부 type 0 이라 굵은 글씨 없음. 누락·초과 없음.
- **밑줄:** 38번(14쪽 y=595.1)·40번·41번 발문 «않은» 만 선이 있고 세트의 `stem_underlines` 와 같다. 지문(가)(나)와 <보기>에는 밑줄이 없고 세트도 비어 있다.
- **구간:** [A]=p4~p6(학생3 «난 단순히…» ~ «문제가 해결되지 않을까?»), [B]=p13~p15(학생3 «응. 그런데…» ~ «들 수 있잖아.») 쪽 그림의 대괄호와 일치.
- **문단 경계:** (가) 17개 발화는 각각 «학생 N:» 로 시작. (나)는 들여쓰기 5개 문단(학생회 여러분 / 현재 분리배출함 / 행동 디자인에서는 / 첫째 / 둘째)이며 p20~p24 와 일치. 40·41번 선지의 «2·3·4·5문단» 과 맞는다.
- **㉠ 네모:** 원본은 (나) 맨 끝 아래에 칸 전체 너비의 빈 네모 안에 ㉠. 세트는 p24 끝에 ` ㉠` boxed + ranges 로 등록했고 렌더러(`xm-bxblank`)가 넓은 네모 빈칸으로 그린다. 42번 발문 «㉠을» 은 밑줄·네모가 아니라 글자만이라 stem 처리 맞음.
- **42번 <보기>(친구의 조언)** 상자: 머리말 없는 상자, 한 문단, 굵은 글씨 없음. 맞음.
- **해설지 대조(basis:"해설지" 전부):** 38①~⑤, 39②③④⑤, 40①~⑤, 41①~⑤, 42②③④⑤ 의 판정·`explanation_quote` 가 해설지 38~42번 풀이와 같은 취지이고 해설지 글자 그대로다. 이유에 «해설지는…» 메타 문구, em dash, 지문 밖 지식 없음.

## 자신 없다고 한 «자체» 선지
- **39번 ① (자체) 타당.** [A]는 학생3의 질문(p4 «네가 생각한 것은 어떤 거야?»)에 학생2가 답하는 구간이고 학생2의 발화(p5)에는 학생3 말의 취지를 확인하거나 이해가 맞는지 묻는 문장이 없다. 판정(부적절)·이유 모두 지문 안에서 확인된다. 근거 두 인용도 글자 그대로이고 결정 문장이다.
- **42번 ① (자체) 타당.** 선지 ①은 «학생회 불편 개선 사업이 필요, 지원 부탁» 뿐이라 건의(분리배출함 교체) 실현의 기대 효과가 없고 비유도 없다. «학생이 학교를 스스로 바꾸어 간다» 는 비유적 표현이 아니다. 이유 문장은 지문·조언 범위를 넘지 않는다.

## 고치면 좋은 것
1. 39번 ② 근거 인용(p6)이 «…구분이 어렵고» 에서 문장 중간에 끊긴다. 학생3이 요약·절충 없이 자기 생각을 덧붙이는 대목이면 충분하지만, 문장 끝까지 넣거나 «나도 그 이야기 들었어.» 와 «분리배출함의 종류가 잘 구분되고…문제가 해결되지 않을까?» 를 같이 두면 더 명확하다.

4. ㉠ 은 원본에서 별도 줄의 넓은 상자인데 세트는 문단 끝에 붙은 인라인 빈칸이다. 도구 한계 범위이며 학습에는 지장 없음(알려진 화면 한계로 두어도 됨).
