- 36번: ③ (2문단은 종류를 나누어 설명할 뿐 제작 과정을 보여 주지 않음). 정답표 ③과 일치.

## 2. 세트 파일과 대조

### 지문·문단 경계
- 문단 5개. 쪽 그림의 들여쓴 첫 줄이 «안녕하세요? / 여러분은 / 우리 조상들은 왜 / 우리 조상들은 기와에 / 지금까지» 로 5곳이고, 중간에 들여쓴 줄은 없다. 세트 `p1~p5` 와 같다.
- 지문 속 괄호 지시문 «(동영상 제시)» 등은 보통 글씨. 지문·발문·선지에 굵은 글씨(type=1) 없음(`get_texttrace` 로 x<300 구역 전체 확인, 해당은 안내문 «[35~37]» 과 문항 번호뿐이고 이것은 도구가 알아서 처리).
- 지문 전체를 감싼 네모 상자는 알려진 화면 한계(학습에 지장 없음).

### 밑줄
- PDF 선 2개: 36번 발문 «않은»(x490~505, y173), 37번 발문 «않은»(x408~423, y519). 세트 `stem_underlines: ["않은"]` 두 곳과 일치. 누락 없음. 35번에는 밑줄 없음(맞음).

### 굵은 글씨 (직접 잼)
- 36번 메모 머리: `∙화제 선정`, `∙청중 분석`, `∙발표 구성` 의 «∙»·글자 모두 `get_texttrace` type 0+1 겹침, 선 굵기 1.36pt. 1200dpi 렌더 세로·가로 획 폭 0.60~0.66pt(보통 글자 «청» 0.36~0.54pt). 굵음 확정. 세트 `bold` 3개와 일치.
- 메모 «- » 줄(`-` 와 본문, 번호·점선 포함)은 type 0 전용, 획 폭 0.36~0.54pt. 보통 확정. 세트에서 bold 없음, 맞음.
- 37번 `학생 N :`: «학생», 숫자(1·2·3), «:» 모두 Haansoft Dotum, type 0+1, 선 굵기 1.36pt 동일. 1200dpi 에서 숫자 1 줄기 0.60pt, 학생 «학» 줄기 0.66pt로 같은 굵기이고 보통 Batang 글자(0.42~0.54pt)보다 굵다. 콜론 점 폭 0.78pt. 쪽 그림 확대에서 숫자·콜론이 가늘어 보이는 것은 고딕 숫자 모양 때문이고, 선(stroke) 처리는 «학생» 과 같다. 비교 기준 보통 글자는 같은 13쪽의 type 0 전용 «학생1은» (선지, Batang)과 메모 «청중의» 로 확인. 세트의 `bold: ["학생1 :", ...]` 는 PDF 텍스트층의 `학생` + `1` + `:` (사이 공백 포함 표기)와 맞다. 3명 모두 같은 처리. 문제 없음.
- 1~3번째 `nth` 문제 없음(각 라벨이 문서에서 한 번씩만 등장).

### <보기>·상자
- 36번 메모: 라벨 없는 상자(`label: ""`) + `choices_in_box`. 선지 글이 상자 안 «- » 줄과 번호 ①~⑤ 로 배치된 원본과 맞다. 스프링 그림은 화면 한계.
- 37번: label «보 기» (텍스트층 «보 기»), 학생1~3 대화. 원본과 같다. 선지 ④·⑤의 «학생 3»(공백 있음)은 원본 그대로.

### 35번 선지 (해설지 없음: ①②④, 가장 엄격히)
- ① 부적절: 2문단 «여러분은 기와에 대해 잘 알고 계신가요?» 직후 답이나 반응 확인 없이 곧바로 정의 설명. 지문 전체에서 청중 반응을 받아 추가 정보를 주는 곳이 없다. 판정 맞음. 근거 인용 적절(질문이 나오는 결정 문장). 이유가 지문 안에서 확인됨.
- ② 부적절: 지문 전체에 출처(자료·책·기관명)를 밝히는 말이 없다. «~라고 합니다» 는 전언 표현일 뿐 출처 언급이 아님. 판정 맞음. 근거 인용 적절.
- ④ 부적절: 1문단은 발표 주제만 밝히고 «그럼 먼저 동영상을 보시죠» 가 있으나 전체 순서를 미리 안내하는 말은 지문 전체에 없다. 판정 맞음. 이유 «어디에도 없다» 는 사실이다.
- ③ 해설지 3문단 «청중의 질문을 받고 있지는 않다» 와 일치. ⑤ 해설지 5문단과 일치. 인용 모두 글자 그대로.

### 36·37번 판정·근거·이유
- 36번 정답 ③ «미반영», 나머지 «반영». 발문이 «않은 것» 이므로 정답 선지 판정이 부정(미반영)이어야 하는데 맞음. ①②④⑤ 이유가 해설지 36번 내용(배경지식, 다음 주 방문 한옥 마을 동영상, 타일, 왼쪽 고구려·오른쪽 백제)과 같은 뜻이다. ③은 2문단 종류 분류 인용으로 해설지와 일치.
- 37번 정답 ⑤ «부적절». 발문이 «적절하지 않은 것» 이므로 정답 선지가 부정이어야 하는데 맞음. ⑤ 이유(학생3은 지적하지 않고 검색해 보겠다고 할 뿐)는 해설지 «‘학생3’은 지적하고 있지 않다» 와 일치. ①~④ 이유는 해설지 문장과 같은 뜻이고 지문 밖으로 나가지 않는다.
- 이유 문장에 em dash, «해설지는…» 메타 문구 없음. 사전·문법 등 지문 밖 지식 없음.
- 해설지 인용은 모두 해당 문항 해설에 글자 그대로 있다.
