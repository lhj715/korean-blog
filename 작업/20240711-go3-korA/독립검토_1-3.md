# 독립 검토 (1차): 세트_1-3.json (2024-07 고3 korA, 1~3번)

검토 방법: 쪽 그림(문제_1쪽.png)과 해설지(해설 1쪽, 1~3번 해설)로 먼저 풀고, 세트 파일과 대조했다. PyMuPDF 로 텍스트층(`get_texttrace`, rawdict 글자 좌표)과 PDF 선 그림도 직접 쟀다. 프로그램 검사(`세트_검사.py`)는 합격(해설지에 없는 선지 4개: 2번 ②③④⑤ 확인 필요 표시)이다.

## 내가 푼 결과
- 1번 ④(일치하지 않는 것), 2번 ①, 3번 ③. 정답표·해설지·세트 파일 모두 같다.
- 선지별 판정(적절/부적절, 일치/불일치) 15개 전부 내 판단과 같다.

## 직접 확인한 것
- **지문 글자·문단 경계:** 쪽 그림에서 5개 문단 모두 첫 줄이 들여쓰기이고 세트의 p1~p5 와 같다. 글자는 텍스트층과 일치한다.
- **굵은 글씨(작업자 «없음» 동의):** 쪽 전체 `get_texttrace` 에서 type=1(굵은 겹침)은 쪽 머리글, `[1~3]` 안내문, 문항 번호 «1.»·«2. »·«3. », 교시 표시뿐이다. 본문·발문·선지·<보기>에는 type=1 이 없다(글꼴은 모두 Haansoft Batang type 0). 지문·선지·<보기>에 굵게 넣을 곳은 없다.
- **밑줄(좌표 대조):**
  - ㉠: 선 2개(227.3~285.8 / 69.2~266.1). 둘째 줄 선이 «조언»의 «언»(끝 266.3)에서 끝나고 «한»은 제외다. 세트 text «18가지 역사서를 … 조언» 과 일치한다.
  - ⓐ: 선 끝 505.8 = «다» 끝(506.2), 마침표(505.9~508.2)는 제외. 세트 «처음부터 자세히 읽어 보았다» 일치.
  - ⓑ: 둘째 줄 선 314.7~329.3 = «했고»에서 끝, 쉼표 제외. 세트 일치.
  - ⓒ: 선 314.7~336.7 = «쉬웠다»에서 끝, 마침표 제외. 세트 일치.
  - ⓓ: 선이 «이 말에 … 있다고»와 둘째 줄 «생각해»(314.7~337.1). 세트 일치.
  - ⓔ: 선 끝 389.3, 마침표(387.2~389.5)까지 포함. 세트 text 에 마침표가 있어 일치.
  - 발문 «않는»(1번), «않은»(3번) 밑줄 선이 PDF 에 있고 세트 `stem_underlines` 에 둘 다 있다.
- **3번 <보기> 띄어쓰기 복원:** <보기> 상자 줄 끝에는 줄바꿈 때문에 공백 글자가 없어서(예: «구체적인/내용이», «관련/내용에», «나눠 보니, 이 말이 부분적인/내용에») 텍스트층만으로는 띄어쓰기를 알 수 없다. 세트의 «구체적인 내용이», «관련 내용에», «부분적인 내용에», «이해하기 어려운», «그런데», «한다는», «글쓴이가 전하려는» 은 모두 맞게 복원됐다. 해설지 인용(«책의 구체적인 내용이 무엇인지»)과도 맞는다. 단 «추천해/준 책»(줄 끝)은 «추천해준»(붙임)으로 복원했는데, 줄바꿈 자리라 «추천해 준»과 구별할 근거가 없다(해설지에도 이 말이 없다). 판단 근거가 되는 말이 아니라 학습에는 지장이 없다.
- **해설지 인용:** 15개 `explanation_quote` 가 해당 문항 해설에 글자 그대로 있고(검사기 통과), 판정 방향도 해설지와 같다.
- em dash, «해설지는…» 같은 메타 문구는 이유에 없다.

## 반드시 고칠 것
1. **2번 ② 근거 인용이 결정 문장이 아님.** 현재 evidence 는 `{"para":"p2","quote":"자신의 손자에게"}` 한 조각뿐이다. 이 선지(요약본이 중요한 내용을 부수적인 내용으로 왜곡한다)를 반박하는 결정 문장은 p2 의 «자신의 손자에게 ㉠… 요약본을 읽지 말라고 조언한 것도 이러한 독서 태도와 상통한다.» 이다. 조언의 이유가 졸독(급하게 읽기)과 상통한다는 것이지 요약의 왜곡이 아니라는 점이 이 문장에서 드러난다. 인용을 «요약본을 읽지 말라고 조언한 것도 이러한 독서 태도와 상통한다»(2번 ① 근거와 같은 문장이지만 반박 방향이 달라 재사용에 해당하지 않음)로 바꾸거나 «졸독은 책을 급하게 읽어 버리는 것으로»를 함께 달아야 한다. 현재 인용은 이유 문장을 뒷받침하지 못한다.

## 고치면 좋은 것
1. **2번 ③ 근거:** p1 «시간이 걸리더라도 … 꼼꼼히 읽고 … 필요하다»는 시간 비교 주장(요약본 꼼꼼히 읽기가 더 오래 걸린다)과 직접 연결이 약하다. 지문에 시간 비교가 없다는 이유 문장에는 맞지만, 이유를 «지문에서 요약본을 읽지 말라는 조언의 이유는 급하게 읽는 졸독과 상통한다는 것이다»처럼 쓰고 p2 문장을 같이 인용하면 더 분명하다. 현재 상태로도 판정은 맞다.
2. **2번 ④⑤:** 판정·이유는 정확하다. ④는 p1 인용 뒤에 p2 «이러한 읽기로는 책의 세부적인 내용을 파악할 수 없다»를 덧붙이면 «대략 훑기는 안 된다»는 근거가 이황의 말로도 확보된다(선택).
3. **3번 «추천해준»:** 위 설명처럼 줄바꿈 자리의 띄어쓰기는 확정할 수 없으므로 작업 노트에 «줄 끝이라 확인 불가»라고 남겨 두면 좋다(선택).
