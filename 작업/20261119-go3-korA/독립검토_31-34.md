## 반드시 고칠 것
1. **(나)·(다) 출처 줄이 화면에서 왼쪽에 붙는다.** n2 `- 송종원-`, n3 `- 김충선-` 은 원본(11쪽·12쪽 그림)에서 마지막 `-` 앞에 빈칸이 있고 오른쪽 정렬이다. 렌더러는 `｣-` 가 아니면 빈칸이 있어야 오른쪽에 붙이므로, `미리보기_31-34.html` 에서 n1 만 `xm-right` 이고 n2·n3 은 아니다. `- 송종원 -`, `- 김충선 -` 으로 고친다.
2. **33① 근거 `관아 ⓐ문` 이 잘렸다.** 명사 조각이라 서술어가 없고, 이유의 "안채로 들어가는 통로"를 뒷받침하는 "안채로 모실 적에"가 빠졌다. `관아 ⓐ문을 크게 열고 안채로 모실 적에` 로 늘린다.
3. **33② 근거 `ⓑ문을 열고` 가 잘렸다.** 이유의 "화자가 생활하는 방의 문"을 보여 주는 "방에 드네"가 빠졌다. `남풍이 건듯 불어 ⓑ문을 열고 방에 드네` 로 늘린다(문을 여는 주체가 남풍이라는 점까지 보인다). 31⑤와 같은 행이어도 결정 문장이므로 괜찮고, 화면 도구는 겹치는 근거를 처리한다.
4. **33④ 근거 `남풍이 건듯 불어` 에 판단의 핵심이 없다.** 선지와 이유는 "남풍이 문을 열고 방에 드는" 능동성을 말하는데 바로 그 부분이 인용에서 잘렸다. `남풍이 건듯 불어 ⓑ문을 열고 방에 드네` 로 늘린다. 둘째 근거 `행여 고향 소식 가져 왔는가` 는 그대로 둔다.
5. **33⑤ 근거가 ⓐ·ⓑ를 여는 대목이 아니다.** (가) 근거 `선경을 얼핏 보며 관아로 돌아드니` 는 문을 열기 전의 행이고, (다) 근거 `방에 드네` 는 "ⓑ문을 열고"가 잘렸다. `관아 ⓐ문을 크게 열고 안채로 모실 적에` 와 `ⓑ문을 열고 방에 드네` 로 바꾼다.
6. **34② 근거에 "고향"이 없고 <보기> 인용이 잘렸다.** 선지는 "고향을 떠올리는 화자의 처지", 이유는 "고향 소식을 전해 주기를 기대하는"인데 지문 근거는 (나) 둘째 행뿐이다. v3 `엇더타 고향 소식을 전하지 않고 가느냐` 를 더한다. <보기> 인용 `(나)는 대상의 이동 경로를 드러내는 방식을 통해` 는 서술어가 없으므로 `(나)는 대상의 이동 경로를 드러내는 방식을 통해, (다)는 화자의 행위를 연이어 제시하는 방식을 통해 정서를 부각한다.` 로 늘린다.

## 고치면 좋은 것
