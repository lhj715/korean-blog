## 확인 결과
- 먼저 스스로 푼 답: 38 ③, 39 ③, 40 ⑤, 41 ①, 42 ③. 정답표, 세트 정답, 선지별 판정 25개 모두 일치.
- 프로그램 검사: 합격.
- 굵은 글씨(texttrace 글꼴): 14·15쪽 본문은 type 0. «학생 N» 은 태고딕(굵음), 콜론은 한양신명조(보통), (가)·(나)는 견명조, 보고서 제목은 태고딕. 세트와 맞음. 번호 항목(중고딕)은 heading 으로 굵게 보이며 문제없음.
- 문단 경계: (나)의 새 문단은 x=455.3 들여쓰기(p30·p32·p34·p35·p36)와 일치. «그리고 연구소에서»(x=445.0)는 p35 에 이어지는 것이 맞음. [C]·42번 상자 첫 줄 들여쓰기 확인.
- [A]·[B]·[C] 구간, 네모 «안내 공지»(지문·39 발문), 39·42 «않은» 밑줄(쪽 그림) 일치. 38·40·41 발문에는 밑줄 없음.
- 39 메모, 40 활동지의 raster_text 는 그림과 일치. 그림 자르기 범위 이상 없음.
- 해설지에 없는 선지: 없음. 이유에 em dash·«해설지는» 문구 없음. 근거 인용의 서술어 잘림, 부당한 재사용 없음.
- 40④: 해설지의 «학생1 서식 실태» 를 빼고 «차이점이 아니라 공통점» 에 맞춘 판단은 타당. (가)에서 식물 특징을 알아보자고 한 사람은 학생 3이라 선지 앞부분은 맞고 뒷부분이 틀림.
- 40①③의 (가) 발화 근거, ③의 염분 점검 문장은 타당.

1. **39번 메모 그림과 40번 활동지 그림의 id 가 둘 다 `f1`** (세트 JSON 의 두 bogi.blocks, 40번 근거 ①④⑤의 `"fig": "f1"`).
   - `도구/기출_렌더.py` 는 그림 근거를 그림 id 로만 묶는다. `_임시\미리보기_38-42_rv.html` 로 확인하니 `q39-f1`(39번 메모)에도 `data-ev='e40-1-1 e40-4-1 e40-5-1'` 과 «그림·표 근거 40-① 40-④ 40-⑤» 꼬리표가 붙는다.
   - 결과: 39번 메모 밑에 40번 번호가 보이고, 40번 ①④⑤의 «지문 근거/정답 근거» 를 누르면 39번 메모도 함께 강조된다(`static/js/exam.js` 코드 기준. 첫 이동 대상은 지문 문장).

## 고치면 좋은 것
1. 40④ 이유: 선지 앞부분(학생 3이 식물 조사에서 알아보려 한 특징)이 맞다는 말이 없어 p16 근거가 이유와 이어지지 않는다. 예: «ⓓ는 '학생 3'이 알아보자고 한 식물의 특징에 해당하지만, (나)는 '둘 다 길쭉한 풀'이라며 두 식물의 길이를 차이점이 아니라 공통점으로 썼다.» (ⓓ는 길이를 서로 다른 수치로 적었고, (나)의 꽃 색 차이는 ⓓ의 내용이 아니다.)
2. 40②③: ①④⑤처럼 ⓑ·ⓒ 활동지 문장도 figure 근거로 넣으면 선지의 대상이 바로 보인다(③은 «하구에 해수 유입이 원활하게 이루어지지 않음»). 넣을 때는 새 id `f2` 를 쓴다.
3. 39① 이유의 «'학생 2'가 좋다고 했다» 근거(p12 «그럼 되겠다.»)가 인용에 없다. 추가 권장.
4. 41③ 이유는 천일사초·모새달·새섬매자기를 말하는데 근거는 «식물을 모둠별로 찾아보았다» 한 문장뿐이다. p36 «천일사초는 연갈색 꽃이, 모새달은 자줏빛 꽃이 피어 있었는데» 를 더하면 좋다.
5. 39②⑤ explanation_quote 가 «발화로 보아» 에서 끊긴다. 해설지 문장 끝(«…생각은 적절하다.»)까지 잇는다.
