- `세트_검사.py`: 합격. 해설지에 없는 선지는 32②⑤, 33①③.
- 굵은 글씨(`get_texttrace` type 0+1 겹침, 11〜12쪽 전체): 지문은 p8 3곳, p13 3곳, p16 1곳, [중략 부분의 줄거리], p22 1곳, p25 3곳, p29 2곳으로 데이터와 같다. 보통 글자는 type 0 전용. 12쪽 발문·선지·<보기> 본문에는 겹침이 없다(번호·머리글 제외).
- 밑줄(PDF 선): ㉠·㉡은 «꿈» 한 글자, 31·34번 «않은». 데이터와 같다.
- 문단 경계(줄 시작 x 좌표)와 [A](p20의 상공 대사), [B](p27) 범위, <보기> 상자, 발문·선지, 34번 3점: 원본과 같다.

- 사실 확인: 31② (울음소리는 중문으로 달려들어 가는 대목에서 들림), 32②⑤ (기약을 깨고 찾아감, ㉡은 자결 뒤 귀향길의 꿈), 33①③ (두 말에 상대의 지난 행위를 탓하는 내용 없음, [A]는 죽음을 말하지 않고 달래며 혼인을 권함, [B]는 낭패를 걱정하며 숙고를 청함) 모두 지문에서 성립한다.
