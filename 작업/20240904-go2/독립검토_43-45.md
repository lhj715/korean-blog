# 독립 검토 43~45 (현대시 (가) 주머니 속의 바다 / (나) 속리산에서), 1차

검토 방법: 쪽 그림(문제 16쪽)과 해설지(4쪽)로 먼저 풀고, 세트_43-45.json 과 대조. PDF 선(get_drawings)·텍스트층 type(get_texttrace)을 직접 읽고 `세트_검사.py` 를 돌림(합격).

## 스스로 푼 결과
- 43번 ①(불쑥, 주섬주섬 = 음성 상징어, 해설지 일치). 44번 ⑤(단숨에, 해설지 일치). 45번 ⑤(해설지 일치). bundle 정답과 같음.
- 발문 방향: 43 «가장 적절한» → 정답 판정 적절, 44·45 «적절하지 않은» → 정답 판정 부적절. 세트 파일 모두 맞음.

## 대조 결과
- 지문 글자·행 구분: 맞음. 줄 넘침 이은 4곳은 쪽 그림과 일치(«보여 준다», «있는 일이다» 는 공백 있음, «안부까지» 는 낱말 중간이라 공백 없음, «건네주던 바다» 공백 있음).
- 밑줄(PDF 선 좌표): ㉠ 설마?(123~149.5), ㉡ 곱게(217.9~239.1), ㉢ 아직(123~144.2), ㉣ 오히려(123~154.8), ㉤ 단숨에(123~154.8) 모두 등록 범위와 일치. 44번 발문 «않은»(612~633), 45번 발문 «않은»(441~462) 선 있음, 세트에 둘 다 등록. 선지·<보기>에 그어진 선은 없음.
- 굵은 글씨(type 0+1 겹침 + 쪽 그림 확대, 같은 쪽 보통 글자는 type 0 전용 확인):
  - (가) 주머니에 넣(고는 보통) / 손바닥 위(첫 줄) / 올려놓(첫 번째만, 뒤쪽 «올려놓고 엽서를» 은 보통) / 손수건 / 갈치 떼 / 사람과 함께 눈뜨(는은 보통) / 잠드는(저녁이면 «사람과 함께» 는 보통). 등록과 전부 일치, 빠진 곳·넘친 곳 없음.
  - (나) «여겨온 나» 의 나(지문 안 첫 번째 «나») / 길을 열어 보(였다는 보통) / 어깨를 낮추며 / 속삭. 등록과 일치(nth 위치 포함).
  - (가)·(나) 라벨은 type 1(굵음), 세트에서 label 타입으로 처리됨. 지문 밖 굵은 글씨는 문항 번호(43.·44.·45.)뿐이며 세트 데이터 대상 아님.
- <보기> 상자: 머리말 «보 기», 본문 글자 일치. 45번 ⑤ 뒤 «확인 사항» 상자는 선지에 섞이지 않고 제거됨(검사 합격).
- 선지 인용 글자(‘ ’ 따옴표 포함) PDF 와 일치.

## 자신 없다고 한 곳 판단
- 43 ②: 첫 행·끝 행 인용이 결정적 근거로 충분. 이유 맞음.
- 43 ③: 판정 맞음. 이유 둘째 문장(속삭인다 = 산을 말하는 존재로 그림)은 해설지 밖이지만 지문 «산은 … 속삭였다» 로 확인되는 사실이고 틀리지 않음. 인용도 그 대목이라 적합. 그대로 두어도 됨.
- 43 ④: 계절어가 없다는 부정 서술은 지문 전체를 보아 사실. 인용(«평평한 길은 …») 은 다소 임의적이나 부정 판단에서는 불가피.
- 43 ⑤: 시선 이동 없음도 지문을 보아 타당. 인용 둘은 약한 편이나 판정에는 영향 없음.
- 45 ④: 판정(적절)·인용(지문 + <보기>) 맞음. 이유가 선지 문장을 거의 되풀이하는 것은 사실이나 틀린 내용은 아님.

## 고치면 좋은 것
1. 45 ④ 이유: «열어 보였다» 의 주어가 속리산이라 등반 대상이 아니라 길을 먼저 내어 주는 쪽이라는 점을 지문 말로 한 번 더 짚으면 되풀이가 줄어듦.
2. 45 ⑤ 이유 첫 문장 «어깨를 낮추며 넘는 것이 산이 아니라 갇힌 시간이라고 속삭여» 는 «어깨를 낮추며» 가 «넘는» 에 걸려 읽혀 어색함. «산이 어깨를 낮추며 넘는 것은 산이 아니라 산 속에 갇힌 시간이라고 속삭여» 처럼 주어를 분명히 하면 좋음.
3. 43 ④·⑤ 인용: 가능하면 선지와 더 직접 닿는 행(예: ④ 계절어 없음을 보이는 (나) 전체 흐름)으로 바꾸어도 되나 필수 아님.
