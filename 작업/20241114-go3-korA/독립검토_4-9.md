# 독립검토 4~9번 (20241114-go3-korA) 1차

검토 방법: 쪽 그림(2·3쪽)과 해설지로 먼저 풀고 세트 파일과 대조. 프로그램 검사(`세트_검사.py`) 합격 확인.

## 정답·판정
정답 4번=④, 5번=⑤, 6번=③, 7번=②, 8번=①, 9번=②. 모두 정답표·내 풀이와 같고, 선지별 적절/부적절 판정도 해설지와 일치한다.

## 직접 확인한 항목
- 굵은 글씨: 2·3쪽 `get_texttrace` 에 type=1 이 하나도 없고 견고딕·견명조 계열은 «(가)»·«(나)»·문항 번호·«홀수형» 뿐이다. 지문·발문·선지·<보기> 본문에 굵은 글씨 없음. 세트에 bold 없는 것이 맞다. «(가)»·«(나)» 는 label 항목이라 화면 도구가 처리하며 문제 없음.
- 문단 경계: 쪽 그림의 들여쓰기와 대조. (가) 4문단(p2~p5), (나) 4문단(p7~p10) 일치. (나) 첫 문단은 단 경계에서 이어지지만 한 항목으로 맞다.
- 밑줄: ㉠·㉡·ⓐ 범위가 쪽 그림과 일치(C3 통과). 발문 «않은» 밑줄 4·5·8번 있음. 9번 선지 밑줄 5개 일치.
- 네모: (가) 1문단 «개화» 네모(boxed) 있음.
- <보기> 상자(8번) 글자·머리말 일치.
- 겹낫표 U+F0854/F0855: PDF 글자 그대로 두고 `도구/기출_렌더.py` 가 『 』 로 바꿔 그리는 기존 방식이며 이미 게시된 회차와 같다. 문제 없음.
- 6번 ①②, 9번 ①③④⑤ 의 근거 공유: 6번은 ①②가 천두슈 쪽 근거는 다르고(p9 «전통문화 전반 부정» / p8 «과학을 습득하여 폐단에서 벗어나»), 장쥔마이 쪽(p10)만 공유하며 해설지도 그렇게 푼다. 9번은 ⓐ 문장 하나가 5개 선지의 공통 대상이라 공유가 맞다. 결정 문장으로 인정.

## 반드시 고칠 것
1. **5번 발문 «개화» 네모 누락.** 쪽 그림(3쪽 5번)에서 발문의 «개화» 에 네모 테두리가 쳐져 있다. 세트 5번 문항에 `"stem_boxed": ["개화"]` 가 없다. 규칙서 5절(네모 테두리 글자, 발문이면 `stem_boxed`)에 해당. 검사기는 이를 잡지 못한다(있는 것만 검사).

## 고치면 좋은 것
- 7번 ④ 근거에 p5 «일본의 지도를 받아야 한다고 보았다.» 가 같이 달려 있으나 이유 문장은 ㉡ 쪽만 설명한다. ㉠ 쪽(박은식은 일본 추종 태도가 아님)까지 이유에 한 줄 더하거나 해당 근거를 빼면 일관된다. 해설지는 ㉡ 만 다루어 판정에는 영향 없음.
- 5번 ③ 근거가 p3 «통치자의 입장에서…» 와 p4 «왕으로 생각했고» 두 문장인데 이유 문장에서 한성순보가 왕을 실행 주체로 상정했다는 연결이 «통치자의 입장» 에 의존한다. 해설지와 같은 풀이라 유지 가능.
- p3 «대한매일신보』등의» 는 텍스트층에 공백이 없다(원본 쪽 그림에는 «』 등의» 로 띄어 있음). 검사는 공백을 무시해 통과하나 화면에서 붙어 보인다. 세트 만들기에서 공백 한 칸을 넣을 수 있으면 넣는다.
