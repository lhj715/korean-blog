## 확인한 것

- 밑줄: ㉠~㉤ 범위가 쪽 그림과 같다(㉠ 은 기호 뒤부터, ㉡ 은 두 줄, ㉢·㉣ 도 같음). 38·39번 발문 «않은» 밑줄 있음(그림 확인, 검사기 C 통과).

  - 42번 상자 «초고»·«초고에 대한 의견» = `한양견명조`(굵음) → bold 등록 맞다.
  - [A] 는 `한양견명조`로 굵은데 화면이 범위 표시 글자를 굵게 그리므로 따로 등록할 것 없다. (가)·(나) 소제목도 label 로 자동 굵게 그려진다.
