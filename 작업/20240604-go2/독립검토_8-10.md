# 독립검토 8~10번 (20240604-go2, 세트_8-10.json) 1차

검토 방법: 쪽 그림(3쪽 오른쪽 열, 4쪽 왼쪽·오른쪽 열)과 해설지 8~10번으로 먼저 풀고, 세트 파일과 대조했다. `세트_검사.py` 는 합격(해설지 없는 선지 8번 ②③④⑤ 확인 요청 문구만 출력).

## 스스로 푼 결과
- 8번 정답 ①, 9번 정답 ④, 10번 정답 ①. 세트의 answer·bundle·해설지 정답표와 모두 일치한다.
- 발문 방향: 8번 «반영된 것», 9번 «적절하지 않은 것», 10번 «가장 적절한 것». 세 문항 모두 정답 선지의 판정 말(반영, 부적절, 적절)이 방향과 맞고 나머지 선지는 반대다.

## 반드시 고칠 것
1. 지문 소제목 두 개의 굵은 글씨 누락 (p1 `[작문 상황]`, p3 `[학생의 초고]`).
   - 근거: 3쪽 PDF `get_texttrace` 에서 이 두 줄(y=210, y=279)이 type 0 과 type 1 로 겹쳐 있다. 같은 쪽 본문 줄(y=228, 297, 332 등)은 type 0 뿐이다.
   - 1200dpi 렌더 잉크 비율로 같은 글자 «고» 를 재면 소제목 속 «고»(`초고`) 0.149, 본문 «고» 0.101 이고(1.47배), 굵은 쪽인 안내문 «고» 는 0.191 이다. 그림 확대(400dpi)에서도 소제목 획이 본문보다 굵다. 둘 다 맞으므로 굵은 글씨가 맞다.
   - 세트의 두 항목에 `bold` 필드가 없다. 같은 시험 다른 회차 세트들(예: 20240904-go2 세트_8-10, 20240604-go3-korA 세트_43-45)은 이 소제목에 `"bold": ["[작문 상황]"]`, `"bold": ["[학생의 초고]"]` 를 달았다. 같게 고친다.
   - 반대로 다른 굵은 글씨는 없다: 3쪽·4쪽 type=1 은 문항 번호(8., 9., 10.)·안내문·«고2» 머리글뿐이고, 지문 본문·<보기>·<조건>·선지에는 type=1 이 없다.

## 고치면 좋은 것
1. 8번 ③ 근거(p4)는 «기부 참여가 적다» 는 말이라 «모금 현황을 밝히지 않았다» 는 판단의 직접 근거로는 약하다. 소셜 기부를 다룬 p5·p6 에 모금액·현황 수치가 없다는 점이 결정적인데, 이는 인용으로 보일 문장이 없는 부재 판단이다. 현재 인용도 «현황과 비슷한 말이 나오지만 소셜 기부 모금 현황은 아님» 을 보이는 용도로는 허용 범위다. 이유 문장은 그대로 둬도 된다.
2. 8번 ⑤ 근거(p5 «소액 기부나 포인트 기부 방식도 있다») 도 부재 판단의 대용 인용이다. 이유(유형·방식만 소개)와 맞으므로 통과 가능. 굳이 바꾼다면 p5 의 «릴레이형 기부가 있다» 문장 쪽이 «방식만 소개» 에 더 가깝다.
3. 9번 ③ 해설지는 «3문단» 이라 쓰지만 세트 근거는 4문단 p7(«긍정적 영향»)이다. 결정 문장은 해설지 ③ 의 기능(기부 참여의 긍정적 영향으로 추가)과 맞는 p7 이 적절하다고 판단한다(작업자 선택 옳음). 다만 해설지 말을 따라 p6 의 «다른 사람과 기부 활동을 공유하며… 즐길 수 있고» 를 evidence 에 하나 더 두면 «3문단» 과 «긍정적 영향 추가 위치» 가 함께 보인다. 필수 아님.
4. 10번 ④·⑤ 근거 인용이 «청유문으로 마무리할 것» 으로 같다. 두 선지 모두 해설지가 «청유문으로 마무리하지 않았다» 한 줄이고, 판단의 결정 부분이 선지 끝말(관심을 가져야 한다 / 어떨까?)이라 evidence 에는 조건 문장 외에 인용할 지문이 없다. 이유 문장이 각각 끝말을 짚으므로 통과 가능.

## 작업자가 자신 없다고 한 곳 판정
- 8번 ②③④⑤ 근거 선택: 4번(p6 «악용될 가능성도 있다»)은 결정 문장으로 정확하다. ②(p5 디지털 기술 발전·미디어 환경 변화)는 «변화 과정 설명 아님» 의 근거로 적절하다. ③⑤ 는 위 «고치면 좋은 것» 참고, 사실 오류 없음. 이유 문장의 사실 판단(변화 과정·모금 현황·피해 사례·법적 제도 모두 지문에 없음)은 지문 전체를 읽고 확인했다. 이유에 지문 밖 지식 없음, em dash 없음, «해설지는» 메타 문구 없음.
- 9번 ③ 근거: 위 3번, p7 선택 옳음.
- 10번 ④·⑤ 동일 인용: 위 4번, 허용.
- [A] 네모 빈칸: 3쪽 그림에서 [A] 는 문단 끝에 이어진 가로로 넓은 네모 상자다. p7 `boxed: ["[A]"]` 로 규칙(괄호 기호 하나만 네모 → 넓은 네모 빈칸)에 맞다. 텍스트 «있다. [A]» 순서·위치도 PDF 와 같다.
- 9번 <보기> ㄱ-1·ㄱ-2 그림: 쪽 그림과 오려 낸 두 그림을 대조했다. 막대 구획·글자·퍼센트(24/76, 38/31/19/12)·테두리가 모두 온전하고 가장자리에 다른 글자나 선이 걸리지 않았다. `pdf_text` 와 alt 도 그림 내용과 같다.
