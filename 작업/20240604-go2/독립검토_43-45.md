# 독립 검토 43~45 (현대시 (가)(나)), 1차

확인 방법: 쪽 그림(문제_16쪽.png)과 PDF 텍스트층 `get_texttrace`(type 0+1 겹침, 글꼴 Haansoft Batang)로 굵은 글씨를 직접 쟀고, 해설지 43~45 해설과 판정을 대조했다. 프로그램 검사(`세트_검사.py`)는 합격.

## 직접 푼 결과
43 = 5, 44 = 2, 45 = 1. 세트의 정답·선지별 판정(43: 부·부·부·부·적 / 44: 적·부·적·적·적 / 45: 부·적·적·적·적)이 모두 맞다. 판정 말이 발문 방향(가장 적절한 것, 적절하지 않은 것)과 맞는다. 이유는 지문·해설지 안에 머물고 em dash 와 «해설지는…» 메타 문구가 없다.

## 굵은 글씨(texttrace type 1 겹침 확인)
- (가) 라벨, (나) 라벨: type 1 겹침 있음, bold 맞음.
- (가) «추운 땅속을 헤매다» (y=247), «부르지 않아도» (y=297), «내 안» 7행 y=364 (type 1; 뒤의 y=630 «내 안에 있지만» 은 type 0 전용이라 nth 1 이 맞다), «뱉아» (y=530), «굳은 살가죽에 불 댕길 일» (y=580): 모두 맞다.
- (나) «자기 안», «모난 돌멩이», «모난 파문», «검은 돌멩이», «검은 파문으로», «들어가», «하늘», «넘치지 않» 모두 type 1 겹침이고 쪽 그림에서도 굵다. 빠진 곳·넘친 곳 없음. 선지·발문에는 굵은 글씨 없음(43. 44. 45. 번호만 굵고 데이터 밖).
