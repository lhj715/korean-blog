# 독립 검토 1-3 (2026-06 고2, 화법과 언어, 1~3번) 2차

방법: 쪽 그림(문제_1쪽.png, 오른쪽 확대)과 해설지로 먼저 스스로 풀었다(1번 ②, 2번 ③, 3번 ④). 정답표·세트와 일치. 그다음 세트를 처음부터 다시 대조했다. `세트_검사.py` 합격. 미리보기를 새로 만들어 900px·400px 화면을 눈으로 확인했다.

## 1차 지적 확인
- 3번 ④·⑤ 선지: 데이터의 글자가 U+F000 이고, 렌더된 화면 글자는 «‘마시-’», «‘-다’» 로 나온다(PC·모바일 모두, 화면 글에 사용자 정의 글자 잔존 0). PDF 의 U+F000 은 낫표와 글리프 번호가 다르다(『 110, 』 119, 하이픈 308). 원본 그림도 하이픈이다. 해결됨.
- 진짜 겹낫표: 지문 『훈몽자회(訓蒙字會)』·『훈몽자회』·『한글 맞춤법 통일안』, 2번 계획표·④의 『훈몽자회』는 데이터에 U+300E/300F 로 있고 화면에도 겹낫표로 나온다. 그대로다.
- `세트_1-3_만들기.py` 에도 수정이 반영돼 있어 다시 돌려도 유지되는 구조다.

## 다시 확인한 것 (이상 없음)
- 문단 5개의 경계가 쪽 그림 들여쓰기와 일치. 줄바꿈에서 이어 붙인 낱말의 띄어쓰기 이상 없음.
- 밑줄: PDF 선으로 ㉠ «차자 표기», 2번·3번 발문 «않은», 향찰 표기 5개(隱 없음) 확인. 1번 발문은 밑줄 없음.
- 굵은 글씨: 글꼴 확인. «선생님:», «학생:» 은 HancomGothicBold 로 콜론까지 굵다. 계획표의 [도입][전개][정리]는 Dotum 0+1 겹침이고 heading 으로 굵게 그려진다. 지문·선지에 다른 굵은 글씨 없음.
- 계획표 상자(선지 번호 점선), <보기> 상자, 빈칸 [A], 향찰 그림의 pdf_text·alt 가 원본과 맞다.
- 판정 15개가 발문 방향과 맞다(3번 «않은» → ④ 부적절). 근거 인용은 각 선지의 결정 문장이다. 3번 선지들의 <보기> 인용 반복은 같은 원칙(훈차·음차)을 적용하는 것이고 선지마다 그림의 해당 한자가 따로 붙어 있어 적절하다.
- 이유는 지문·<보기>·해설지 안에 있고 사실에 맞다. em dash·메타 문구 없음. 전부 basis 해설지(해설지 없는 선지 없음).
