# 독립 검토 (1차): 20240328-go1 세트 8~10 (작문 초고)

검토 방법: 쪽 그림(문제 3·4쪽)과 해설지 8~10번으로 먼저 풀고(8=③, 9=⑤, 10=④, 정답표와 같음) 세트 파일과 대조. `세트_검사.py` 합격 확인. 미리보기 HTML 은 만들었으나(`_임시\검토_미리보기_8-10.html`) 브라우저로 열지 못해 화면 모양은 보지 못했다.

## 확인한 것 (이상 없음)

- 정답 8=③, 9=⑤, 10=④. 발문 «않은» 두 곳(8·9번)의 정답 판정이 부정(부적절·미반영)이고, 10번은 긍정(적절). 8·9번 발문 «않은» 밑줄은 쪽 그림에 있고 `stem_underlines` 에 등록돼 있다. 10번 발문에는 밑줄이 없고 등록도 없다.
- 지문 문단 경계: 오른쪽 단 줄 시작 x 좌표가 449(들여쓰기)인 줄은 281·381·498·681·848 다섯 곳이고 p4~p8 다섯 문단과 일치한다. 문단 번호 말(2문단=거북이 등대, 3문단=옥수수, 4문단=갈칫국)도 맞다.
- 굵은 글씨(`get_texttrace`, 쪽 그림 대조):
  - 3쪽 `[작문 상황]`, `[초고]`: type 0+1 이므로 굵음. label 항목 처리가 맞다.
  - 4쪽 9번 `처음`·`중간`·`끝`: 글꼴 휴먼고딕(type 0+1) 굵음. `[거북이 등대]`·`[옥수수]`·`[갈칫국]`은 바탕체 type 1 이고 대괄호까지 굵다. 세트의 bold 등록과 일치한다.
  - 4쪽 10번 «선생님:»: `선생님` 만 type 0+1 이고 콜론(x 139.2~142.9)은 type 0 뿐이다. 콜론 뒤 본문과 같은 굵기이므로 «선생님» 만 굵게 한 세트의 등록이 맞다. 비교 기준 글자(`글이`, `마무리되지` 등)도 type 0 전용임을 확인했다.
  - 이 문항들 외에 8·9·10번 선지·본문에 type 1 이 더 있는 곳은 없다(문항 번호 `8.`·`9.`·`10.` 은 문항 번호 서식).
- 근거 인용: 모든 인용이 해당 문단에 글자 그대로 있고(검사기 E 통과), 8번 ③ 부재형은 «의성어가 없다» 는 판정에 맞춰 대상을 생생하게 나타낸 부분(맛 표현)을 보인 것으로 수용할 만하다. 지문에서 의성어를 찾아봐도 없다(‘점점’·‘환하게’는 의태·상태 표현). 이유 문장도 지문 안 내용만 쓴다.
- 이유: 지문·해설지 밖으로 나가는 말 없음, «해설지는…» 메타 문구 없음, em dash 없음. 10번 ①~⑤ 이유가 해설지 판단과 같은 말이다.
- 10번 ①~⑤ 가 모두 같은 <보기> 조건문을 근거로 쓰는 점: 스키마상 선지 글을 근거로 못 쓰고(passage·bogi·figure 만 허용) 판정 기준이 <보기> 의 조건 자체이므로 재사용이 아니라 같은 기준 적용이다. 문제 없음.

- 9번 구상 상자: 데이터상 `처음`(b1)·내용(b2 inbox 처음) / `중간`(b3)·세 묶음(b4~6 중간1, b7~9 중간2, b10~12 중간3) / `끝`(b13)·내용(b14 inbox 끝) 로 묶음 구분이 쪽 그림과 같다. 원본의 왼쪽 라벨 상자 테두리·연결선은 데이터로 못 나타내는 알려진 화면 한계로 보고 학습에는 지장 없다고 판단한다.

1. 지문 p6 «여름 방학에는점점»: 공백 누락. 쪽 그림 3쪽 `여름 방학에는` 줄 끝과 `점점 자라는` 줄 시작은 낱말 경계(PDF 텍스트에서 이 줄만 끝 공백이 없어 줄 이음 때 공백이 빠짐)이므로 «여름 방학에는 점점» 이어야 한다. 검사기는 공백을 무시해 못 잡았다. (같은 단락·다른 줄 끝 `있/는`, `법/이란다`, `여물/었다` 등은 낱말 중간이라 붙여 쓰는 것이 맞다.)

1. 10번 ④ 선지 «익어　가는»: 공백이 전각 공백(U+3000)으로 들어 있다(PDF 텍스트층 그대로). 쪽 그림에는 보통 간격이고 해설지도 «익어 가는» 이므로 보통 공백(U+20)으로 바꾸는 편이 화면·검색에 낫다. 검사기는 공백을 무시하므로 통과한다.
