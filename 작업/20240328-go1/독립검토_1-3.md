# 독립검토 1-3 (2024-03 고1 1~3번, 1차)

방법: 쪽 그림(문제_1쪽.png)과 해설지 정답표로 먼저 풀고 세트와 대조. 검사기 합격 확인.

## 직접 푼 결과
- 1번 정답 ②(역사적 일화 없음), 2번 ⑤(㉠ 시각적 효과, ㉡ 실용적 기능), 3번 ②(착시 발생 이유). 세트의 answer 와 해설지 정답표(②⑤②) 일치. 1번 «않은» 은 정답 ② 가 부적절 판정이라 방향 맞음.

## 확인한 것
- 지문: 문단 5개. 쪽 그림의 들여쓰기 시작 위치(안녕하세요 / 트릭 아트란 / 아, 질문이 / 자, 이해되셨나요 / 이외에도)와 일치. 글자·괄호 지문 일치.
- 밑줄: ㉠자료, ㉡자료, ⓐ질문은 조사(를·을) 제외하고 낱말만 그어져 있음(그림 확인). 발문 1번 «않은» 밑줄 등록됨. 선지·2번·3번 발문에 다른 밑줄 없음.
- 2번 그림(그림_1-3_2_자료.png): 토끼·오리 그림과 횡단보도 사진, 아래 ㉠ ㉡ 기호가 잘리지 않고 들어옴. 가운데 칸 구분선 외 테두리 잘림 없음. pdf_text «㉠ ㉡» 적절.
- 굵은 글씨: get_texttrace 로 1쪽 전체를 쟀다. type=1(굵은 글씨) 겹침은 안내문 «[1 ~ 3] 다음은 학생의 발표이다. 물음에 답하시오.»(휴먼고딕), 문항 번호 «1.»«2.»«3.», 쪽 머리글·«제 1 교시» 뿐이다. 지문 본문(Haansoft Batang)과 선지에는 type=1 이 없다. 굵은 글씨로 넣을 것 없음(세트에 bold 없음이 맞음).
- 선지 근거: 1②는 해설지도 «없다» 는 부재 판단이라 개념·원리를 다룬 p2 첫 문장을 근거로 둔 것이 적절. 3번 선지 근거가 모두 p3 안이지만 선지마다 서로 다른 문장이고, 3② 가 결정 문장(시각 정보가 불분명하거나 해석에 혼선이 생길 때 착시가 일어난다), 3⑤ 는 같은 문장의 일부 «시각 정보가 불분명하거나 해석에 혼선이 생길 때» 를 «앞서 언급한 요인» 의 근거로 쓴 것이라 결정 문장으로 인정(해설지도 «앞에서 언급한 내용» 이라 했음). 2번 ①~④ 근거도 해당 선지가 다루는 지문 부분과 맞음.
- 이유: 지문·해설지 밖 내용 없음, «해설지는…» 메타 문구 없음, em dash 없음. 해설지 없는 선지(자체) 없음, 모두 basis=해설지.
- 프로그램 검사(세트_검사.py): 합격.
