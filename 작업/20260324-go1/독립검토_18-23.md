### 작성자 확인 요청에 대한 답
- **20⑤ "해설지는 이 비를 에너지로 보아"**: 받아들이기 어렵다. 지문은 비를 "에너지"라 부르지 않으므로, 학생에게는 ㉠과 기우제를 잇는 추론 과정을 지문 말로 보여 주어야 한다. "해설지는 …로 본다"는 추론을 생략하고 출처 권위로 대신하는 문장이며, 해설지를 화면에 드러내지 않는다는 원칙과도 맞지 않는다. 고쳐 쓸 것.
- **18③**: 문제 없음. 예시(농경 문화)를 변천 과정으로 착각할 여지를 짚은 설명은 지문 범위 안이다.
- **22번 상자**: 제목 '△△ 분수의 연혁' — texttrace type=1(Haansoft Dotum) + 300dpi 확대에서 항목 글자보다 굵음, 가운데 정렬 확인. `bold`·`center` 맞음. 항목 5개(∙1751년 / ∙1943년 / ∙1969년 / ∙1979년 / ∙1992년) 글자·순서 일치. 그림에서 연도 뒤는 "1751년 :"처럼 보이나 텍스트층이 "1751년:"로 붙어 있고 콜론 앞 간격은 서체 여백 수준이라 지금 표기로 무방. 상자 머리말 없음(label "") 맞음.
- **'[B]:' 간격**: 300dpi 확대에서 ①②의 "[A]:"와 ③~⑤의 "[B]:"는 콜론 위치 차이가 눈에 띄지 않는다. '[B]:'로 통일한 것 맞음.
- **네모 테두리 글자**: 지문 (가) 1문단 '세 가지 층위', (나) 2문단 '기우제', 19번 발문 '세 가지 층위', 20번 발문 '기우제' — 쪽 그림의 네모 4곳과 `boxed`·`stem_boxed` 등록이 정확히 일치. 빠진 네모·남는 네모 없음.

## 3. 지문·화면 충실도

- (가)·(나) 소제목: label 로 분리 맞음.
- 문단: (가) 4문단 + 각주. 6쪽 오른쪽 첫 줄 "화이트는 기술적 체계가 변화함에 따라"는 들여쓰기가 없어 2문단의 이어짐 — 그림 확인, p3 한 문단 처리 맞음. (나) 5문단 일치.
- 각주 "* 엔트로피: …" note 처리 맞음. ㉠ "반(反) 엔트로피*적 성향"에 위첨자 * 포함, 밑줄 범위(㉠ 뒤 '반'부터 '성향'까지) 일치.
- 밑줄 ⓐ'분담하는' ⓑ'실현된다' ㉡'명사가 아닌 동사로서의 문화' ⓒ'도모하려는' ⓓ'규명하려는' ⓔ'제고할' 모두 그림과 일치.
- 발문 밑줄: 19·22·23 '않은' 일치. 18·20·21 없음 맞음. 선지 밑줄 없음(22·23 확대 확인).
- 굵은 글씨: texttrace type=1 은 안내문 "[18 ~ 23] 다음 글을…", 문항 번호, '(가)'·'(나)', 22번 상자 제목뿐. '(가)'·'(나)'는 600dpi 확대에서 본문 '화이트는'·'반 퍼슨은'과 획 굵기가 같아 굵게 보이지 않는다 → 둘이 일치하지 않으므로 굵은 글씨로 넣지 않은 현재 처리가 맞다. 상자 제목만 굵은 글씨 등록, 맞음. 빠지거나 남는 굵은 글씨 없음.
- 23번 발문 "ⓐ~ ⓔ": 텍스트층에는 물결 뒤 간격이 있으나 그림은 "ⓐ~ⓔ"로 양쪽이 대칭이다. 한쪽에만 공백이 있는 지금 표기는 그림과 다르다(공백은 검사기가 무시하므로 손으로 맞춰야 함).
- 22번 points=3, 발문에서 "[3점]"과 상자 글자 분리 맞음.
