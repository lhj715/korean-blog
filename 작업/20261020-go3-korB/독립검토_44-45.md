# 독립 검토 44-45 (1차): 매체, 청소년 공간 대관 앱 온라인 공동 문서

## 확인한 것

- 쪽 그림(16쪽)과 해설지(5쪽 44·45번)로 먼저 풀었다: 44번 ⑤, 45번 ④. 세트·bundle 정답과 같고, 10개 선지의 판정도 모두 맞다. 두 발문 «않은»에 맞게 정답 선지가 부정 판정이다.
- `세트_검사.py` 합격.
- 안내문·발문·선지·<보기> 머리말: 쪽 그림, 글자 덤프와 같다.
- 밑줄: PDF 선이 44번(y 898, x 270~291)과 45번(y 202, x 605~627)의 «않은»에 있고 둘 다 등록됐다. 선지에 그어진 밑줄은 없다(댓글의 링크 밑줄은 그림 안).
- 굵은 글씨: 16쪽 `get_texttrace` 에서 type 0+1 겹침은 안내문, 문항 번호, 쪽 머리뿐이다. 발문·선지·댓글 글자는 type 0 이라 데이터에 넣을 굵은 글씨가 없다.
- 그림 글자: 공동 문서(접속 사용자 체크 여섯 명, 본문 항목, 댓글 이름·시각, ♥3, ㉠~㉤ 상자)와 앱 화면(검색 칸, 표, 달력 기호, 범례, 더 보기, 알림 단추)의 raster_text·alt 를 그림과 대조했고 틀린 글자는 없다. ㉣ 연결선(‘더 보기’ 항목과 서진 댓글)은 alt 에 적혀 있고 그림에도 온전하다.
- 그림 조각: 600dpi 에서 잉크 범위를 쟀다. 공동 문서는 온전하고 옆 글자가 없다. 앱 화면은 아래가 잘렸다(아래 1).
- 해설지 인용은 각 문항 해설 글자 그대로다. 이유는 자체 문장이고 em dash·메타 문구가 없다. `basis:"자체"` 선지는 없다.
