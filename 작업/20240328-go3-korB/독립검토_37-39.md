# 독립 검토 37~39번 (20240328-go3-korB, 언어와 매체 문법), 1차

검토자는 세트 파일을 열기 전에 쪽 그림(13·14쪽)과 해설지로 직접 풀었다. 프로그램 검사(`세트_검사.py`)는 합격(해설지에 없는 선지 12개는 아래에서 확인).

## 스스로 푼 결과 (세트와 일치)
- 37번: ㉠ 자음군 단순화, ㉡ 거센소리되기, ㉢ 음절의 끝소리 규칙, ㉣ 된소리되기(해설지 37번과 같음). 정답 ④(숱하다[수타다] = ㉢+㉡). 정답표와 일치.
- 38번: 정답 ②(보리밥은 앞 어근이 뒤 어근을 수식하므로 ㉯). 나머지 ①③④⑤ 적절. 발문이 «않은» 이고 정답 판정이 부적절이므로 방향 맞음.
- 39번: ㄴ·ㅁ=(가), ㄹ·ㅂ=(나), ㄱ·ㄷ=(다). 정답 ③. 해설지 39번과 같음.

## 해설지 없는 선지(basis:"자체") 확인
- 37① 밝히다[발키다]: 거센소리되기만(ㄺ의 ㄹ이 남음), 자음군 단순화 없음. 사실 맞음. 흙화덕은 ㄹ이 탈락하는 합성어 경계 환경이라 ㉠이 일어난다는 점과 모순 없음.
- 37② 닭고기[닥꼬기]: 자음군 단순화(㉠)+된소리되기(㉣), 끝소리 규칙 없음. 맞음.
- 37③ 깎고서[깍꼬서]: ㄲ→ㄱ(㉢)+된소리되기(㉣). 맞음.
- 37⑤ 단팥죽[단팓쭉]: ㅌ→ㄷ(㉢)+된소리되기(㉣). 맞음.
- 38①③④⑤: 논밭 대등, 돌다리·길바닥 수식, 피땀 새 의미. 모두 맞음. ③④가 같은 ㉯ 정의 문장을 근거로 쓰지만 각자 ㄷ·ㄹ 예문 인용이 함께 있어 재사용 문제 아님.
- 39①②④⑤: 각 선지 (가) 칸의 오류 낱말(ㄱ·ㄷ·ㅂ·ㄹ)이 관형사절을 안은 문장이라는 설명이 맞음(ㄱ 목적어 생략, ㄷ 주어 생략, ㄹ·ㅂ 생략 없음).

작업자가 걱정한 «음운 변동 설명이 지문 밖 지식» 문제: 이 문항은 지문이 없고 <학습 활동>의 변동 이름(해설지가 ㉠~㉣을 알려 줌)과 각 낱말의 표준 발음만 쓴다. 설명에 사전 뜻풀이나 학교문법 밖 내용은 없고, 낱말별 변동 판정은 표준 발음 규정과 맞는다. 문제 없음.

## 쪽 그림·PDF 좌표 대조
- 37번 <학습 활동> 상자와 안쪽 낱말 상자(PDF 사각형 449~742, 가운데 맞춤 두 줄)가 데이터의 inbox/center 와 일치. 문단 경계(첫 줄 들여쓰기) 일치.
- 38번 밑줄(PDF 선 좌표와 글자 좌표 대조): ㉮ 203~364 = «두 … 것»(것 354~365), ㉯ 118~296 = «한 … 것»(것 286~297, «도» 제외), ㉰ 둘째 줄 383~405 + 셋째 줄 전체 + 넷째 줄 «것». 데이터 3건과 모두 일치. 발문 «않은» 밑줄 있음(stem_underlines 일치).
- 39번 굵은 글씨: get_texttrace 에서 «선생님»(105~137)만 type 0+1 겹침(굵음), 뒤 콜론은 type 1 겹침 없음(보통). 상자 안 «[자료]»(`[`·`]`·자료) 굵음. 본문 속 «[자료]를»의 «자료»(131~153)는 type 0 전용(보통). 데이터(bold: 선생님 / [자료])와 일치. 37·38번 본문에는 굵은 글씨 없음(발문 번호만 굵음).
- 39번 선지 표(그림, raster_text): 쪽 그림과 글자 단위로 대조해 5행×3열 모두 일치. 열 머리 (가)(나)(다) 밑줄은 그림에 있음. PDF 에는 선지 표 칸 테두리가 없고 열 머리 밑줄 3개(y 990)만 있다. 그림 안 화살표 흐름도 상자는 보기 상자 안 그림(ff)으로 pdf_text 와 일치.

## 고치면 좋은 것
1. 39번 `table_border: true` 는 표에 칸 테두리가 없는데 붙어 있다(오탐을 피하려는 표시). 검사기 C9 예외로만 쓰이므로 화면에는 영향이 없으나, 이 문항은 선지 밑줄을 데이터로 따로 쓰지 않으므로 빼도 합격하는지 확인해 보면 좋다. 표 테두리를 그리는 화면 옵션이면 오히려 지워야 한다(원본에 테두리 없음).
