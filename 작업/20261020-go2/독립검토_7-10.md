# 독립 검토 7~10번 (문법) 1차

## 확인 방법
- 세트 파일을 열기 전에 문제 3쪽 그림과 해설지로 먼저 풀었다. 7번 ④, 8번 ③, 9번 ②, 10번 ①. 정답표 bundle, 세트 파일과 모두 같다.
- 7번 음운 변동 횟수 직접 검산: ① 2·2·4, ② 2·3·1, ③ 2·3·1, ④ 2·3·2, ⑤ 3·3·2. 이유에 적힌 횟수와 모두 같다.
- 8번: ①은 ㉠만, ④는 ㉢만, ⑤는 ㉡만 틀리고 ②는 셋 다 틀리다. 해설지에 없는 ①②④⑤ 이유와 맞는다.
- 9번 ①③④⑤(자체) 이유는 <보기> 설명과 해설지의 ⓐ~ⓔ 분류 안에 있고 사실 오류가 없다. 표 선지의 칸 구분은 원본과 같다.
- 굵은 글씨: 3쪽 texttrace 에서 type 0+1 겹침은 말한 이(콜론 포함)와 [학습 활동], 문항 번호뿐이다. 글꼴은 본문과 같다. 세트와 일치.
- 밑줄: 9번 ㉠~㉢·ⓐ~ⓔ, 10번 ㉠~㉤, 8·9번 열 머리 밑줄, 발문 «않은» 모두 PDF 선과 일치.
- 그림: 자물쇠, 8번 선생님 말·예문 display_image 는 잘림이 없다. 선지 옛한글 조각 5종은 확대해 보니 모양이 alt 와 맞고 획 잘림이 없다. «승» 조각 왼쪽 끝에 옅은 회색 점 몇 픽셀(밝기 219~243)이 있으나 화면 크기에서는 보이지 않는다.
- 프로그램 검사: 합격(해설지에 없는 선지 8개). 미리보기는 브라우저 없이 HTML 만 확인했다.
- 판정, 이유에서 틀린 것은 없다. em dash 와 메타 문구도 없다.

## 반드시 고칠 것
1. **7번 ③ 두 번째 근거 «‘물난리’는 교체 2회»** (문제 3쪽 <보기> 학생 말, 해설지 7번 ③). ③은 셋째 단어 ‘식용유’(첨가 1회)가 자리 번호 2와 달라서 틀리다. 이 인용은 ③의 어떤 단어나 판단과도 이어지지 않아, «지문 근거»를 누르면 관계없는 예시로 간다. `[KEY7, RULE7]`(②와 같은 조합, 틀린 이유가 같아 겹쳐도 자연스럽다)이나 `[KEY7]` 로 바꾼다.

## 고치면 좋은 것
1. 7번 ⑤ 두 번째 근거 «순서대로 제시해야 자물쇠가 열릴까요?»는 질문 문장이라 결정력이 없다. 빼거나 RULE7 로 바꾼다. (②의 RULE7 은 횟수 계산의 기준이라 괜찮다.)
2. 9번 근거가 선지 사이에서 어긋나게 배치됐다(<보기> 설명 문단).
   - ③: ⓒⓓ 가 ㉢임을 정하는 문장은 «명사형 어미는 용언의 어간과 결합하여 ㉢…»(D_NOUN)인데 ㉠ 정의를 달았다.
   - ①: ⓔ 가 ㉡이라는 이유에는 «㉡어근의 품사를 변화시키지 못하는 경우도 있다.»가 직접 근거다.
   - ⑤: «…사전에 등재된다»는 이유 문장과 직접 이어지지 않는다. ⓓ 를 가르는 D_NOUN 이 낫다.
3. 9번 ②(정답) 근거에 ⓐⓑⓒ 예문만 있고 ⓓⓔ 예문과 ㉠㉡㉢ 기준 문장이 없다. ⓓⓔ 를 보태면 이유와 짝이 맞는다.
4. 8번 선생님 말은 그림 항목이라 밑줄 없이 번호표만 붙는다. 특히 ③은 세 근거가 모두 여기라 «8-③» 번호표가 세 개 나란히 보이고, 눌러도 어느 문장인지 알 수 없다. ③ 근거를 그림 문단 하나와 예문 해석 줄(b4·b6)로 바꾸고, ①에도 «부처께 이런 말을 못 들으며»를 보태면 밑줄이 보인다. ②는 ㉠·㉢ 판단 근거(부사격·관형격 조사 문장)가 없다.
5. 8·9번 발문 «㉠~ ㉢» 은 물결 뒤에만 공백이 있다(텍스트층 그대로). 원본 모양처럼 «㉠~㉢» 이 낫다.
6. (도구 한계, 주 세션 참고) 10번 label «자 료»는 화면에 꺾쇠 없이 «자 료»로 보이고 원본은 «< 자 료 >»다. label 을 «< 자 료 >»로 바꾸면 검사기가 B3 불합격(«자료» 남음)을 내므로 작업자는 지금 값을 두어야 한다. 렌더에서 «보 기»처럼 바꿔 주면 해결된다.
