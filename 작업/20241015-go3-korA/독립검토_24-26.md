# 독립 검토 24~26번 (1차)

## 스스로 푼 결과
쪽 그림(8쪽·9쪽)과 해설지로 먼저 풀었다. 24번 정답 ③, 25번 정답 ④, 26번 정답 ②. 세트 파일의 정답·판정과 모두 같다. 25번 «않은», 26번 «않은» 모두 정답 선지가 부적절 판정이다.

## 직접 잰 것
- **굵은 글씨**: 8쪽 `get_texttrace` type=1 줄을 모두 뽑아 `bold` 목록과 대조했다. (가) 6곳(도회 안에서…사는 / 누구 집을…있고 / 팽이가 돌면서 나를 울린다 / 팽이는 나를 비웃는 듯이 돌고 있다 / 스스로 도는 힘을 위하여 / 서서 돌고 있는 것인가), (나) 5곳(댓가지가…나는 소리 / 물소리처럼 들리는 거 / 저 지하 깊은 곳에서 / 아이의 작은 실핏줄에까지 이어져 흐르는 / 가장 길고 맑은 실개천)이 정확히 같고, 쪽 그림 확대와도 맞다. 같은 줄의 나머지 글자는 type=0 이다. 빠진 곳·넘친 곳 없음. («(가)»·«(나)» 소제목과 «24.»·«25.» 번호도 type=1 이지만 label 항목·문항 번호라 지문 굵은 글씨 대상이 아니다.)
- **행 경계**: 쪽 그림에서 «영원히 나 자신을 … 놓여 있는» 줄 다음 «이 밤에 / 나는 한사코 …» 는 안쪽 시작으로 시작하는 줄바꿈 연속 줄이고 «/» 는 원문 표시다. 그러므로 «놓여 있는 이 밤에 / 나는 한사코 …» 를 공백으로 이어 한 줄로 만든 것이 맞다. 다른 «/» 줄(팽이가 돈다 / 팽이가 돈다 등)도 원문 한 줄과 일치한다. 연 구분 빈 줄도 일치(쪽 경계 «저 지하 깊은 곳에서 하늘 푸른 곳으로 다시» 뒤에 빈 줄 없음도 맞다).
- **밑줄**: ㉠~㉤ 범위가 쪽 그림의 선과 같다. 25번·26번 발문 «않은» 밑줄 등록됨(24번 발문은 밑줄 없음, 맞음). 선지에 밑줄 없음.
- **<보기>·선지 글자**: 쪽 그림과 대조해 일치(25① «가 보아도» 띄어쓰기 포함).
- **프로그램 검사**: `세트_검사.py` 합격. 해설지 없는 선지 5개(24⑤, 25③, 25⑤, 26①, 26③) 안내만 나옴.

## 판정·인용·이유 검토
- 해설지 근거 선지(24①②③④, 25①②④, 26②④⑤): 판정·해설 인용·이유 모두 해설지 및 지문과 맞다. 메타 문구·em dash 없음.
- `basis:"자체"` 5개: 모두 판정이 맞고 이유가 지문 안에서 설명된다.
  - 25③: 이유가 해설지 25②의 «스스로 도는 힘 = 주체성» 풀이를 빌렸지만, 해설지·<보기>가 같은 해석을 쓰므로 지문 밖 말이 아니다. 인용 «너도 나도 스스로 도는 힘을 위하여» + «서서 돌고 있는 것인가» 는 결정 문장으로 충분하다.
  - 25⑤: 인용(지하 깊은 곳에서…, 실핏줄까지 이어져 흐르는)이 «자연과 인간의 연결»의 결정 문장이다. 맞음.
  - 26①: «이 집 주인과의 이야기도 잊어버리고» + «또 한번 팽이를 돌려주었으면 하고 원하는 것이다» 로 열중을 보인다. 맞음.
  - 26③: 인용·이유 맞음.
