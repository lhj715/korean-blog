## 직접 잰 것

### 굵은 글씨 (2쪽 `get_texttrace`, type 0+1 겹침, 글꼴 Haansoft Batang)
- (가) 대화 16발화 모두 «학생N» 의 글자·숫자가 type 0+1. 세트의 `bold` 와 일치(발화 수 16 = 데이터 p2~p17).
- 쌍점: 앞 15개는 type 0 전용. **마지막 발화(학생1: 그럼 내가 먼저 초고를…)의 쌍점만 type 0+1**. 1200dpi 로 쌍점 잉크량을 재니 다른 쌍점은 모두 643, 마지막 쌍점만 893 이다. 비교 기준 15개가 type 0 전용임도 확인했다. 따라서 p17 의 `bold: ["학생1 :"]` 는 맞고, 나머지 발화에 쌍점을 굵게 하지 않은 것도 맞다. 작업자가 자신 없다고 한 곳은 문제 없음.
- «(가)», «(나)» 는 PDF 에서 type 1(굵은 글씨)이라 label 항목 처리와 일치한다. `[A]`·`[B]`·`[C]` 구간 표시도 type 1 이고 화면이 따로 그린다. 4번 발문의 «[A], [B]» 는 type 0(보통)이며 데이터도 굵게 하지 않았다.
- 3쪽 6·7번 선지·<보기>에는 굵은 글씨가 없고 데이터에도 없다.
