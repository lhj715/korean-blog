# 독립 검토 (1차): 세트_31-34 ((가) 고향으로 간다 / (나) 그 골목 잃어버리고)

검토 범위: 문제 11~12쪽 그림, 해설지 4쪽, 문제 PDF 텍스트층(`get_texttrace`), 정답 bundle, `세트_31-34.json`. 세트를 열기 전에 먼저 31~34번을 풀었다.

## 0. 스스로 푼 결과 (세트 열기 전)

- 31번 ④ (동일 시구 반복: (가) «고향으로 간다», (나) «그들은 떠났다»). ①은 (가)에 감탄사 없음, ②는 명령형 없음, ③은 (나)가 «영혼이여» 호격으로 끝남, ⑤는 (가)에 청자 없음.
- 32번 ② (㉠ 벗어 버림 = 변화를 앞두고 자신과 분리, ㉡ 검은 재를 밟으며 돌아옴 = 주변 변화 실감).
- 33번 ③ (ⓒ는 «어떤 황혼»이 무엇인지 묻는 것이지 이유를 묻는 것이 아님).
- 34번 ④ («기웃거리던 나»는 과거 행동).
- 전부 정답표·해설지와 일치. 세트 파일의 answer 값도 같다(4, 2, 3, 4).

## 1. 프로그램 검사

`세트_검사.py` 합격. 해설지에 없는 선지 8개(31① ② ③ ⑤, 32① ③ ④ ⑤)는 아래 3절에서 직접 확인.

## 2. 작업자가 자신 없다고 한 곳

1. (가) bold `{"text":"간다","nth":5}`: 맞다. `get_texttrace` 에서 마지막 행 «내가 간다» 의 «간다»만 type 0+1 겹침(글자마다 b,B 쌍)이고, «간다» 는 v1 안에서 1) 첫 연 2) «내가 간다» 3) «마시며 고향으로 간다» 4) «울리며 / 고향으로 간다» 5) 마지막 행 순서이므로 5번째가 맞다. 앞의 «고향으로 간다» 들은 모두 type 0 뿐이다. 쪽 그림에서도 마지막 행만 굵다.
2. (나) «떠»: 맞다. 첫 행 «그들은 떠났다» 에서 «그들은»(3자)과 «떠»가 type 0+1, «났다» 는 type 0 이다. 쪽 그림에서도 «그들은 떠» 까지만 굵다. 12쪽 맨 위 «그들은 떠났다» 는 전부 type 0(보통)이어서 bold 목록(첫 번째만 해당)이 맞다.
3. (나) 12쪽 맨 위 앞의 연 구분: 연이 나뉜 것이 맞다고 판단한다(데이터의 빈 줄 유지). 근거: 11쪽 오른쪽 단 마지막 줄(아, 처음부터…)의 글자 상단 y=737, 줄 간격 12pt, 단 아래 끝은 약 760pt(같은 단의 30번 선지 마지막 줄이 y≈758 에서 끝남). 연 구분 없이 이어지는 행이라면 다음 줄(상단 y≈749, 하단 ≈757)이 11쪽에 들어갔을 것인데 12쪽으로 넘어갔다. 빈 줄(연 구분, (가)의 연 사이와 같은 24pt 간격)이 있었다면 다음 줄이 y≈761 이 되어 들어가지 못하므로 12쪽으로 넘어간 것과 맞는다. 12쪽에서는 쪽 맨 위라 빈 줄이 눌려 보이지 않는다. 이 방향이 시 원문의 연 구분과도 부합한다(시의 호흡: 이웃이 떠났다는 반복 시구로 새 연을 시작). 직접 시집 원문 확인은 못 했다(웹 검색으로 전문을 찾지 못함).
4. (가)·(나) 머리표 굵기: 둘 다 type 0+1(굵다). 화면 도구가 `label` 을 굵게(`font-weight:700`) 그리므로 맞다. 노트 `- 김용호, ｢고향으로 간다｣-`, `- 나희덕, ｢그 골목…｣-` 는 type 0 뿐(보통)이고 데이터에도 bold 없음.
5. 34번 ④ 시행별 인용: 인용 둘(`침대에 몸을 눕히고 살면서 그들의`, `낮은 잠자리 기웃거리던 나는`)은 v2 의 연속된 두 시행이고 글자 그대로 들어 있다. 해설지가 지적한 «기웃거리던 나는 = 과거 행동» 이 둘째 인용에 있어 결정 문장이다. 통과.

## 3. 본문 대조

- 지문 글자·행 나눔·연 구분: (가) 7연(PDF 줄 간격 24pt 위치와 일치), (나) 1연 + 2연(위 2-3). 옛 표기(`하암북`, `예옛`, `서언하게`, `데불고`)와 `〜`·`~` 문제 없음.
- 문단 경계: 시이므로 해당 없음. `ranges` 는 비어 있고 원본에도 [A]·[B] 구간 표시 없음.
- 밑줄: ㉠ «낡은 옷», ⓐ «또한», ⓑ «사뭇», ㉡ «검은 재», ⓒ «어떤», ⓓ «총총히», ⓔ «또» 모두 쪽 그림 밑줄 범위와 같다. 발문 «않은» 밑줄은 33번·34번 둘 다 쪽 그림에 있고 `stem_underlines` 가 있다. 31번·32번 발문에는 밑줄 없음(그림과 일치). 선지 밑줄 없음.
- 굵은 글씨 (가): «끝내 잃어버려», «없는 고향», «눈감아도», «좁은 골목 골목들이 서언하게 다가»(«오구나» 는 보통), «그리움을 캐러 고향으로», «간다»(5번째)가 모두 type 0+1 와 일치. 누락·초과 없음. («그 그리움을» 의 첫 «그» 는 type 0 이어서 `그리움을 캐러` 부터가 맞다.)
- 굵은 글씨 (나): «그들은», «떠», «무너져내», «판잣집들», «그들의»(첫 번째, 3행 끝), «때 묻은 벽지를 정겹다 말했던 나»(«는» 보통), «침대에 몸을 눕히고 살면서»(뒤의 «그들의» 보통), «낮은 잠자리 기웃거리»(«던 나는» 보통), «누군가의 가난을 필요로 했»(«던 반성과» 보통) 모두 일치. 두 번째 «그들의»(676행)는 type 0 뿐이어서 bold 에 넣지 않은 것이 맞다. 12쪽 2연은 전부 보통.
- <보기>(34번): label «보 기», 한 문단, 글자·들여쓰기 그림과 일치. 34번 선지에는 굵은 글씨·밑줄 없음(그림·텍스트층 type 0 뿐).
- 정답·판정 방향: 31 ④(적절), 32 ②(적절), 33 ③(부적절·`is_answer` true), 34 ④(부적절·`is_answer` true). 모두 발문 방향과 맞다. 33번 ①·②·④·⑤(적절)과 34번 ①②③⑤(적절)의 `is_answer` false 도 맞다.
- 해설지 인용: 31④, 32②, 33 전 선지, 34 전 선지의 `explanation_quote` 가 해설지 4쪽 글자와 같고 그 문항 해설이다.

## 5. 반드시 고칠 것

1. **31번 ① 근거 인용·이유 (해설지 없음, basis 자체)**
   - 문제: 둘째 `evidence` 인용 `새론 출발의 기적을 울리며` 가 이유(«(가)에는 감탄사가 보이지 않는다. (가)는 '~ㄴ다'로 담담히 말한다»)를 받치지 않는다. 이 행은 감탄사가 없다는 것도, «-ㄴ다» 서술이라는 것도 보여 주지 못한다. «담담히» 는 지문·해설지 밖 해석이다.
   - 고칠 방향: 둘째 인용을 (가)가 «-ㄴ다» 로 끝나는 시행(`고향으로 간다` 또는 `고향으로 내가 간다`)으로 바꾸고, 이유를 «(가)에서 감탄사는 보이지 않고 행이 '간다'로 끝나는 서술이다. 감탄사 '아,'는 (나)에만 나온다» 꼴로 줄인다. «-구나»(감탄형 어미)는 품사가 감탄사가 아님을 필요하면 한 구절로 덧붙인다. «담담히» 삭제.

## 6. 고치면 좋은 것

1. **32번 ⑤ 이유**: «소외를 깨닫게 하는 것이 아니다. 소외되고 있음을 깨닫게 한다는 설명은 ㉠에 맞지 않다» 는 같은 말의 되풀이다. «㉠은 화자가 스스로 벗어 버리는 것이어서 변화로부터 소외된 상태를 보여 주지 않는다. ㉡도 그들이 떠난 상황을 실감하게 할 뿐 소외를 깨닫게 하는 것은 아니다» 처럼 이유를 채우면 좋다. 둘째 인용 ㉡은 이미 걸려 있다.
2. **31번 ⑤ 이유**: 위 표대로 «(가)에는 청자가 없다» 를 앞세우고 (나)는 «화자가 자기 마음을 부르는 말» 정도로 줄이기.
3. **32번 ③ 근거**: ㉡ 쪽 인용을 `그들은 떠났다` 와 함께(또는 대신) `㉡검은 재를 밟으며 돌아오는 나에게` 로 두면 이유(㉡이 이미 떠난 뒤의 모습)와 더 직접 이어진다.
4. **33번 발문 표기**: 데이터는 `ⓐ~ ⓔ에` 로 «~» 뒤에만 공백이 있다. PDF 텍스트층은 `ⓐ`(x=322.7) `~`(331.8) `ⓔ`(339.4) 사이에 공백 글자가 없고 쪽 그림은 `ⓐ~ⓔ` 꼴로 보인다. 검사기는 공백을 무시해 통과하지만 화면에는 공백이 보이므로 `ⓐ~ⓔ에` 로 맞추면 좋다.
