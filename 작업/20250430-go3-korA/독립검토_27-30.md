# 독립 검토 (1차): 세트_27-30.json (최서해 ｢무명초｣, 27~30번)

검토 방법: 세트 파일을 열기 전에 쪽 그림(10쪽·11쪽)과 해설지(3쪽 현대소설 부분)로 먼저 풀었다. 정답은 27=⑤, 28=②, 29=③, 30=④ 로 정답표·세트 파일과 같다. 프로그램 검사(`세트_검사.py`)는 합격이었다.

## 직접 확인한 것

- **굵은 글씨**: 10쪽·11쪽 `get_texttrace` 에서 type=1 줄을 모두 뽑아 세트의 `bold` 와 대조했다. 모든 type=1 줄에 같은 자리의 type=0 줄이 겹쳐 있고(58/58), 굵은 글꼴 이름 따로 쓴 곳은 없다(쪽 번호·머리글 제외).
  - p1: «김을 찾»(4째 줄 끝) + «아»(다음 줄 첫 글자), «서»는 type=0. 그래서 `김을 찾아`. 이어서 «원고를 / 써주기로 / 하고 / 돈 / 교섭» 까지 굵고 «을»은 보통. 세트의 두 항목과 일치.
  - p4: «목전의 현실»(은 보통), «그의 발을 문 안으로 끌어들였다». 일치.
  - p10: «그 사람», «같은 제배», «자기의 그림자가 눈앞에 떠»(오를 보통). 일치. p10 안에서 «그 사람» 은 한 번뿐이라 nth 불필요.
  - p11 [중략 줄거리]: 돋움, 대괄호 포함 굵음. 일치(`bold: ["[중략 줄거리]"]`).
  - p28 «병 없으면»·«못 견딜», p30 «나 같은 병자야 있으나 마나»·«마주 웃», p35 «가는 때마다 거절 없»·«감사히 생각»·«남의 기분»·«비열». 모두 일치.
  - 30번 선지가 인용한 낱말(‘김을 찾아’, ‘원고를 써주기로 하고 돈 교섭’, ‘목전의 현실’, ‘그의 발을 문 안으로 끌어들였다’, ‘같은 제배’, ‘그 사람’, ‘자기의 그림자가 눈앞에 떠’, ‘병 없으면’, ‘못 견딜’, ‘나 같은 병자야 있으나 마나’, ‘마주 웃’, ‘가는 때마다 거절 없’, ‘감사히 생각’, ‘남의 기분’, ‘비열’)는 지문의 굵은 글씨와 빠짐없이 짝이 맞는다. 세트에 없는 굵은 글씨도, 굵지 않은데 넣은 곳도 없다. 문제 번호(27.~30.)는 굵지만 이는 화면 도구 몫.
- **밑줄**: PDF 선 그림 확인. ㉠ «일 원 지폐»(x 210.6~247.3), ㉡ «알약»(x 506~521), 29번·30번 발문 «않은» 두 곳뿐이다. 세트에 모두 있다(`stem_underlines`). 29번 ①의 «미리 원고료»는 선이 없다(그림에서 그렇게 보일 뿐). 28번 선지·발문에 선 없음.

## 반드시 고칠 것

1. **`meta.exam` 의 월이 틀렸다.** 세트는 «2025학년도 4월 고3 전국연합학력평가 국어(공통)» 인데, 문제지 머리글(문제 PDF 1쪽·16쪽 «2025학년도 5월 고3 전국연합학력평가 문제지»)과 해설지 1쪽 모두 **5월**이다(파일 날짜 0430 은 시행일). 이 회차는 선택 «화법과 작문»(korA)이고 이미 게시된 2026-05-07 korA 세트도 «국어(화법과 작문)» 꼴이다. → `2025학년도 5월 고3 전국연합학력평가 국어(화법과 작문)` 으로 고친다. (참고: 이 폴더의 다른 세트도 meta.exam 이 제각각이다: 10-13·14-17·43-45 는 3월, 18-21·22-26 은 6월 모의평가, 31-34 는 4월, 1-3·4-9 는 «국어» 뿐. 회차 전체에서 한 표기로 맞춰야 한다. 주 세션이 일괄 처리 권장.)
2. **28번 ④ 근거·이유가 결정 문장이 아니다(자체 선지).** ④는 «㉡은 자신이 상대방을 찾아가게 된 이유»가 틀린 것인데, 이유는 «춘수가 찾아간 이유와 짝이 맞지 않는다» 로 모호하고 근거 인용 p4(«그 친구는 있으나 다른 사람이 있어서…»)는 어느 쪽도 가리지 않는다. 춘수가 의사를 찾아간 이유는 딸의 약(p11 «딸의 약을 얻기 위해 …의사에게 찾아간다»)이고, ㉡ 알약은 춘수 본인 몫으로 의사가 따로 준 것(p32 «이 물약과 가루약은 어린애한테 먹이고 이건 박이 잡수.»)이라는 점을 쓰고 evidence 도 이 두 곳으로 바꾼다. ㉠ 쪽도 «춘수가 상대를 찾아가 얻은 것이지 상대가 찾아온 것이 아니다» 로 분명히 쓴다(p1·p4 의 «찾아갔다»·«집 앞에 이르렀다» 가 근거).
