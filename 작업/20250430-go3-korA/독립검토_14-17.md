# 독립 검토 (1차): 세트_14-17 (독서 사회, 섀플리 값)

검토자는 쪽 그림(문제 5쪽·6쪽)과 해설지(14~17번)를 먼저 보고 스스로 푼 뒤 세트 파일과 대조했다.

## 스스로 푼 결과
- 14번 ⑤(적절한 해설 없음 = 지문에서 답을 못 찾는 질문), 15번 ②(C 한계기여도 8억 < B 16억), 16번 ③, 17번 ④(ⓓ 가다 / 회귀하다). 정답표·해설지·세트 파일 모두 일치.

## 프로그램 검사
- `세트_검사.py` 합격. 해설지에 없는 선지 4개(16번 ①②④⑤)를 별도 확인 대상으로 알려 줌.

## 대조 결과
- 지문 글자·문단 경계: 5개 문단. 들여쓰기 위치(연합형 / 섀플리 값은 / 섀플리 값을 구할 / 이제 가상의 / 이렇게 갑과 을이)를 쪽 그림에서 직접 확인. 5문단은 5쪽 왼쪽 단 맨 아래에서 시작해 오른쪽 단으로 이어지고, 텍스트층이 한 줄로 이어져 한 항목(p5)으로 맞다. `cont` 불필요.
- 밑줄: PDF 선과 대조. ⓐ뜻하며 / ⓑ빼서 / ⓒ달라질 / ⓓ갈 / ⓔ같다 모두 기호 뒤 낱말만, 쉼표·마침표 제외. ㉠은 «섀플리 값은 … 알 수 있다» 세 줄(선 3조각)이고 시작은 ㉠ 기호 다음 «섀플리», 끝은 «있다»로 마침표 제외(확대로 확인, ⓔ와 같은 방식). 발문 밑줄 14번 «없는», 15번 «않은», 17번 «않은» 모두 PDF 선과 일치. 16번 발문과 모든 선지에는 밑줄 없음(세트도 없음).
- 굵은 글씨: `get_texttrace` 로 5·6쪽의 type=1(굵은) 글자를 모두 뽑음. 문항 번호(14~17)·안내문(<[14 ~ 17] …>)·다음 안내문만 해당하고 지문·<보기>·선지·발문에는 없음. 세트도 굵은 글씨 없음으로 맞다. 선지·발문의 숫자·기호에도 굵은 처리 없음.
- 15번 <보기>: 구성 순서(그림 → 문단 → 표 → 문단)가 쪽 그림과 같다. 머리말 «보 기» 형식 맞다. `raster_text` «취수장 1 2 3 A B C» 는 그림과 일치(취수장 상자, 구간 1·2·3, A·B·C). 표 `pdf_text` «지자체ABC건설 비용6억 원22억 원30억 원» 은 쪽 그림 표 글자와 일치.
- 그림 조각 확인: 두 조각 모두 확대해 봤다. 구간 그림은 <보기> 상자 테두리 선이 조각에 걸리지 않고, 표는 표 자체의 바깥 테두리 4면이 모두 보이며 잘린 글자가 없다. 상자 바깥 테두리가 따라 들어온 곳은 없음.
- 정답·판정: 14번(없는 → ⑤ 확인 불가), 15번(않은 → ② 부적절), 16번 ③, 17번(않은 → ④ 부적절) 모두 발문 방향과 맞고 정답이 부정 판정이다. 각 선지의 판단도 지문·<보기>에 비추어 사실이다. 15번 숫자 계산(B 22-6=16, C 30-22=8, B,A,C 순서 C 증가 8억, B,C,A 순서 A 한계기여도 0)을 직접 재계산해 맞음.
- 해설지 인용(`explanation_quote`): 해당 문항 해설과 대조해 맞다(검사기 통과와 별개로 눈으로 확인). 이유에 «해설지는…» 메타 문구와 em dash 없음.

## 해설지 없는 선지(basis: 자체), 16번 ①②④⑤
- ①: 3문단 «순서에 따라 한계기여도가 달라질 수 있기 때문» 이 직접 반박한다. 맞다.
- ②: 가중치는 «특정 순서로 형성된 연합이 나타날 확률» 로 정의되고 증가분 크기와 무관하다. 근거(p3 정의)와 이유 맞다.
- ④: 2문단 «증가분에 비례» 와 반대. 근거·이유 맞다.
- ⑤: 판정(부적절)과 이유는 맞다. 다만 근거로 쓴 p5 문장(섀플리 값의 합 = 총비용)은 «경제주체 수가 늘수록 총비용이 줄어든다» 를 직접 반박하는 결정 문장은 아니다. 아래 «고치면 좋은 것» 참조.

## 반드시 고칠 것
- 없음.

## 고치면 좋은 것
1. 16번 ⑤ 근거: 이유는 «줄어든다는 내용은 지문에 없다» 로 맞지만, 근거 인용(p5 «섀플리 값을 모두 더하면 … 총비용과 같다»)이 반박 문장으로는 약하다. p3 «한계기여도는 … 총비용의 증가분» 을 함께 인용하면 «참여가 늘수록 총비용은 증가분만큼 늘거나 그대로» 라는 논리가 지문에 닿는다. 필수는 아님.
2. 17번 ⓐ~ⓔ 이유에 사전 뜻풀이가 들어 있으나 해설지가 직접 쓴 풀이와 같은 내용이고 어휘 문항의 성격상 허용 범위로 본다(선택 사항으로 «해설지에 쓴 풀이» 수준을 넘지 않는지만 유지).
