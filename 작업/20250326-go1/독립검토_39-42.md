# 독립검토 39~42번 (1차)

방법: 쪽 그림(14·15쪽)과 해설지로 먼저 풀고(39①, 40③, 41①, 42④, 정답표와 일치) 세트 파일과 대조했다. `세트_검사.py` 합격.

## 직접 확인한 곳
- ㉡ 밑줄: PDF 선 x 211.8~243.6 (y 666.7). 「㉡」 기호(198.8~)와 쉼표를 뺀 «웃으며» 와 일치. 세트 `웃으며` 맞음. ㉠ 선 199.9~231.7 도 «웃는다» 와 맞음.
- 발문 42번 «않은» 밑줄: 15쪽 선 x 97.7~118.9, `stem_underlines:["않은"]` 있음. 39번 발문·보기 밑줄 없음. 선지 쪽 «않은»(40번 ②, 선 없음)은 해당 없음.
- 굵은 글씨(`get_texttrace` type, font Haansoft Batang): (가) 띠집 / 보리밥 풋나물을 알맞게 먹 / 그 남은 여남은 일 / 성이 게으 / 하늘 / 강산을 지키라 하, (나) 밭 갈고 씨 뿌리 / 눈과 얼음 속에서 / 여우 담비 털옷을 덮어 주면 사양하지 않 / 다른 사람과 다 / 그늘에 들어가는 것 / 햇볕 아래 홀로 서 있는 것만도 못 — 모두 type 1(또는 0+1)로 세트와 같다.
- 작업자가 자신 없다고 한 «그늘에 들어가는 것» 뒤 «은 차라리 뜨거운»: «은 »(x~480~493)과 «차라리 »(493)·«뜨거운» 은 type 0 전용이고 type 1 조각이 없다. 쪽 그림에서 번져 보이는 것은 변환 탓. 굵지 않음이 맞다(세트 정상). 비교 기준 type=0 글자(예: «합니다», «못하게»)도 type 0 전용 확인.
- 문단 경계(줄 시작 x): a8 «저는 하늘의 때를…» x=459, a9 «그대는 어찌…» x=459(들여쓰기), a10 «물어봤던…» 새 줄. a1~a7 은 그림과 같음. [A] 는 a7 전체(14쪽 괄호선, 쪽 넘어 «것입니다.» 까지). 맞음.
- 40번 ⑤ 끝 [A] 꼬리표: 텍스트층 쪽 끝 글자일 뿐이며 세트 선지에는 없음. 맞음.
- 판정: 39①·40③·41①·42④ 정답이 정답표와 같고, 42는 «않은» 이므로 정답 선지 판정이 «부적절» 로 맞다. 선지 5개씩, 해설지 인용은 각 문항 해설에 글자 그대로 있고 해설지에 없는 선지 없음. 이유에 em dash·«해설지는…» 메타 문구 없음.
