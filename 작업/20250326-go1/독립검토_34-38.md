## 고치면 좋은 것
1. 36③ 근거 인용(p3 «검사가 … 기소하며 소송이 시작된다.»)은 «법규가 없으면 기소할 수 없다» 와 직접 맞닿지 않는다. 이 선지는 해설지가 «기본권 침해와 관련 없음» 으로만 처리하므로 근거를 p2 «여기서 형벌은 … 기본권을 박탈하는 것을 내용으로 한다.» 로 바꾸거나 함께 달면 이유(법언은 기본권 침해 방지)와 연결이 더 분명하다.
2. 36⑤ 두 번째 근거(p6 «그래서 흉악한 범죄를 … 무죄를 선고받기도 하는데») 는 결정 문장이 아니다. 이유 문장이 «형벌은 기본권을 박탈» 이므로 p2 의 기본권 박탈 문장을 첫째 근거로 넣고 p6 첫 문장(합리적 의심 여지 없는 강한 입증)과 짝지으면 더 낫다. 현재 상태도 판정·이유 자체는 틀리지 않았다.
3. 36④ 근거(p6 «즉, 증거가 … 피고인의 이익으로 판단한다.»)는 «확실한 범죄자가 아니면 기본권 침해 금지» 와 간접 연결이다. 무죄추정 문장(p6 «피고인은 유죄의 판결이 확정될 때까지는 무죄로 추정된다.»)을 쓰는 편이 이유와 더 가깝다.
4. 37④ 두 번째 근거(p6 «결국 법원은 … ⓔ신뢰할 만한 증거…») 는 이 선지가 틀린 이유(ㄱ 무죄 이유에 B의 과실이 없다)와 무관하다. 둘째 근거는 빼거나, 선지 후반부(ㄴ에서 A가 보행자를 인지하지 못한 것이 원고에게 유리)가 보기에서 판단 근거로 쓰이지 않았음을 보이는 ㄴ 문장(«A가 도로에 사람이 다닐 가능성을 염두에 두어 안전하게 운행할 의무가 있었고…») 으로 바꾸면 좋다.
5. 34⑤ 근거(p5 «형사법과 민사법은 서로 다른 분야인 만큼…») 는 «절충·대책 없음» 을 직접 보이지 못한다(없음의 증명이라 한계). 현재도 해설지와 같으므로 유지해도 무방.
