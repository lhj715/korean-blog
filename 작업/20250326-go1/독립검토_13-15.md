# 독립검토 13-15 (1차)

## 스스로 푼 결과 (세트 파일 열기 전)
- 13번: ⑤ 부적절(소녀와 사람은 대립이 아니라 포함 관계로 상하 관계). 정답표 5와 같음.
- 14번: ① 부적절(ㄱ의 «자기» 는 정우). 정답표 1과 같음.
- 15번: ② 부적절(쪽의 초성은 처음부터 된소리라 변동 없음, «윗쪽» 아님). 정답표 2와 같음.

## 확인한 것
- 프로그램 검사 합격. 정답·판정 방향(모두 «않은» 발문, 정답 선지가 부정 판정) 맞음.
- 굵은 글씨(get_texttrace, 글꼴 Haansoft Batang): 15번 «선생님» 은 type 0+1 겹침(굵음), 뒤 콜론은 type 0만(보통). «￭학습 과제» 의 «￭»·«학습 »·«과제» 는 0+1 겹침(굵음), 뒤 콜론 type 0(보통). 작업자의 bold(`선생님`, `￭학습 과제`)와 일치하고 콜론을 뺀 것도 맞음. 13번 표 머리(단어·의미 자질)는 type 1이나 그림 속 글자라 데이터에 달 필요 없음. 비교 기준 보통 글자(같은 쪽 지문·선지)는 type 0 전용 확인.
- 밑줄(PDF 선): 13·14·15 발문 «않은» 선 있음(데이터 stem_underlines 일치). 14번 <보기> ㄱ~ㅁ 의 자기·저·저희·당신·스스로 선 5개, 데이터 일치. 선지에는 밑줄 없음.
- 문단 경계: 13번 <보기> 두 문단(둘째 «상하 관계에서…» 는 들여쓰기), 14번 <보기> 서두 문단과 ㄱ~ㅁ 줄 구분(원본 빈 줄) 맞음. 15번 «선생님:» 은 대화 줄(둘째 줄부터 내어쓰기) 표기 맞음.
- 15번 흐름도 그림: 쪽 그림과 대조해 raster_text(A + B / ㄱ~ㄷ 중 하나의 음운 변동이 일어나는가? / 예·아니요 / A+ㅅ+B / A+B)가 그림과 같음. inbox 조건(제목+ㄱㄴㄷ 세 줄, 가운데 맞춘 제목), inbox 과제(a~e 다섯 줄), blank 표시가 쪽 그림의 상자 구조와 맞음. 학습 과제 문장은 상자 밖(맞음).
- 13번 표 그림: 단어·의미 자질 5행이 pdf_text, alt와 같음.
- 근거 인용: 선지마다 결정 문장 인용(13⑤는 상하 관계 정의 + 소녀 행, 15②는 ㄱ 조건 + «위+쪽» 줄). 다른 선지 근거 재사용 없음. 해설지 인용은 해당 문항 해설에 그대로 있음(검사 통과).
- 이유: 지문·해설지 범위 안, 사실 맞음, 메타 문구·em dash 없음. 해설지 없는 선지는 없음(해설이 선지마다 한 줄 이상 있음).
