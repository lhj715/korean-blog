# 독립검토 35~39번 (2024-06 고1, (가) 강호사시가 + (나) 상춘곡 + (다) 입춘) 1차

검토자는 쪽 그림(12·13쪽 좌우)과 해설지로 먼저 풀고 세트 파일과 대조했다. 유료 AI API 는 쓰지 않았다.

## 스스로 푼 결과
정답 35=③, 36=②, 37=⑤, 38=③, 39=④. 세트 파일의 answer 와 같고 bundle 정답과도 같다(검사기 합격). 판정(적절/부적절) 25개 모두 맞다.

## 직접 잰 것
- 굵은 글씨: 12쪽·13쪽 `get_texttrace` 에서 type 0 과 type 1 이 같은 자리에 겹친 글자를 줄별로 뽑았다. 본문 굵은 곳은 정확히 16곳이고 세트의 `bold` 와 한 글자도 다르지 않다. (가) 미친 흥이 절로 / 미더운 강 물결 / 소일하는 것 / 도롱이로 옷을 삼아. (나) 산수구경 가자 / 아침에 나물캐고 저녁에 낚시하 / 공명 / 부귀 / 청풍명월(淸風明月) / 벗. (다) 슬슬 / 으등등 / 봄비가 풋나물 내음새를 피우며 / 절기가 뜰 적마다 / 소년은 슬펐던 것이다(마침표 제외) / 슬퍼하는 슬픔도 가버렸다(마침표 제외). 쪽 그림에서도 같다. 누락·과잉 없음. 각 낱말은 해당 항목에 한 번씩만 나와 `nth` 문제도 없다. 선지·<보기> 안 굵은 글씨는 없다. (가)(나)(다) 소제목은 굵게 찍히나 label 로 도구가 그리므로 문제없다.
- 밑줄(PDF 선 좌표와 글자 대조): ㉠ ㉡ ㉢ ⓐ ㉣ 일치. ㉣ 은 선이 «것이다.» 의 마침표까지 간다(세트도 마침표 포함). ㉤ 은 선이 줄바꿈을 지나 «입춘이 온 / 것이었다» 에서 끝나고 마침표 앞에서 멈춘다. ⓑ 도 «있고 싶다» 에서 끝나고 마침표에는 선이 없다. 마침표를 뺀 처리는 PDF 선과 맞는다. 36·37·38번 발문 «않은» 밑줄 3개도 PDF 에 있고 세트에 등록되어 있다.
- 문단 경계: 쪽 그림의 들여쓰기로 (다) p1(㉣ 문단) / p2(절기가 뜰 적마다) / (중략) / p3(이런 고향에서는) / p4(그런 소년도) / p5(입춘이 드는 날) 5개가 맞다. 시 연 구분도 (가) 4연 12행, (나) 23행 연속이 쪽 그림과 같다.
- 36번 ③④ 선지 띄어쓰기: 세트의 «변화된 들판을 보며 감탄하는 화자의 모습이 드러나 있다», «타지에서 소대한을 맞이한 글쓴이의 상황이 드러나 있다» 는 쪽 그림과 같다.
- `세트_검사.py` 합격. 해설지에 없는 선지는 39 ①②③⑤ 4개 뿐이라는 안내가 나왔다.

## 반드시 고칠 것
없음. 아래는 «고치면 좋은 것» 이며, 정답·판정·인용 일치·밑줄·굵기·문단은 모두 맞다. 다만 아래 1~3 은 지난 회차 검토에서 «근거가 결정 문장이 아님» 으로 지적되던 유형이므로 2차에서 반영을 권한다. 3개를 다 반영하지 않아도 사실 오류는 없다.

## 고치면 좋은 것
1. 39번 ⑤ 근거 첫 인용 «맑은 물 굽어보니 떠오는 것이 도화(桃花)로다» (v2). 선지의 ⓐ 절망과 아무 관계가 없는 문장이다. ⓐ 가 든 줄 «아모타 백년행락(百年行樂)*이 ⓐ이만하면 어떠한가» 로 바꾸면 «절망이 아니라 만족» 이라는 이유와 맞는다.
2. 39번 ③ 근거 «공명도 날 꺼리고 부귀도 날 꺼리니» (ⓐ 쪽) 는 외로움과 무관하다. ⓐ 줄로 바꾼다. ⓑ 쪽 인용도 «겨울이 가는 것을 섭섭히 여기지 못했으나» 에서 잘려 있어 «즐거움이 아니다» 를 보이지 못한다. 같은 문단의 «봄이 오는 것을 즐거이 여기지는 않았다» 가 결정 문장이다.
3. 39번 ② 근거는 ⓐ 쪽 «청풍명월 외에 어떤 벗이 있사올고» 가 «행위에 대한 아쉬움이 없다» 를 직접 보이지 못하고, ⓑ 쪽 인용 «봄이 오는 것을 즐거이 여기지는 않았다» 는 오히려 ⓑ 의 거부감 쪽 설명이 맞다는 것을 보여 준다. 이 선지가 틀린 이유는 ⓐ 쪽(아쉬움 아님)뿐이다. 이유 문장은 이미 ⓐ 만 다루므로 문제없지만 근거를 ⓐ 줄(만족을 묻는 말) 하나로 정리하는 편이 낫다.
4. 39번 ① 이유 «ⓑ도 앞으로의 소망이 아니라 현재 느끼는 답답함이다» 는 ⓑ 가 «있고 싶다» 라는 바람인 점에서 단정이 과하다. 해설지(④)의 뜻대로 «ⓐ 는 과거 동경이 아니라 현재 삶에 대한 만족이고, ⓑ 는 봄이 오는 현재 상황에 대한 답답함» 정도로 낮추는 것이 안전하다.
5. 35번 ④ 근거(v1 «이 몸이 서늘한 것도 역시 임금의 은혜로다», v2 도화 줄)는 «감정이입이 없다» 를 보이는 근거로 약하다. 해설지 자체가 «드러나 있지 않다» 형이라 반증용 인용이 원래 어렵다. 지금 인용도 틀리지는 않으므로 그대로 둬도 된다. 35 ①(겨울 줄 하나), ⑤(공간 이동 줄과 오피스 줄)도 같은 «없다» 형이며 해설지 문장과 일치하므로 통과 수준이다.
6. 36번 ② 근거에 «꽃나무 가지 꺾어 잔을 세면서 먹으리라» 가 같이 있다. 이 줄은 자연 속에서 즐기는 모습이라 읽는 학생이 «동화 바람이 드러난다» 고 오해할 수 있다. 이유가 갈건 표현만 다루므로 이 줄은 빼도 된다.
7. 36번 발문 stem 이 «㉠~ ㉤에» (공백 포함) 로 되어 있다. 쪽 그림은 «㉠~㉤에» 로 붙어 있다(텍스트층에는 공백이 있어 검사는 통과). 화면 충실도만의 문제다.
8. 38번 ① 근거는 «슬슬» 줄만 인용하고 «으등등» 줄은 없다. 선지가 두 낱말을 말하므로 두 번째 근거를 추가하면 더 좋다.

## 확인한 «자체» 선지(39 ①②③⑤) 요약
판정은 모두 맞다. ① ⓐ 현재 만족이라 «과거 동경» 아님, ② ⓐ 아쉬움 없음, ③ ⓐ 외로움 아님·ⓑ 즐거움 아님, ⑤ ⓐ 절망 아님·ⓑ 후회 아님. 이유 문장은 지문 안 내용으로만 되어 있고 em dash·«해설지는…» 문구도 없다(위 4번만 표현을 낮출 것). 문제는 근거 인용의 선택(위 1~3)뿐이다.
