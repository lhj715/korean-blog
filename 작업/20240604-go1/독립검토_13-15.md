# 독립 검토 13~15번 (세트_13-15.json, 1차)

검토 방법: 문제 5쪽 그림과 해설지 2쪽으로 13~15번을 먼저 풀고(정답 5·1·5, 정답표와 같음), 그다음 세트 파일과 대조했다. 프로그램 검사(`세트_검사.py`)는 합격(해설지에 없는 선지 13번 ①②③④ 표시).

## 확인한 것

- 지문 글자·<보기> 글자: 쪽 그림과 텍스트층이 일치한다. 15번 «벌써그렇게»(텍스트층 붙임)는 그림대로 띄어 쓴 것이 맞다.
- 13번 <보기> ▸ 항목: 그림에서 ◦ 줄 아래 ▸ 두 줄이 안쪽으로 들여 쓰여 있고 각 줄이 한 문장 단위다. b1(◦)·b2·b3(▸)로 나눈 구조가 맞다. 화면은 ▸ 들여쓰기를 그리지 않으나 내용·순서에는 영향이 없다.
- 14번 흐름도: 그림 확인. 첫 질문 «아니요» → 신라[실라], «예» → 둘째 질문, 둘째 «예» → ㉠(아래), «아니요» → ㉡(오른쪽). alt 설명이 그림과 정확히 같다. 표시 상자(<보기> 테두리) 안에 [학습 활동]과 흐름도가 있고, ㉠ ㉡ 열 머리는 상자 밖이라 plain 상자로 둔 것도 맞다. 음운 변동 판정(옷맵시·꽃말·덮개·묵념·부엌문·앞날·광안리·권력가·귓속말·습득물)은 해설지와 같다.
- 굵은 글씨(`get_texttrace` type 0+1 겹침 직접 확인): 15번은 «학생 1»·«학생 2» 여덟 곳만 type=1이고 뒤의 콜론은 type=0(보통)이다. 데이터 bold 가 정확히 같다. 14번은 «[학습 활동]» 만 type=1(㉠과 ㉡에… 이하는 보통)이다. 13번 <보기>·선지와 15번 선지에는 굵은 글씨 없음. 누락·과잉 없음.
- 밑줄(PDF 선 좌표와 낱말 좌표 대조): 15번 ㉠우리(117~137 쪽 안 505~526), ㉡그거, ㉢어디(593~614, 조사 «서» 제외), ㉣거기, ㉤무엇(541~562, 조사 «을» 제외), ㉥그때, ㉦그때가 낱말 범위와 일치한다. 발문 «않은» 밑줄은 13번(342~364)·15번(676~697) 있고 14번(「적절한」)은 없다. 데이터와 같다. 선지 안 밑줄 없음.
- 정답: 13번 ⑤, 14번 ①, 15번 ⑤ 모두 정답표와 같고, «적절하지 않은 것» 발문(13·15)의 정답 판정이 «부적절», 14번(적절한 것)의 정답 판정이 «적절»이다.
- 해설지 없는 13번 ①②③④(basis:"자체"): 각 선지를 <보기> 두 규칙에만 대어 확인했다. ① 떫다(기본형 현재 → 형용사), ② 읽는다(-는-), ③ 논다(-ㄴ-), ④ 간 사람(과거 → 동사) 모두 판정·이유가 <보기>와 사실에 맞고, 이유가 <보기> 밖으로 나가지 않는다. 근거 인용도 각 선지의 결정 문장이다(③은 ‘-는-/-ㄴ-’ 문장 전체를 인용해 ㉣ 해당 부분을 포함한다).
- 해설지 인용: 13⑤, 14번 5개, 15번 5개 모두 해설지 해당 문항 문장과 글자 그대로 같다(검사기 통과).
- 이유 문장: «해설지는…» 메타 문구 없음, em dash 없음, 지문·해설지 밖 사실 없음.
