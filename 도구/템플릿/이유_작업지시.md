# «이유» 다시 쓰기 지시 (작업자)

기출 풀이 페이지의 «이유» 중 선지를 거의 되풀이하기만 해서 학생이 «왜 그런지» 알 수 없는 것을 고친다. 사용자 결정(2026-11-25): **선지를 되풀이하는 것만** 고치고 **말투는 지금 그대로**(«~다» 평서체, «-요» 쓰지 않는다). 핵심은 학생이 이해하기 편한가다.

## 입력과 출력
- 입력: `D:\Work\블로그\리딩맵\작업\_이유\묶음_NN.json` — `passages`(세트별 지문 문단), `items`(고칠 대상: 발문 stem, <보기> bogi, 선지 choice, 판정 verdict, 지금 이유 reason, 근거 evidence, 해설지 인용 explanation_quote).
- 출력: `D:\Work\블로그\리딩맵\작업\_이유\결과_NN.json` — `{"항목 id": "새 이유"}`. 지금 이유가 이미 «왜 맞는지/틀리는지» 를 충분히 알려 주면 값을 null 로 둔다(선지와 글자가 겹쳐도 설명이 되면 그대로 둔다). **묶음의 모든 id 가 결과에 있어야 한다.**

## 새 이유 쓰는 법
1. 지문(또는 <보기>)의 **어느 말**이 근거인지 따옴표로 짚는다(지문 글자 그대로. 필요하면 «2문단» 처럼 위치도).
2. 그 말이 선지의 어떤 표현에 해당하는지, 어려운 말이면 쉬운 말로 잇는다.
3. 그래서 **왜** 맞는지(또는 어디가 어떻게 틀렸는지) 한 마디로 말한다. 틀린 선지는 «선지의 이 부분» 이 지문의 «이 말» 과 어떻게 다른지를 짚는다.
- 보통 1~3문장, 40~150자. 선지를 그대로 옮겨 적지 않는다.
- 지문·<보기>·해설지 인용에 없는 사실을 지어내지 않는다. 판정(verdict)을 바꾸지 않는다. 판정이 틀려 보이면 고치지 말고 null 로 두고 보고한다.
- em dash(—) 금지, «해설지는…» 같은 메타 문구 금지, 따옴표 속 글자는 원문 그대로.
- 근거 판단에 지문 전체가 필요하면 `passages` 를 읽는다. 그림이 근거면 그림 글자(raster_text 등)를 본다.

## 확인
`py -X utf8 도구\이유_고치기.py 검사 NN` (폴더 D:\Work\블로그\리딩맵) 의 문제가 0 이 되게 한다(«여전히 선지를 되풀이» 는 설명을 보태 해결한다. 설명이 이미 충분해 어쩔 수 없으면 null).
파일은 결과_NN.json 만 만든다. 세트 JSON·도구·CLAUDE.md 는 고치지 않는다. 임시 파일은 `작업\_이유\_임시\` 에만. 유료 AI API 는 쓰지 않고 언급하지 않는다. 최종 답: 대상 수, 고친 수, 판정이 의심스러운 항목. 짧게.
