# 문법 자료 마스터 체계 (readingmap.kr)

표준 학교문법(고등 국어 + 「언어와 매체」의 '언어') 체계를 그대로 따른다.
전통 문법 3분(음운론·품사론·문장론) + 담화·국어사·어문규범으로 확장한 형태로,
교과서·수능·내신이 공유하는 정해진 골격이다. **이 순서대로 위에서부터 채운다.**

출처 원칙: 개념·정의는 학교문법 통일안, 예시·심화는 평가원 기출·교재(`sources.yaml` 3순위),
단어 품사·발음·맞춤법 사실은 국립국어원 API·어문규범으로 검증(1·2순위). 블로그는 사실 출처 금지.

---

## 0. 언어와 국어  (도입, category: 언어)
- 언어의 본질 — 자의성·사회성·역사성·창조성·규칙성·기호성
- 국어의 특질 — 음운·어휘·문법적 특질

## 1. 음운  (category: 음운)
- 음운의 개념과 체계 — 자음 체계, 모음 체계(단모음·이중모음), 운소(소리의 길이)
- 음운의 변동
  - 교체 — 음절의 끝소리 규칙 / 비음화 / 유음화 / 구개음화 / 된소리되기(경음화)
  - 탈락 — 자음군 단순화 / 'ㅎ' 탈락 / 'ㅡ' 탈락 / 'ㄹ' 탈락 / 동음 탈락
  - 첨가 — 'ㄴ' 첨가 / 반모음 첨가 / 사잇소리 현상
  - 축약 — 거센소리되기(자음 축약) / 모음 축약

## 2. 단어  (category: 단어)
- 형태소 — 자립/의존, 실질/형식 형태소
- 단어의 형성 — 단일어 / 복합어(합성어·파생어), 합성법·파생법
- 품사 — 9품사
  - 체언: 명사·대명사·수사
  - 용언: 동사·형용사 (활용, 어간·어미, 본용언·보조용언)
  - 수식언: 관형사·부사
  - 관계언: 조사
  - 독립언: 감탄사
- 단어의 의미 관계 — 유의/반의/상하 관계, 다의어·동음이의어

## 3. 문장  (category: 문장)
- 문장 성분
  - 주성분: 주어·서술어·목적어·보어
  - 부속 성분: 관형어·부사어
  - 독립 성분: 독립어
  - 서술어의 자릿수
- 문장의 짜임
  - 홑문장 / 겹문장
  - 안은문장: 명사절·관형절·부사절·서술절·인용절
  - 이어진문장: 대등·종속
- 문법 요소
  - 높임 표현 — 주체·객체·상대 높임
  - 시간 표현 — 시제(과거·현재·미래), 동작상
  - 피동·사동 표현
  - 부정 표현 — '안'/'못' 부정, 짧은/긴 부정
  - 종결 표현

## 4. 담화  (category: 담화)
- 담화의 개념과 구성 요소 — 화자·청자·전언·맥락
- 담화의 표현 — 지시·대용·접속 표현, 직시
- 담화의 요건 — 통일성·응집성

## 5. 국어의 역사  (category: 국어사)
- 국어의 계통과 형성
- 훈민정음 — 창제 원리(제자 원리)
- 중세 국어 — 음운·표기·문법 특징
- 근대 국어
- 현대 국어

## 6. 어문 규범  (category: 어문규정)  ← 어문규범 원문이 1차 근거(가장 안전)
- 한글 맞춤법
- 표준어 규정
- 표준 발음법
- 외래어 표기법
- 국어의 로마자 표기법

## front matter 스키마 (grammar)
```yaml
title: "..."          # 항목명
category: "..."       # 위 7분류 중 하나 (언어/음운/단어/문장/담화/국어사/어문규정)
grade: "고1-3"        # 학년 범위(선택)
keywords: [...]       # 검색용
summary: "..."        # 1줄 요약
```
* 본문에 '시연용/예시' 같은 자기참조 안내문 금지.
