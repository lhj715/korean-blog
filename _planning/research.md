# Phase 1 — 자료 수집·리서치 결과 (readingmap.kr)

대상: 고1~고3 / 목적: 국어(특히 문학) 작품 자료 + 기출 아카이브. 작품 수백~수천.

## 1. 전문 사이트들이 다루는 분류 체계 (조사 결과)

### 수능 국어 영역 공식 구조
- **공통**: 독서(17문항), 문학(17문항)
- **선택**: 화법과 작문 / 언어와 매체 (택1, 11문항)
- 총 45문항 / 80분

### 문학 갈래 표준 6분류 (EBS 수능특강·교과서 공통)
1. 고전시가 (향가·고려속요·시조·가사 등)
2. 현대시
3. 고전산문 (설화·판소리계·고전소설·고전수필)
4. 현대소설
5. 극 (희곡·시나리오)
6. 수필

### 작품 1편당 전문 사이트가 제공하는 자료 항목
- 원문 (고전은 **고어 표기 + 현대어 풀이** 병기)
- 작가 / 갈래 / 연대(추정) / 출전
- 해제(작품 해설) · 핵심 정리(주제·특징·표현)
- 시어/구절 풀이, 어휘·한자
- 수능·평가원 **출제 이력**
- 변형문제 / 기출문제 연결

### 기출 분류 축
- 연도(학년도) × 시험종류(학력평가 / 모의평가 / 수능) × 영역

## 3. 핵심 인사이트
- **탐색은 다축(多軸)이어야 한다.** 학생마다 진입로가 다름:
  - 갈래별(고전시가/현대시…) · 작가별 · 연대별 · 출제연도별 · 교과서(출판사)별
  - → Hugo **taxonomy(분류)** 기능으로 한 작품에 여러 축을 동시에 태깅.
- **데이터 중심 설계 필수.** 수천 작품을 글마다 손으로 못 만듦.
  → 작품 = 정형화된 front matter(메타) + 본문. 목록/연표/필터 페이지는 자동 생성.
- **저작권 주의.** 블로그 해설 원문 복제 금지. 출처 표기 + 자체 재가공/요약.
  현대 작품 원문은 저작권 살아있는 경우 多 → 발췌·해설 중심, 고전(저작권 만료)은 원문 게재 가능.

## 4. 기술 스택 결론: Hugo 유지가 정답
- 정적사이트 = 수천 페이지도 빠르고, 호스팅 무료(Cloudflare Pages/GitHub Pages), 비개발자 유지보수 부담 적음.
- GitHub = 단일 진실 소스 (기존 워크플로우와 일치).
- 데이터 파일/콘텐츠 + 커스텀 레이아웃 + taxonomy로 다축 탐색 구현 가능.
- DB 기반(Next.js 등)은 작품 자료 사이트엔 과함 + 비용·취약점↑. → Hugo 채택.
