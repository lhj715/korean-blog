# 기출 근거 표시형 분석 작업 지침

이 문서는 리딩맵의 기출 분석란에 올릴 문항 분석 콘텐츠를 만들기 위한 작업 방식이다. 목표는 문제와 정답을 단순히 함께 보여 주는 것이 아니라, 각 정답 판단을 지문 속 근거와 직접 연결하는 것이다.

## 목표 형식

- 문제 전문을 통째로 재게시하지 않는다.
- 원천 문제 PDF와 정답 및 해설 PDF를 기준으로 정답을 확인한다.
- EBS 해설은 검증 소스로 사용하되 문장을 그대로 길게 옮기지 않는다.
- 페이지에는 짧은 근거 구절, 자체 분석, 선지별 판단, 사이트용 근거 태그를 제공한다.

## 작업 순서

1. 회차 선택
   - 예: `2026-03-24 고2 전국연합학력평가 국어`
   - 문제 PDF, 정답표 또는 정답 이미지, 해설 PDF가 모두 있는지 확인한다.

2. 텍스트 추출
   - 문제 PDF에서 지문, 문항, 선지를 추출한다.
   - 해설 PDF에서 정답표와 해당 문항 해설을 추출한다.
   - 추출 텍스트는 검증용으로 보관한다.

3. 세트 단위로 묶기
   - 국어 기출은 보통 하나의 지문이나 자료가 여러 문항을 이룬다.
   - `1~3번`, `4~6번`처럼 지문 세트 단위로 분석한다.

4. 지문 근거 태그 만들기
   - 정답 판단에 필요한 지문 구절을 `E1`, `E2`처럼 태그화한다.
   - 근거 구절은 길게 옮기지 말고, 필요한 만큼만 요약 또는 짧게 인용한다.
   - 각 근거 태그에는 연결 문항을 명시한다.

5. 문항별 분석 작성
   - 문제 요구를 한 문장으로 설명한다.
   - 정답 번호를 명시한다.
   - 정답 근거를 `E1`, `E2` 같은 태그와 연결한다.
   - 선지별로 `정답`, `오답`, `적절`, `부적절`, `반영`, `미반영`을 분명히 판정한다.

6. 검증
   - 정답 번호가 EBS 정답표와 일치하는지 확인한다.
   - EBS 해설의 판단과 자체 분석이 충돌하지 않는지 확인한다.
   - 지문 근거 없이 단정한 문장이 있는지 확인한다.
   - 선지의 용어를 바꿔 말하다가 의미가 달라지지 않았는지 확인한다.

## 문체 원칙

- 교사용으로도 쓸 수 있게 판단 근거를 정확히 쓴다.
- 학생이 읽어도 바로 이해되도록 문장을 짧게 유지한다.
- “왜 이 선지가 틀렸는지”를 지문 근거와 연결한다.
- EBS 해설 문장을 그대로 베끼지 않고, 정답 확인과 판단 검증에만 사용한다.
- 애매한 분석은 쓰지 않는다. 근거가 불명확하면 “검토 필요”로 표시한다.

## 품질 기준

- 정답 번호가 틀리면 실패다.
- 정답 근거가 지문에 없으면 실패다.
- 선지별 판단이 정답과 충돌하면 실패다.
- 긴 원문 복붙으로 페이지를 채우면 실패다.
- 사용자가 문제 PDF를 옆에 두고 볼 때, 어느 문장 때문에 정답이 되는지 바로 알 수 있어야 성공이다.
